## 摘要

本文件描述虛擬幣與外匯系統的整體組件架構。Crawler Agent 使用 Go 語言實現，透過 Chromedp 從火幣網、幣安、Yahoo、鉅亨等來源爬取數據；後端服務則以 .Net 開發，分為 Crypto 與 Forex 兩大流程，包含 Model、FlowService（存 DB）、CacheService（存 Redis）。最終由 CurrencyService 透過 WebSocket 或 API 暴露數據給第三方，CurrencyManageService 則提供管理端的 Page 與 Dashboard 功能。此文件可幫助 AI 開發者快速掌握各模組的職責與技術棧。

## 關鍵設計決策

- - 爬取代理（HouBiCAgent、BinanceCAgent）採用 Go + Chromedp 模擬瀏覽器進行動態資料擷取
- Crawler 與後端分離，Go 負責爬取，.Net 負責流程處理、持久化與對外服務
- 虛擬幣與外匯採用獨立的 Package（CryptoPackage、ForexPackage）和對應的 Flow/Cache Service，確保邏輯隔離
- CurrencyService 提供兩種對外通訊方式：WebSocket（即時推送）與 API（請求/回應），滿足不同第三方整合需求
- Cache 層使用 Redis，負責快取最新匯率/幣值，降低 DB 查詢壓力
