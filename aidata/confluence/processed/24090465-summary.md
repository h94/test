## 摘要

本文件說明了 CrawlerAgent 產出的股票資料爬取架構，列出要寫入 Cassandra 的目標資料表（如 indexprice、stockprice、etfprice、twiiprice 等）及其欄位。文中提供了每個資料表對應的公開資料來源（台灣證券交易所、櫃買中心 API、政府資料開放平台、Yahoo 等）與詳細的欄位映射。對於 AI 開發 crawlerservice，可以據此實作各資料表的資料擷取邏輯與寫入 Cassandra 的轉換規則，並注意部分欄位（如最高/最低/開盤價）需從原始資料（如 5 秒指數統計）進一步計算。

## 關鍵設計決策

- - 所有股票資料爬取後直接寫入 Cassandra，不經過中間服務
- 資料表按年份分表命名，如 indexprice_xxxx、stockprice_xxxx，年份為四位數字
- 使用台灣證券交易所 (TWSE) 與櫃買中心 (TPEx) 的公開 HTTP API (response=json) 作為主要資料來源
- 部分指標（最高價、最低價、開盤價）無法直接從原始 API 取得，需從「每 5 秒指數統計」資料自行計算
- 上市與上櫃的指數名稱不一致，透過 Mapping Table 統一為 DB 顯示名稱（如「半導體」對應上市「半導體類指數」、上櫃「半導體業」）
- 公司基本資料從政府資料開放平台 CSV 下載，區分上市 (L)、上櫃 (O)、興櫃 (R)，並額外從官方網站擷取注意股、處置股、變更交易等狀態
- ETF 資料需合併上市與上櫃的來源，目標表 etfprice_xxxx 欄位統一
- 休市日期與原因從 TWSE 行事曆 API 取得，存入 closemarket 表
- 主力進出資料 (brokervolume) 從 Yahoo 股市抓取，非官方來源
