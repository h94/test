## 摘要

本文件為 ForumService 的初期技術規劃，採用 WordPress + wpForo 套件建置討論區並以 iframe 嵌入主站台。內容記錄了跨域 cookie、iframe 通信、外部阻擋、帳號安全傳遞等技術問題的嘗試與解決方案，並訂出擴充 WordPress PHP 的開發規範（如 class 封裝、PDO 連線、關閉 display_errors）。亦包含 API 備案設計與用戶交互介面雛形，但多數問題最終標示「暫無」解法，整體屬於探索性設計。

## 關鍵業務規則

- - 文章列表每頁顯示 10 筆（來自問題列表的確認結果，但最終改採 WordPress，此規則可能隨 WordPress 設定調整，需人工確認）
- 外部網站可透過 window.location.ancestorOrigins 阻擋，僅允許來自主站台的請求（最終採用此方式）
- 帳號傳入 iframe 前原本考慮加密傳輸（TripleDES/AES/SHA256），最終改採 member service 驗證（詳細驗證流程未說明）

---

## 關鍵設計決策

- - 選用 WordPress 架設論壇，搭配 wpForo 套件，而非自建系統
- 以 iframe 方式嵌入主站台，透過 port 轉發或檔案同源解決 cookie 跨域問題，最後選擇將檔案存放於同網域
- 不使用 v-show 以避免切頁後 postMessage 傳值異常，改採 v-if 並在 main.vue created 時重新渲染 forums 確保畫面狀態
- 擴充 WordPress PHP 時自訂 custom-includes/custom-config 資料夾，所有擴充用 class 封裝並先檢查 class_exists，連接資料庫一律使用 PDO，API 呼叫透過 Request Library，且不使用 Composer 及 namespace
- display_errors 設定保持關閉
- 備案考慮使用 MySQL + Cassandra 儲存文章、回文、留言，並以 Solr 提供文章列表查詢，以及 ckeditor 作為編輯器（但不確定是否實際導入）
