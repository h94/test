## 摘要

本文件說明了從 Betradar（Sportradar）API 提取足球比賽完整結果的技術方法，包括使用的端點（stats_match_timeline、match_details）、事件結構與關鍵字段（如 type 為 match_ended 取得總比分，periodscore 取得半場比分，goal/card/corner 等為技術事件）。同時列出隊伍、聯盟、時間等基本資訊的取得路徑。對 AI 開發的幫助：可作為 CrawlerAgent 解析 Betradar 數據的實作參考，確保正確輸出完整的比賽結果。

## 關鍵設計決策

- - 採用 Betradar 的 stats_match_timeline/{game_id} 端點獲取事件清單，並以 events 陣列中的 type 字段區分不同事件（如 match_ended、periodscore）來提取比分資訊
- 總比分直接取自 match_ended 事件的 result 字段，最後進球隊伍由 result.winner 給出
- 技術事件（進球、發牌、角球）透過 events 中每個物件的 key.type 辨識，name 欄位提供事件描述（如黃牌或紅牌）
- 比賽基本資訊（聯盟、隊伍、時間）從 match_details/{game_id} 的 data.values 取得，使用固定的 JSON 路徑（如 season.id、data.teams[home/away].name）
