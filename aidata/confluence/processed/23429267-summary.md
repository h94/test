## 摘要

文件定義了一個用於更新會員等級的 REST API（POST /memberservice/api/updateuserrank），可將一般會員（Rank:5）轉為專家會員（Rank:3），更新後需同步調用 ForumService API 以更新 Forum 系統中的帳號等級。因 ForumService 在本地環境未架設，此 API 僅限 PRD 環境執行。該設計為 AI 開發 MemberService 提供了明確的 API 介面、參數規格與外部依賴。

---

## 關鍵業務規則

- - 會員等級透過 Authkey 與 Rank 參數更新，Authkey 機制待確認
- Rank=3 代表專家會員，Rank=5 代表一般會員
- 更新會員等級後必須請求 ForumService API 同步更新 Forum 帳號等級
- 此 API 僅能在 PRD 環境操作，非 PRD 環境不可使用

---

## 關鍵設計決策

- - 採用 POST 方法提供更新會員等級操作，路由設在 /memberservice/api/updateuserrank
- API 需傳入 Authkey（推測用於身份驗證）與目標 Rank
- 更新完成後會再呼叫外部 ForumService 同步會員等級，以保持系統一致性
- 因 ForumService 僅存在於 PRD 環境，將此 API 限制為 PRD only，非 PRD 環境不暴露此功能

---

## 注意事項

- ⚠️ - ⚠️ Authkey 的來源與驗證機制文件未說明，需人工確認
- ⚠️ API 僅限 PRD 環境，開發與測試時無法直接調用，需注意環境隔離
- ⚠️ ForumService 為外部依賴，若其不可用可能導致部分同步失敗，文件中未定義異常處理
