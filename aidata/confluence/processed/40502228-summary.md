## 關鍵設計決策

- - ascbet provider 為減少 Docker 問題，未來將改用 WinApp 部署。

- BC(Vbet) 規劃將 Provider 從 SRV38 部署至 PRD 集群並切換到正式訊號源。
- 1Xbet Result 和 8BO 等 Provider 須根據目標機器環境建置對應的 EXE 檔。
- 使用 Bet365EdgeController 監控 Windows 上的 Provider 並執行重啟與更新。
- 透過 AutoUpgrade 監控並更新 Bet365EdgeController，並設為系統開機啟動。
