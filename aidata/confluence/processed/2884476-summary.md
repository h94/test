## 摘要

定義 LivechatService 中 SignalR Hub 將聊天訊息從 Redis 同步至 DB 的需求。包含定時作業檢查 Redis 中已結束的對話 Channel，將其備份到 DB 後清除 Redis 資料；以及當使用者或客服手動結束對話時，立即儲存訊息到 DB 並從 Redis 刪除。目的在於確保聊天記錄持久化並釋放 Redis 空間。

---

## 關鍵業務規則

- - 定時作業需檢查 Redis 中所有已結束的聊天 Channel。
- 對於已結束的 Channel，將資料從 Redis 備份至 DB。
- 備份完成後，清除 Redis 中該 Channel 的資料。
- 當 User 或 Agent 手動點選對話結束時，將該對話的 Message 資料儲存至 DB 並刪除 Redis 中的對應資料。
