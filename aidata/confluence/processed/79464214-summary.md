## 摘要

本文件記錄 InvestingFAgent 從原版本重構為 Python（InvestingFAgentV2），從 investing.com 抓取美元兌 18 種貨幣的即期匯率。採用兩種數據獲取方式：先用 httpx 解析 HTML 獲取所有匯率的全量快照，再通過 WebSocket 連接收取實時更新；定義了與 investing.com 的 pid 對應關係，並規範了最終寫入 DB 的 JSON 格式。部署在 SRV33（本機）和 SRV102（PRD2）的容器中。

## 關鍵設計決策

- - 採用雙通道數據採集：先以 httpx + regex 解析 HTML 頁面取得全量匯率（考慮某些匯率更新較慢），再通過 WebSocket 接收實時推送數據，以確保數據完整性與即時性。
- WebSocket payload 使用 bulk-subscribe 機制，以 pid 區分不同貨幣對（如 pid-2091 對應 USD/AUD），但 pid 涵義與 isOpenExch 參數尚未有官方文檔，目前根據測試經驗使用。
- 送入 DB 的數據結構統一為：{Site, Name, Datum, RequestTime, SendTime, Bid, Ask}，Bid/Ask 保留原始字串格式（含千分位逗號），未做數值標準化。
