## 摘要

此文件定義了一個從日本雅虎和美國雅虎運動新聞網站抓取新聞及評論的爬蟲任務。日本雅虎部分透過 API 取得文章列表、內容與評論，並以類似 PTT 格式寫入檔案；美國雅虎則直接爬取新聞列表頁面，再透過 spot.im API 取得評論。檔案依看板及日期組織，並有特定命名規則。這份設計文件可協助開發者理解爬蟲架構、資料格式與輸出結構。

---

## 關鍵業務規則

- - 日本雅虎抓取的看板及其 code：プロ野球(1)、MLB(2)、高校野球(3)、Jリーグ(5)、海外サッカー(6)、NBA(476)。
- 美國雅虎抓取的看板：NBA、NCAAB、NCAAW、MLB、WNBA。
- 日本雅虎新聞寫入格式仿照 PTT 看板格式，開頭為「Yahoo看板 {看板名}」。
- 日本雅虎存檔檔名格式：JP_Yahoo_{網頁名稱}，例如 JP_Yahoo_77d1d15271c0609d7f39774e6258537e518aac1c.html.txt。
- 美國雅虎存檔檔名格式：EN_Yahoo_{網頁名稱}，例如 EN_Yahoo_224947604.html.txt。
- 美國雅虎新聞無日期列表，需依文章的更新時間（update time）歸類至對應日期的資料夾。
- 日本雅虎文章的評論及回覆需透過特定 API 抓取（見文件中的三個 API）。
- 美國雅虎評論透過 POST 請求 spot.im API 取得，每次請求上限 50 筆，可指定排序方式（newest/top/oldest）。

---

## 關鍵設計決策

- - 採用 PTT 格式寫入檔案，便於與現有解析工具或閱讀習慣相容。
- 日本雅虎優先使用官方提供的 contents_list API 獲取文章列表，穩定性較高。
- 美國雅虎因無等效 API，直接解析新聞列表頁面（sports.yahoo.com/{page}/news/）的 HTML 取得文章連結。
- 美國雅虎文章日期以頁面上標示的更新時間為準，並以此決定檔案存放的日期目錄。
- 評論抓取採用兩段式流程：先取得文章內容，再根據文章 ID 調用評論 API。
- spot.im API 的請求需帶入從頁面提取的 spot_id 和 post_id，並在 headers 中傳遞，確保數據權限。

## 注意事項

- ⚠️ - ⚠️ 日本雅虎 API 的認證方式、請求頻率限制未說明，需人工確認。
- ⚠️ 美國雅虎 spot.im API 所需的 spot_id 和 post_id 需從原始文章頁面解析，提取規則未詳述，可能隨頁面改版而失效。
- ⚠️ 檔案命名中的「網頁名稱」具體來源未明確：日本雅虎範例使用了一段 hash（疑似從文章 URL 衍生），美國雅虎範例為數字，需確認提取邏輯。
- ⚠️ 美國雅虎的「更新時間」時區未定義，可能導致資料夾日期歸屬錯誤。
- ⚠️ 看板清單可能非最終版本，未來可能動態擴充，文件需持續維護。
