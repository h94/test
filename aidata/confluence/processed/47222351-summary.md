## 摘要

這篇文件記錄了爬蟲補上籃球與棒球賽果詳細資料的開發筆記。內容列出無法爬取的網站清單、已更新至 git 的站台，以及棒球關鍵統計欄位的定義與計算公式（如 ERA、AVG、OBP）。針對 MLB-BS、Sofascore-BS、ESPN-BS、ESPN-BK、CPBL-BS、nowscore-BS、covers-BS、betsapi-BS 八個資料源，分別給出 result_info JSON 輸出範例、資料取得方式（API、HTML 解析、個別球員彙總）與欄位計算細節，對爬蟲解析邏輯開發具直接參考價值。

---

## 關鍵業務規則

- - 棒球攻擊率 AVG = 安打數 (Hits) / 打數 (AtBats)
- 上壘率 OBP = (安打數 + 保送數) / (打數 + 保送數 + 犧牲觸擊)，但各站台不一定同時提供全部參數
- 長打率 SLG = 壘打數 / 打數，但文件中未直接給出壘打數來源，建議參考 Sofascore 或自行計算
- 總壘打率 OPS = OBP + SLG
- 自責分率 ERA = 自責分 (EarnedRuns) / 投球局數 (InningsPitched) × 9
- 守備局數 Outs = 總局數 × 3（一局 3 個出局數）

---

## 關鍵設計決策

- - ESPN-BS 的 AVG 與 ERA 因官網未直接顯示，採用自行計算（AVG = H/AB，ERA = 失分/局數×9），並以 Sofascore 數據對照驗證
- CPBL-BS 因原始資料為個別球員統計，需根據「VisitingHomeType」欄位（主隊=2，客隊=1）累加總和後再輸出 result_info
- covers-BS 採用 HTML 正則解析，直接取 AB、H、BB、SO、LOB、E 等欄位
- betsapi-BS 僅能取得 Hits 一項，資料最簡
- 各站台 result_info 均統一格式化為 {欄位名: [客隊值, 主隊值]}，即使部分欄位無資料仍保留結構
