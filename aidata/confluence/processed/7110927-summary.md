## 摘要

這份文件定義了 PriceCenterService 中 11 個用於查詢運動賽事相關資料的 API 端點，包含 SiteLeague、SiteTeam、SiteGame 和 SiteMatches 四大類。每個 API 都明確規範了必要參數（如 GameType）和選用參數（如 site、日期範圍、是否取賠率），其中 site 和 sitelid 等參數支援以逗號分隔的多值查詢。開發 AI 時可依據此規範正確調用 API 取得聯賽、隊伍、比賽及比賽歷史資料，特別要注意 GameType 是所有 API 的必要參數，而 isGetOther 賠率查詢功能僅在 isGetOdd 為 true 時才生效。

---

## 關鍵業務規則

- - 所有 API 的 GameType 欄位皆為必要選擇欄位，不可省略
- GetSiteLeauges、GetSiteTeams API 的 site 欄位為非必要，可傳入多筆以逗號分隔（如 mlb.com,yahoo.com），亦可不傳
- GetSiteTeamsBySitelid API 的 sitelid 欄位為必要，支援多筆資料以逗號分隔
- GetSiteGames、GetSiteGamesBySite API 的 endGameDate 為選擇欄位，不帶時僅查詢 startGameDate 當天資料
- GetSiteGames、GetSiteGamesBySite API 的 isGetOdd 為選擇欄位，預設為 false
- isGetOther 選擇欄位僅在 isGetOdd 為 true 時才有作用，預設為 false
- GetSiteGamesBySitelid API 的 site 欄位為必要（與其他 API 不同，此處 site 為必要）
- GetSiteSingleGameBySitegid 需同時提供 GameType、site、sitegid 三個必要欄位
- GetSiteSingleGamesByGid 僅需 GameType 和 gid 兩個必要欄位（無 site 限制）
- GetMatchHistrories 需同時提供 GameType、site、sitegid 三個必要欄位
