## 摘要

本文件定義足球讓分盤與大小盤的球頭顯示格式轉換規則。根據 API 回傳的球頭值（如 0+50、-1-50），使用特定公式區分讓分隊與被讓分隊，將原始格式轉換為慣用顯示（如 0/0.5、-0.5/-1）。大小盤僅需計算主隊球頭，規則類似。提供完整計算範例，可直接用於實現前端或賠率服務的格式轉換邏輯。

---

## 關鍵業務規則

- - 讓分盤判斷隊伍身份：球頭第一個數字為正數 → 讓分隊；負數 → 被讓分隊；若第一個數字為 0，第二個數字為負數 → 讓分隊，第二個數字為正數 → 被讓分隊。
- 球頭第一個數字為 0 時，不論讓分或被讓分隊，轉換公式均為：第一個數字 / (第一個數字 - 第二個數字/100)。
- 讓分隊且第二個數字為正數時，轉換公式為：(第一個數字 - 第二個數字/100) / 第一個數字。
- 讓分隊且第二個數字為負數時，轉換公式為：第一個數字 / (第一個數字 - 第二個數字/100)。
- 被讓分隊且第二個數字為正數時，轉換公式為：第一個數字 / (第一個數字 - 第二個數字/100)。
- 被讓分隊且第二個數字為負數時，轉換公式為：(第一個數字 - 第二個數字/100) / 第一個數字。
- 大小盤只轉換主隊球頭，客隊顯示與主隊相同，無需分別計算。
- 大小盤轉換公式與讓分盤相似，針對主隊球頭使用對應公式（例如 1-50 → 1/1.5）。
