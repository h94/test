## 關鍵設計決策

- - API 層按功能拆分獨立檔案（如 user.js），並封裝為 function，集中管理
- 靜態資源一律使用 `@/assets/{路徑}` 別名引入，確保跨環境路徑一致性
- 元件與頁面盡可能採用延遲 import（lazy loading），提升初始載入效能
- router 使用巢狀路由區分登入/非登入狀態，結合延遲 import
- Vuex store 以 module 拆分，簡化內部結構，不強制拆分 state/mutations/actions
- CSS 採用 OOCSS 原則，巢狀最多三層，命名使用 `小寫-小寫` 格式，少用 id 選擇器及 vw/vh 單位
- HTML 模板中屬性排序：v-if 類指令最前，原生屬性其次，事件綁定最後
- JS 程式統一使用 let 取代 var，function 宣告取代箭頭函式，async/await 取代 Promise（單純情況），並禁止不必要的全引入
