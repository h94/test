## 摘要

為解決前端無法顯示 siteleagues 與 siteteams 的 source_name，定義了兩個內部 PUT API，用於補充 namemap 欄位。API 由 xxl-job 每 3 小時依球種(gameType)排程呼叫，且不經過 gateway。同時提供各站台(site)對應的語言列表，用於取得正確的原始名稱翻譯。

---

## 關鍵業務規則

- - 定時任務每 3 小時執行一次，依球種(gameType)分別觸發對應的修復 API
- PUT /api/v1/system/fix/siteleagues/namemap/{gameType} 用於補齊 siteleagues 的 namemap 中的 source_name
- PUT /api/v1/system/fix/siteteams/namemap/{gameType} 用於補齊 siteteams 的 namemap 中的 source_name
- API 僅供內部 job 呼叫，不透過 gateway，對外不可見
- 參數 ?allData=false 可能表示只處理部分資料（非一次性全量）
- 每個 site 有對應的語言代碼，例如 mlb.com 對應 en-US，cpbl.com 對應 zh-TW，用於決定取得原始名稱的語系

---

## 關鍵設計決策

- - 採用 xxl-job 分散式任務調度，每 3 小時執行，並以球種為粒度分開處理，降低單次負載與失敗影響範圍
- 不經過 gateway，直接暴露內部 endpoint，因為僅限 job 使用，不需對外提供，簡化安全與路由設計
- API 設計為 PUT 操作，帶入 gameType 與 allData=false，推測可能僅更新缺少 source_name 的記錄，而非整個表
