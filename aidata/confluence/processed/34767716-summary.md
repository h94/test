## 摘要

本文件記錄了回測 API 的測試請求範例與對應的 Postman、資料庫及交易視圖截圖。測試案例涵蓋 SMA 乖離率、日 K/D、MACD 交叉、成交量等多種策略條件組合。從範例中可歸納出策略條件的 JSON 編碼格式：每個條件有 ID、text 與固定順序的 Value 陣列，不同 ID 對應不同指標（如 ID=9 為 SMA 乖離率，ID=13 為成交量）。對 AI 開發回測相關功能時，可用此文件理解請求結構與條件參數的語意。

---

## 關鍵業務規則

- - 策略條件以 JSON 物件陣列傳遞，每個物件包含 text（描述文字）、ID（條件類型代碼）、Value（參數值陣列）。
- ID=9（SMA乖離率）：Value 為 [均線類型（如'SMA'）, 天數, 比較運算符（如'小於'）, 閾值]
- ID=1（日KDJ值）：Value 為 [線型（K/D/J）, 天數, 比較運算符, 閾值]
- ID=2（KD交叉）：Value 為 [天數, 幾天內, 交叉類型（'黃金交叉'或'死亡交叉'）]
- ID=8（MACD交叉）：Value 為 [天數, 幾天內, 交叉類型]
- ID=13（成交量絕對值）：Value 為 [比較運算符, 張數]
- ID=3（成交量與均量比較）：Value 為 [比較運算符, 均量天數, 百分比]
- 比較運算符使用中文字串，如「大於」「小於」等。
