## 摘要

這份文件定義了 PredictService 中「莊家殺手」功能的 API 設計與資料庫結構。核心功能包含：1) 管理端設定莊家殺手週期（CID、開始/結束日期）與條件（最低場次、獲利點數、勝率）；2) 根據遊戲類型與聯盟 ID 查詢當前期別設定；3) 使用 Cassandra 儲存設定與會員殺手紀錄。文件也附帶了預測排行榜的回應格式範例，展示了 LastThirty/LastFourteen/LastSeven/ThisMonth 四個時間區間的排名結構。對 AI 開發而言，此文件提供了 API 合約（請求/回應格式）與 DB Schema，可直接用於生成 API Client 或 Mock 資料。

---

## 關鍵業務規則

- - 莊家殺手分為 normal（莊家殺手）和 super（超級莊家殺手）兩種等級，由 KillerType 欄位區分
- 莊家殺手條件設定須包含：最少預測場次(MinCount)、最低獲利點數(MinProfitPoint)、最低勝率(MinWinPercentage) 三項門檻
- 查詢週期設定時需傳入 gameType、lid 和指定日期，系統根據日期回傳對應的該期設定

---

## 關鍵設計決策

- - 選擇 Cassandra 作為資料庫，表名使用 settings_killer_cycle_{gametype} 的動態命名模式，以 gameType 作為分表依據
- killeraccounts_{gameType} 的 partition key 為 lid，clustering key 依序為 cid 和 account，支援依聯盟→期數→會員的查詢模式
- 莊家殺手 API 統一掛在 /predictservice/api/settings/killer 路徑下，週期設定和條件設定為獨立端點
