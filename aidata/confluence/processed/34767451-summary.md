## 摘要

此文件定義 PriceCenterService 新增一個 REST API 提供今日賽事站台資訊，取代既有的 WebSocket 方式。詳細說明了 GET /pricecenter/api/games/live/{gameType} 的回應格式（RedisTodayGame 結構），並包含站台與球種的對應規則。數據由排程每分鐘寫入 Redis DB7 快取，提供近即時查詢。對 AI 開發的幫助：理解今日賽事資料的獲取邊界、快取策略與回應結構，有助於整合或重構相關服務。

---

## 關鍵業務規則

- - 球種 SC 賽事對應的站台清單為：ZB, HGA, KU, NK, KKK, 188Bet, 1xBet, PS3838；其他球種對應：ZB, KU, NK, KKK, 1xBet, PS3838。
- 當日賽事站台資訊會由排程每 1 分鐘抓取一次，寫入 Redis DB7 快取。
- 取得賽事站台資訊的 API 必須從 Redis DB7 讀取資料，而非即時查詢來源系統。

---

## 關鍵設計決策

- - 從 WebSocket 推送改為 HTTP API 輪詢：降低客戶端複雜度，減少長連線依賴，且更容易監控與除錯。
- 採用 Redis 快取 + 排程定時更新（每分鐘）：在可接受的延遲內提供高效讀取，避免每次請求都直接查詢底層賽事服務。
- 以 gameType 作為路徑參數區分球種，讓前端可以按需拉取特定球種賽事，減少不必要的資料傳輸。
