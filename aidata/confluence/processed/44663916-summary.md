## 摘要

本文件定義了 PriceCenterSite GameTools 所需的所有 RESTful API 規格，涵蓋人工合併賽事、編輯賽事、編輯站台賽事、強制合併聯盟/隊伍、編輯聯盟/隊伍、翻譯及操作紀錄等功能。這些 API 主要供前端 Merge 站台使用，支援後台管理人員對來自不同資料源（站台）的賽事、聯盟、隊伍進行手動合併、拆分、編輯名稱/語系等操作。對 AI 開發的幫助：提供了完整的 API 路由、請求參數與回應結構，可據此實作 GameTools 的後端邏輯與前端介面串接。

---

## 關鍵業務規則

- - 人工合併賽事時，需指定 main（主賽事）及其 siteGames（被合併的賽事清單），主賽事欄位包含 site、siteLID、siteGID
- 強制合併賽事、聯盟、隊伍時，route 中的 dst 參數為主體（被保留下來的），src 參數為被合併方
- 搜尋隊伍 API（GET /backend/teams/{gameType}）的查詢參數 lids 與 tids 需擇一必填
- 取得聯盟詳細資料時，若不過濾 site 則 site 參數帶 'all'
- 取得原始賽事時，startTime、endTime、site 參數可不帶

---

## 關鍵設計決策

- - 所有 API 路徑統一以 /backend/ 開頭，區分後台管理功能與前台服務
- API 回應格式統一使用 {Code: 10000, Message: 'Success'} 表示成功
- gameType 作為路徑參數貫穿所有 API，支援多球種（如 BK 籃球、TB 桌球等）
- 合併操作（merge）與拆分操作（split）分別使用 PUT 方法，符合 RESTful 資源操作語意
- 翻譯功能獨立提供 GET /backend/translate API，支援指定來源語系與目標語系
- 前端 Merge 站台另有一組對外 API（/pricecenter/api/frontend/games/{gameType}），用於根據球種與時間範圍取得賽事
