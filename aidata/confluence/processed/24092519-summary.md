## 摘要

本文档描述了 GameTools 中强制合并赛事、联盟和队伍的功能需求，旨在解决数据中重复出现的问题。文档定义了三种合并场景：联盟强制合并（按时间或条件）、队伍强制合并（同一 LID 下不同 TID）、赛事强制合并（LID/TID 相同但 GID 不同），并指定了对应的 API 列表。前端通过开关（switch）控制已合并赛事显示，以启用强制合并操作。开发者可据此了解合并触发条件和前端交互逻辑。

---

## 關鍵業務規則

- - 联盟强制合并（时间搜索）：通过选择时间范围，筛选某球种 SiteGame 中已合并的 League 进行合并操作。
- 联盟强制合并（条件搜索）：可通过 URL 携带多个 LID（英文逗号分隔）实现多重搜索，支持中英文搜索。
- 队伍强制合并适用条件：相同赛事未合并，且在同一 LID 下出现队伍相同但 TID 不同的情况；通过 URL 携带 LID 和多个 TID（逗号分隔）进行合并。
- 赛事强制合并适用条件：赛事未合并，但两端联盟和队伍均已正确合并（即 LID 和 TID 相同，仅 GID 不同），且赛事已存在 GID。
- 赛事强制合并操作限制：必须先将显示模式 switch 切换为 enable（仅显示已合并赛事），然后才能进行强制合并，只能勾选已有 GID 的赛事。
