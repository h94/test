## 摘要

本文件描述股票前端（StockFrontEndSite）新增自選股畫面和回測系統畫面的實作需求。定義了股票資訊模型擴充欄位：三十日收盤價陣列、開盤價、最高價、最低價，並說明趨勢圖用 Canvas、K 棒用 HTML 繪製。自選股以 Tab 分類，可從股票頁面加入。回測系統需送出策略後透過刷新取得進度。對 AI 開發的幫助在於了解前端所需的資料結構和互動流程，以及與 API 的協定雛形。

---

## 關鍵業務規則

- - 股票資訊模型必須包含 ThirtyDayPrice（30日收盤價陣列）、OpenPrice、HighestPrice、LowestPrice。
- 30日趨勢圖使用 Canvas 繪製，需 API 提供30日價格資料連線。
- K 棒繪製需使用開盤價、收盤價、最高價、最低價，以 HTML 方式完成。
- 自選股需以 Tab 分類管理。
- 使用者可從股票資料畫面新增股票至自選股，並可透過自選股篩選。
- 回測系統送出策略請求後，需透過刷新機制查詢進度。

---

## 關鍵設計決策

- - K 棒繪製採用純 HTML 而非 Canvas 或 SVG，可能考量實作簡單或相容性。
- 30日趨勢線採用 Canvas，可能是為了支援動畫或平滑連線。
- 回測進度查詢採用輪詢（刷新）而非即時推送方式。
- 自選股以 Tab 分類設計，允許使用者建立多組自選組合。
