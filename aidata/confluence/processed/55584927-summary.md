## 關鍵業務規則

- - 當 Story 的 StoryPoint 為 13 時，須召開 Design Review
- 新增 Service 或 API 接口時，Release 階段應檢查 Gateway 是否有對應配置
- 新增 Service 或 API 接口時，必須修改對應的 swagger.json，步驟參考 Confluence 頁面 5341691
- 每日需確認團隊問題是否影響時程並回報，以及確保 JIRA Work Log 確實填寫
- 測試階段需關注 Bug 收斂情形，後期需補齊分析文件
