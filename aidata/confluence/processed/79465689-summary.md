## 摘要

這份文件定義了在現有的 NHL 爬蟲流程中，如何提取單場比賽的即時 Game Stats（如射門、爭球、判罰時間等），並說明了數據來源（score_cache JSON）、解析後的 send_data 欄位映射、以及本地與 PRD 環境的檔案儲存路徑。對 AI 開發來說，可直接參考 teamGameStats 結構與 send_data 的 type 命名對照，完成數據正規化與後續應用。

## 關鍵設計決策

- - Game Stats 數據已在 score_cache JSON 內，不需額外請求，直接從 game_cache['teamGameStats'] 讀取。
- teamGameStats 中的 category 值作為統計項目標識，對應 send_data 的 type 欄位（例如 'sog' -> 'shoot_on_goals'，'pim' -> 'penalty_minutes'）。
- 資料落盤分兩處：local 儲存於 D://GameData，PRD 則透過 WinSCP 上傳至主機 /usr/local/openresty/nginx/html/downloads/info/nhl.com/ 下的日期資料夾，檔名為 game_id.txt。
