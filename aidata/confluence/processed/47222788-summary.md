## 摘要

本文件定義了為球王新版站台新增或修改的預測相關 API，包含6支 API 的 Method、Route、Parameter 與 Response 範例。對 AI 開發的幫助：可直接作為 predictservice 的 API 規格參考，理解會員預測紀錄、殺手詳情、賽事預測下注等資料結構，以及語系參數的傳遞方式。部分 API 基於現有功能修改輸出格式，API #4 已被標記移除。

---

## 關鍵業務規則

- - API #2 和 API #3 新增語系參數 lang，預設值為 zh-TW
- API #1 取得的會員資訊包含 rank（排名）、killerCount、superKillerCount、focusCount、predictJoinWeek、predictWinWeek、stability（穩定性）、lastWinLoss（最近勝負紀錄陣列）
- API #1 的 killerDetails 包含 killerType 欄位，值為 super 表示超級殺手，以及 winPercentage、profitPoint、hasPending 等欄位
- API #3 的 lastWinLoss 陣列使用 W（贏）、L（輸）、-（無紀錄）三種狀態值
- API #3 的 predictBets 中 winLoss 值包含 W（贏）、L（輸）、C（取消）三種狀態，null 表示尚未結算
- API #3 的 score1 和 score2 為 -1 時表示比賽尚未開始或無比分資料
- API #5 解鎖會員多場預測賽事使用 PUT 方法，Request Body 為陣列，每個元素包含 LID、GDate、GID
- API #6 解鎖會員單場預測賽事使用 PUT 方法，Request Body 為單一物件，包含 LID、GDate、GID
- API #4 已被標記為移除，不應再使用

---

## 關鍵設計決策

- - API #2 和 #3 基於現有 API 修改，新增語系參數並更改輸出結構以符合新版球王站台需求
- API #4 原本用於取得會員球種聯盟賽事預測日期近況，但被標記移除，推測功能已整合至其他 API 或不再需要
- API #5 和 #6 分別處理批量解鎖和單場解鎖，分開設計以支援不同使用場景
