## 摘要

文件定義了會員服務（MemberService）的錯誤碼、.Net 中間層轉換碼及對應的 UI 提示訊息，涵蓋註冊、登入、忘記密碼/更改密碼、修改暱稱等流程，提供一致的錯誤處理規範，可作為 API 開發與前端錯誤提示的參考。

---

## 關鍵業務規則

- - 成功：MemberService 回傳 10000，對應 UI code 10000，訊息為 Success。
- 註冊：MemberService 10100 表示註冊成功，應發送驗證 Email；10101 表示 Email 驗證失敗；10102 表示 Email 已註冊；10103 表示註冊密碼格式錯誤；10106 表示 token 系統錯誤。
- 註冊中無 MemberService 碼的 UI code（如 10104 暱稱格式錯誤、10105 帳號驗證錯誤）可能由 .Net 層直接產生，需人工確認來源。
- 登入：MemberService 10200 表示登入成功；10201 表示 Email 格式錯誤（.Net 轉為 10206）；10202 表示 Email 不存在；10203 表示密碼格式錯誤；10204 表示密碼錯誤；10205 表示密碼加密失敗。
- 忘記密碼/更改密碼：MemberService 10300 表示請求成功並已發送驗證信；10301 表示信箱格式錯誤；10302 表示信箱不存在；10303 表示信箱未開通；10304 表示信箱已凍結；10305 表示密碼格式錯誤（忘記密碼）；10306 表示驗證逾時；10307 表示原始密碼格式錯誤；10308 表示新密碼格式錯誤；10309 表示原始密碼錯誤；10310 表示更新密碼成功。
- 修改暱稱：MemberService 10400 表示修改成功；10401 表示暱稱格式錯誤；10402 表示暱稱重複。
