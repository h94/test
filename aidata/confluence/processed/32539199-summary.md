## 摘要

本文件定義了一個新的 API 端點，用於查詢 GameTools 的操作日誌。用戶可透過 GET 請求，傳入日期 (路徑參數) 與遊戲類型 (查詢參數)，取得對應的操作記錄清單，每筆記錄包含時間、使用者、動作、動作類別等欄位。該 API 為 PriceCenterService 的一部分，有助於 AI 開發時了解操作日誌的存取方式與資料結構，但需確認此 API 在當前系統中仍有效。
