## 摘要

這份文件定義了自選股功能的 RESTful API 規格，包含對 FavoriteStockDTO 的 CRUD 操作以及單獨修改股票名稱的端點。對 AI 開發的幫助在於：當需要實作或串接使用者自選股管理功能時，可以直接參考此份 API 藍圖，了解請求方法、路徑、參數格式與回傳模型，確保前後端規格一致。

## 關鍵設計決策

- - 採用 RESTful 風格設計 API，以 HTTP Method (GET/POST/PUT/DELETE) 對應 CRUD 操作。
- 修改我的股票名稱 (API 5) 獨立於批次修改 (API 3)，提供單一欄位更新的端點，減少傳輸整筆資料的需求。
- FavoriteStockDTO 的 Value 欄位使用 List<string> 型別，允許一筆自選股記錄包含多個股票代碼（例如不同市場的同一標的）。
- API 中的 user 參數對應 Account 欄位，表明使用者身份識別採用帳號而非使用者顯示名稱。
