## 摘要

文件定義了前端第三方登入的技術實作規格，包含兩個後端 API：memberservice 的 loginforsite 與 pricecentersite 的 loginforsite。支援 Facebook、Google、Twitter、Discord 等第三方（部份未完成），API 參數包含 Finger、Account、UserName 及 Site。登入失敗可能因帳號凍結或 authkey hash 失敗。明確限制第三方登入使用者不得修改個人資料。

---

## 關鍵業務規則

- - 第三方登入成功時 response code 為 2000，message 為 success
- 登入失敗情況包含：帳號凍結、authkey hash 失敗（具體細節待人工確認）
- 第三方登入使用者不允許修改 profile（問題討論結論為「否」）
- 後端不需額外參數區分登入方式，已使用專屬 API 端點（/loginforsite）

---

## 關鍵設計決策

- - 採用專屬 API 端點區分網站登入，而非透過參數區分，以簡化後端辨識邏輯
- 第一階段優先整合 Facebook、Google、Twitter、Discord（v1 標記），其他平台依測試結果再決定
