## 摘要

此文件定義了來自 1XBET 的即時比賽統計項目（PlayByPlay）與內部中文名稱、ZBDigital 名稱及 AppSetting CODE 的對應表，涵蓋籃球、足球、棒球、冰球和美式足球五種運動。主/客隊的統計項目需分別加上 'Home' 與 'Away' 前綴。這份映射表有助於理解 PriceCenter 服務如何標準化不同數據源的欄位，以及 AppSetting CODE 所代表的統計類型，對開發即時比分或數據展示功能具有參考價值。

---

## 關鍵業務規則

- - 所有主隊相關的 PlayByPlay 統計項目，在命名時須加上 'Home' 前綴（例如 Home Dangerous Attacks）；客隊相關項目則加上 'Away' 前綴（例如 Away Dangerous Attacks）。
- 當對應的 ZBDigital 名稱為空時（如冰球項目中 64 號 CODE 無對應名稱），表示該統計類型尚未定義或暫不使用。
