## 摘要

本文件定義了 StockFilterService 新增的多個股票篩選規則，包含移動平均線突破與關係、均線交叉、成交量創新高、成交量股價高低點突破/跌破、MACD 穿越等。每個規則均提供可配置參數（如觀察天數、均線類型、均線週期、交叉方向），支援靈活的策略組合。這些規則是 AI 開發中實現股票篩選邏輯的直接依據，有助於理解功能邊界與參數結構。

---

## 關鍵業務規則

- - 規則 ID 22：最近 N 天內（N=1~10），股價突破或跌破指定週期（1~12,15,20,26,60,120,240）的均線，均線類型可選 SMA、EMA、WMA。
- 規則 ID 24：某條均線（可選類型、週期）位於另一條均線之上（比較關係由參數決定兩線位置）。
- 規則 ID 23：近 N 天內（N=1~10），兩條均線發生黃金交叉或死亡交叉，兩線可設定各自的類型與週期。
- 規則 ID 25：今日成交量創 N 天（N=1~10）新高。
- 規則 ID 26：今日股價突破過去 N 天中最大成交量當日的股價高點價格。
- 規則 ID 28：今日股價跌破過去 N 天中最大成交量當日的股價低點價格。
- 規則 ID 27：近 N 天內，MACD 的 DIF/OSC/MACD 線向上或向下穿越 0 軸，可指定線別與穿越方向。
