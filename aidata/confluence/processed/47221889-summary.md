## 摘要

此文件定義了一個機器學習預測服務的三個 REST API：預測比賽勝負（predict_1X2）、總分（predict_OU）、兩隊分數（predict_scores）。API 以 game_type 作為路徑參數區分球種，回傳包含場次識別、日期時間和預測值的陣列。模型每天零點訓練，結果快取供 API 讀取。對 AI 開發而言，這提供預測服務的輸入輸出合約與回傳格式參考，有助於系統整合與對接。

---

## 關鍵業務規則

- - 模型訓練於每日 0 點執行，預測結果存入快取供 API 查詢

---

## 關鍵設計決策

- - 預測 API 採用 /api/v1/predict_{類型}/{game_type} 的路徑結構，以 URL 路徑參數區分預測類型和球種
- 回傳格式為 JSON 陣列，每筆包含 gid、隊伍、日期、時間和預測值（勝負用字串，總分用整數，兩隊分數用整數陣列）
- 採用快取機制儲存預測結果，避免每次請求重新計算
