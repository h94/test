## 摘要

這份文件定義了聯盟與隊伍名稱多語系翻譯功能的技術規格。翻譯流程以 Translateservice 為核心，繁體/簡體中文互轉使用 NuGet 套件本地處理，英文與其他語系則轉發 Google Translate API。系統透過 XXL-JOB 每 30 分鐘定時觸發兩個 PUT API 執行批次翻譯。文件也記錄了開發時遇到的兩個問題：部分資料因 JSON key 格式錯誤導致直接跳過不翻譯，以及 Google API 僅限 PRD 環境使用導致本地端 XXL-JOB 無法執行聯盟隊伍翻譯排程。

---

## 關鍵業務規則

- - 聯盟翻譯 API 路由為 PUT /api/v1/system/leaguelanguage，無需傳入參數，無回傳內容
- 隊伍翻譯 API 路由為 PUT /api/v1/system/teamlanguage，無需傳入參數，無回傳內容
- XXL-JOB 每 30 分鐘觸發一次翻譯任務
- 支援語系：英文、繁體中文、簡體中文、日文
- 資料格式錯誤時（例如 key 為 zh-TW 而非正確格式），該筆資料直接跳過不翻譯，簡中資料也直接保留英文原文

---

## 關鍵設計決策

- - 繁體中文與簡體中文互轉使用 NuGet 套件本地處理，不呼叫外部 API，原因是降低延遲與外部依賴
- 英文翻譯至其他語系使用 Google Translate API，原因是翻譯品質較好，但限制為僅 PRD 環境可用
- 採用 XXL-JOB 定時任務而非即時翻譯，原因為翻譯需求非即時性且可批次處理，降低系統負載
- 翻譯流程透過 Translateservice 統一分派，不讓 PriceCenterService 直接處理翻譯邏輯，維持服務職責分離
