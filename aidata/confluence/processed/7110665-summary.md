## 摘要

本文為操作手冊，說明如何在 Telegram 上透過 BotFather 建立新的 Bot，取得 API Token 與 BotToken 後，再到內部管理頁面將 APIToken、BotToken、BotName 儲存至資料庫，以便 LiveChat 服務整合 Telegram Bot 功能。對 AI 開發而言，可了解 Telegram Bot 的註冊流程與必要參數，有助於實作 LiveChat 服務與 Telegram 的對接。
