這是一份 2021 年 6 月的前端站台問題追蹤記錄，整理了多個功能模組的 bug（如 FB 登入失敗、論壇 CSS 錯誤、賽事比分相反、暱稱更新後登出等）及對應處理方式。對 AI 開發的幫助在於，可了解過去系統曾出現的邊界交互問題與當時採用的解決方案（例如登入後用 postMessage 導頁、Service 排序聯盟、WordPress 設定影響論壇行為），有助於開發類似功能時避開已知陷阱。

## 關鍵業務規則

- - 發布文章或回覆後僅在有限時間內允許編輯或刪除；逾時後只能隱藏，不可刪除。
- 點擊「close all」按鈕不應將第一個聯盟縮小，應維持展開。
- 已登入使用者進入論壇時不應顯示登入頁，應直接導向論壇首頁。
- 更新暱稱後，右上角使用者資訊應立即反映變更，不應變成「登入／註冊」的未登入狀態。

## 關鍵設計決策

- - 登入成功時，由 iframe 內的頁面透過 postMessage 通知 Vue 進行路由導向，以解決先跳轉 404 再轉首頁的問題。
- 為了讓主要聯盟 (NBA, MLB) 顯示在列表最前面，由 Service 在送出資料時調整排序。
- 賽事合併（combine）問題導致 API 不送出未合併賽事，需確保 PRD 與 Local 環境的賽事資料一致性。
