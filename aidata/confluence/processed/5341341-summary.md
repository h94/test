## 摘要

本文档规定了 LivechatService 在用户非正常关闭页面（如直接关机）时的处理规则：必须将相关会话数据持久化到数据库，防止数据丢失。同时规划了定时清理 Redis 中无活动用户数据并同步到 DB 的功能，该功能计划通过 Service API 实现。这有助于开发时确保异常断线场景下的数据完整性和 Redis 资源管理。

---

## 關鍵業務規則

- - 用户非正常关闭网页（如不点击关闭按钮、直接关机）时，必须将关联的会话信息保存到数据库。
- 需要实现定时检测用户无活动状态，清空 Redis 中对应的用户数据并存入数据库，该能力通过 LivechatService 的 API 提供。
