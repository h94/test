## 摘要

本文档定义了为 SportKing 平台提供数据的 REST API（获取联盟日期赛事队伍分析）。API 返回队伍近期状态、交手记录等数据，并根据球种区分使用 ATS 或 M/L 盘口格式。同时明确了不应显示的联盟赛事规则、棒球先发投手的抓取数据源、赛程赔率数据源及部分联盟名称翻译状态，确保 API 返回数据符合 SportKing 的业务需求。

---

## 關鍵業務規則

- - API `GET games/analysis/{gameType}/{lid}/{date}/{gid}` 返回 `teamRecentStatus`（近期状态，含平均得分、失分、胜负记录）和 `gameTeamLastRecord`（包含 headToHead、last10Home、last10Away 三组历史记录）。
- `teamRecentStatus` 适用于篮球、美足、足球、棒球、冰球；其中篮球和美足使用 M/L 格式，足球、棒球、冰球使用 ATS 格式（参见 Response 示例和 Memo 字段）。
- 不显示的联盟赛事规则：SC 球种中，联盟中文名包含“奇幻赛事”或英文名包含“fantasy event”、“Fantasy Matches”的不显示；特别投注类联盟，英文名包含“- Props”、“- Proposition”、“-Special betting”的不显示；HL 球种中，名称包含“REGULATION TIME”的不显示。
- 棒球先发投手数据源：MLB 联盟从 covers.com 获取，其它联盟从 kkk.net 获取。
- 赛程列表主要赔率球头数据源：篮球、足球、棒球、冰球、美足统一使用 zba 数据源。
- 部分联盟的名称翻译需要确认，清单中的备注指示了状态（DONE/缺某个站台/只有特定站台等），例如“Brazil - LBF Women”已完成，“Netherlands Eredivisie Women Cup”缺少 ps3838 站点等。
