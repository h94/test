## 摘要

本文件記錄將至尊球王活動的百分比分數滿分從 10 分調整為 100 分的變更，並詳細定義 PriceBackEndService 與 MemberService 相關 API 的路由、請求與備註。包含了資料修復的 56 天限制、結算時間檢查、冠軍存在性檢查，以及每月 2 號執行週期結算的排程原因。對 AI 開發者而言，可據此更新計分邏輯與 API 的驗證規則，確保實現符合活動營運需求。

---

## 關鍵業務規則

- - 修復至尊球王參與者日期活動資料時（手動 API），若 type 為 PredictBet，只能修復 56 天前（含當天）的資料
- 結算至尊球王（系統自動結算 API）時，若當前時間未大於 supremecycle 的 endtime，禁止結算
- 結算至尊球王時，若排行榜資料沒有冠軍，禁止結算
- 週期結算預設在每月 2 號執行，因為週期結束日通常設在月底，需等待至隔月 1 號讓資料完整後再於 2 號進行結算
- MemberService 設定使用者活動資料的 API 中，gameType、lid、cid、account、type、data 皆不可為空
- MemberService 設定資料時，data 必須依照各 type 的格式序列化為字串，且不會寫入不在至尊球王週期時間內的資料

---

## 關鍵設計決策

- - 每月 2 號結算：週期結束日設在月底，為避免當日資料即時性錯誤，讓系統跑到隔月 1 號修復週期最後一天的資料後，於 2 號進行結算，確保資料正確性
