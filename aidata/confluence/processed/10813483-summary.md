## 摘要

定义了 PriceCenter 服务在 Redis 中存储游戏、赔率等实时数据的数据结构。包含四种主要的 Key 模式：游戏级缓存（GameType_GID）、站台游戏缓存（GameType_Site_SiteLID_SiteGID）、按日期站台索引（GameType_Date_Site）以及正在进行的游戏索引（GameType_Site_GamePlayNow），值均为 Dictionary 并用 JSON 序列化存储 BaseInfo、Match、Odds 等信息，为 AI 开发时理解实时数据的存取方式提供了结构指引。

## 關鍵設計決策

- - 使用 {GameType}_{GID} 等复合 Key 直接索引游戏主数据，将 BaseInfo、Match、Odds 等打包为 Dictionary 后 JSON 序列化，减少多次 Redis 查询
- 对于站台维度，Key 为 {GameType}_{Site}_{SiteLID}_{SiteGID}，包含更多站台定制字段（如 LeagueID、GameMode），表明存在游戏基础数据与站台数据的分离存储
- DateSiteGame 使用 Set 类型存储 {gameType}_{site}_{sitelid}_{sitegid}，实现按日期和站台快速查询当天的所有游戏
- GamePlayNow 使用 Set 存储正在进行的比赛 ID，支持快速获取当前活动游戏列表
