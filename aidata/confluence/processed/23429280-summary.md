## 摘要

文件描述如何開發一個 Chrome Extension 來擷取 1xbet 網站的比賽結果 HTML，並透過一組 class 名稱與圖片 src 的替換規則（例如將 'c-games__row' 改成 'G__row'、將特定圖片 src 設為 'False'）來簡化與淨化 DOM 結構，以利後續資料解析。

## 關鍵設計決策

- - 採用瀏覽器擴充套件直接存取 DOM 取得結果資料，避免反向工程或模擬請求。
- 對 HTML class 屬性進行標準化重新命名（如 c-games__row → G__row），降低後續解析對原網站命名規範的依賴。
- 將部分圖片的 src 設為 'False'（非必要資源）或設為 'True'（其他外部 URL），以區分資源類型或減少干擾。
