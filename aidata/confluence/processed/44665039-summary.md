## 摘要

本文件描述 SportKing 賽程資訊的即時更新設計。前端先透過 PriceCenterSite/Service 取得今日賽程列表，再與 WebSocket 連線接收滾球 (inplay) 資料的即時推送，以取代原輪詢方式。此外，每十分鐘呼叫 GET /game/live/{gameType} 拉取資料，主要用於提供多語系名稱 (NameMap) 翻譯。文件定義了 WebSocket 及 REST API 的規格與資料結構，可協助 AI 開發者理解賽事資料的取得流程與資料格式。
