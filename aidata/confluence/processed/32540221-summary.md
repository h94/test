## 摘要

本文件定義了一組股票相關的後端 API，涵蓋股票篩選（策略掃描）、券商進出明細、券商買賣超排行、股票基本資料、股票價格、多日收盤價以及回測任務的查詢/新增/更新。這些 API 主要提供給前端進行股票數據展示與篩選功能，參數與回傳格式均有具體範例，可用於開發股票篩選服務（StockFilterService）的接口對接與測試。

---

## 關鍵業務規則

- - 股票篩選 API（/stock/strategy）的 Date 參數非必填，未提供時預設使用最新日期。
- 股票篩選 API 的 First 參數非必填，預設值為 false。
- Strategy 陣列中每個物件包含 ID 與 Value，Value 格式依 ID 決定，例如 ID=1 使用 ['D','9','大於','90']。
- 券商進出 API（/stock/brokervolume）參數 Broker 為券商分點名稱陣列，非必填，可查多個分點。
- 股票價格 API（/stock/codedetail/price）若未帶 StartDate/EndDate，則回傳 DB 最新一筆資料。
- 取得最新 N 天收盤價 API（/stock/closeprice/{day}）day 可更換為任意天數，請求 body 為股票代碼陣列。
- 回測任務 GET API 返回尚未計算（status=0）的任務，供後續排程處理。
