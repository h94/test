## 摘要

此文件描述 ps3838 爬蟲的兩項需求變更：1) 新增抓取滾球盤 (inplay) 資訊，透過將 API mk 變數改為 2 來達成；2) 新增西班牙文 (ES)、法文 (FR)、德文 (DE) 語言支援，用於抓取不同語系的隊伍與聯盟資料。文件中具體說明了語言代碼與 inplay/pregame 組合方式（例如西班牙文籃球 inplay 為 ES-BK-FI），為 crawlerservice 或 crawlerflowservice 的開發與維護提供了直接的參數設定依據，幫助 AI 理解如何擴充爬蟲的多語言與即時資料抓取功能。

---

## 關鍵業務規則

- - 抓取 inplay 滾球盤時，需將 ps3838 API 的 mk 變數設為 2
- 新增語言代碼：西班牙文 (ES)、法文 (FR)、德文 (DE)
- 語言-運動-類型組合格式為 {語言代碼}-{運動代碼}-{FI/FU}，FI 表示 inplay，FU 表示 pregame，例：ES-BK-FI 為西班牙文籃球 inplay

---

## 關鍵設計決策

- - 沿用原流程，僅透過修改 API 參數 (mk 變數) 來區分滾球盤與非滾球盤，不改變整體爬蟲架構
- 採用統一的語系配置擴展方式，將新語言以固定 key (ES/FR/DE) 加入，避免日後增加語言時需要大規模重構
