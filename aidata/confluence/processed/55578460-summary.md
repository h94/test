## 摘要

本文件定義了如何從 footballant.com 爬取足球聯盟、隊伍及介紹資訊。透過 cloudscraper 繞過 Cloudflare 防護，使用正則表達式從網頁 HTML 中提取聯盟 ID 與隊伍 ID，並將資料儲存至指定路徑（支援中文/英文）。對 AI 開發而言，此文件提供了 crawlerservice 中 footballant provider 的具體抓取邏輯與檔案格式。

## 關鍵設計決策

- - 使用 cloudscraper 建立 session 以繞過 Cloudflare 驗證，僅需攜帶 User-Agent 標頭
- 採用正則表達式直接從 HTML 中匹配特定模式（如 <a href="/football-data/league/(\d+)" ...）來獲取 ID，不依賴 DOM 解析
- 檔案存放路徑依語言（zh/en）與資料類型（league/team）區分，便於後續處理

---

## 注意事項

- ⚠️ - ⚠️ 正則表達式高度依賴 footballant 網站當前的 HTML 結構，網站改版可能導致匹配失效
- ⚠️ 聯盟介紹並非所有聯盟都有，需處理不存在的情況
