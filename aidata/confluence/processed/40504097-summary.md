## 摘要

本文件定義 Cloudbet 賽事 API 回傳資料的解析規則，包含主客隊、聯盟、比賽時間、賽事狀態、分數、賠率等欄位的對應關係與取值路徑，並記錄一個已知問題（黃牌變紅牌後資訊消失）。對 AI 開發而言，可直接用以實作或維護 Cloudbet parser 的資料轉換邏輯。

---

## 關鍵業務規則

- - 主客隊名稱取自 home->name，並分別賦予 team_home 與 team_away
- 主客隊 ID 取自 home->key，賦予 team_home_id 與 team_away_id
- 聯盟名稱由 competition->name 作為 html_league，加上 competition->category->name 作為 country，組合後形成 league，league_id 取自 competition->key
- 比賽時間取自 startTime
- 賽事狀態對應：TRADING_LIVE -> 進行中；TRADING -> 賽前；RESULTED -> 結果；POST_TRADING -> 進行中(中場休息或暫停)
- 分數資訊：metadata->score 取得總比分；metadata->setScores->score 取得單節比分；metadata->basketballV3->remainingSecondsInPeriod 取得剩餘秒數
- 賠率資料：markets 下依玩法結構動態取值，需直接取 values；取出後 spread 為讓分，price 為賠率且需減 1，outcome 標示歸屬(H/A/O/U)，status 為 SELECTION_ENABLED 或 SELECTION_DISABLED
