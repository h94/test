## 摘要

本文檔描述了一個用 Golang 開發的韓國股票爬蟲，目標網站為 finance.daum.net。提供了兩個 REST API 介面的詳細規格：取得單一股票資訊（Get SingleStockInfo）和取得所有股票資訊（Get AllStockInfo），包含請求方法、Headers（必須帶入 referer）、參數及完整的 JSON 回應範例。回應欄位涵蓋股價、財務指標、外資比例、圖表圖片 URL 等，可用於後續資料解析與儲存。對於 AI 開發可依照此規格實作資料擷取與映射邏輯。

## 關鍵設計決策

- - 選用 Golang 實作爬蟲。
- 使用 finance.daum.net 的兩個 API 端點來取得韓國股票資料。
- 請求 Header 必須包含 referer，分別設定為對應的股票報價頁面。
- Get AllStockInfo API 支援 market=KOSPI 及 changes 等參數過濾，並以 sectors 結構彙整回傳。
