## 摘要

本文件定義了 GameSettingSite 中「站台延遲查詢頁面」所需的一個 API，用於取得指定站台與遊戲類型的賽事警報日誌。該 API 接受 gameType、site、siteGID 及時間範圍等參數，返回包含多個站台比對資料的警報記錄（如比分範圍錯誤）。日誌內容可顯示各站台對同一場比賽的比分，輔助檢測延遲或分數異常。此 API 由 gamesettingapiservice 提供，前端使用 Figma 設計呈現。
