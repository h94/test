## 摘要

本文件定義 PriceBackendService 的廣告資訊維護後台功能，包含取得廣告（支援多重選填過濾）、新增廣告（含圖片上傳）、編輯廣告（可選擇更新圖片）三支 API。廣告可分為 promotion（自家優惠）與 sponsorship（贊助廣告），並可指定點擊行為（新分頁、直接導頁或新視窗）。圖片上傳限制格式為 gif/jpg/jpeg/png 且檔案容量不超過 100KB。對 AI 開發的幫助：提供精確的端點、參數規格與業務約束，可直接據此生成 API 客戶端、自動化測試或模擬服務。

---

## 關鍵業務規則

- - 查詢廣告時 query 參數 title、enabled、startTime、closeTime、createby 皆為選填，createby 可為 'promotion' 或 'sponsorship'。
- 新增與編輯廣告的 action 欄位僅接受 'blank'（新分頁）、'location'（直接導頁）、'window'（新視窗）。
- 上傳廣告圖檔副檔名必須為 .gif / .jpg / .jpeg / .png，且檔案容量不得超過 100KB。
- 時間欄位 StartTime 與 CloseTime 採用 Unix timestamp（秒）。
- 編輯廣告時必須提供 ID，且可選擇是否上傳新圖檔（file 為選填）。

---

## 關鍵設計決策

- - 廣告查詢 API 設計為 GET /pricebackendservice/api/advertising/{type}，透過 type 路徑參數區分 promotion 或 sponsorship，並以 query string 進行過濾，降低路由數量。
- 新增與編輯使用 POST，並以 multipart/form-data 同時接受 JSON 與檔案上傳，避免多次請求。
- 回傳格式統一使用 Code/Message 結構（Code 10000 表示成功），與既有系統風格一致。
