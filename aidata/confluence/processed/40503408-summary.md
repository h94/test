## 摘要

本文件定義 StockKing 訂閱付費機制的技術設計，包含金流串接綠界、方案列表 API、回調處理，以及個人設定頁顯示訂閱狀態與中斷續約功能。明確列出付款頁面路由、綠界回調參數與回應格式、方案列表資料結構，可作為 paymentservice 或相關服務實作 API 的規格基礎。

---

## 關鍵業務規則

- - 未登入用戶點擊訂閱時，須導向登入頁按鈕；依會員階級控制購買按鈕顯隱
- 個人設定頁須顯示客戶階級、訂閱日期、到期日、使用天數、倒數天數，並根據階級提供「訂閱導向」或「中斷續約」操作
- 訂閱紀錄頁須顯示客戶階級、訂閱日期、付款金額
- 付款頁面入口為 /home/index?sub={方案編號}&ut={user token}
- 綠界回調成功時，後端需回應字串 "1|OK"；失敗時回應 "2|FAIL"
- 綠界回調中 CustomField1 欄位攜帶 JSON，包含 account、subid、ut 等資訊，用於辨識訂閱用戶與方案
- 方案列表 API 回傳欄位需包含 ID、SubTitle、SubRank、Name、Amount、StartDate、EndDate、Enabled、SubType、SubTypeCount

---

## 關鍵設計決策

- - 選擇綠界（ECPay）作為第三方金流，回調端點為 stockapi.zbdigital.net/api/v1/ecpay/callback
- 利用綠界的 CustomField1 傳遞自定義業務參數（帳號、方案 ID、user token），於回調時解析以完成訂閱開通
- 方案列表以 GET /api/v1/payment/plans 提供，透過 StartDate/EndDate 控制方案有效期間
- 個人設定沿用現有 API /auth/users/settings/${token} 獲取使用者資料，擴充顯示訂閱狀態而不新增獨立端點
