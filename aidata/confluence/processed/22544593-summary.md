## 摘要

本文件描述 PriceCenterService 中用于生成游戏结果与多语言联盟/队伍映射静态 JSON 文件的设计。API 通过 GET /api/v1/system/gameresult 接收日期参数，输出两个 JSON 文件：GameResult.json（GameOutputDTO 结构）和 LanguageMap.json（嵌套 Map 结构），文件按日期和球种分目录存储。前端直接读取 nginx 暴露的静态文件，无需额外读取 API。联盟队伍映射为避免一次性加载过大，按球种和天分片。

## 關鍵設計決策

- - 采用静态 JSON 文件输出而非动态 API，因为前端 .Net 可以直接读取文件，降低服务端请求压力。
- 联盟队伍映射数据按球种（BS、BK、SC）和日期分文件，解决一次加载所有数据过大的问题。
- 文件通过 Docker 卷映射暴露给 OpenResty（nginx），由 /usr/local/openresty/nginx/html/downloads 提供静态访问，路由格式为 {日期}/{球种}/{档名}。
- 输出两个独立文件：GameResult.json 存储比赛结果，LanguageMap.json 存储多语言映射，两者类型不同，解耦管理。
