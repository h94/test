## 摘要

本文件定義 Playbet 平台的爬蟲實作細節，包含賽前/賽中/賽果資料的 API 端點（如 sport.playbet.io/api/v2/matches）、查詢參數（limit, match_status, sport_key, sort_by, start_from, start_to, sport_type）、回傳 JSON 欄位對應（id, tournament, competitors, start_time, 分數, 賠率等），以及球種代碼對照表（basketball→306, baseball→314 等）。同時說明了語系參數 (language=en) 與賠率需要除以 1000 的轉換規則。對 AI 開發爬蟲服務時，可直接參考本規格進行 API 請求構造與資料解析。

## 關鍵設計決策

- - 採用 Playbet 官方 API v2 端點 (sport.playbet.io/api/v2/matches) 獲取比賽資料，避免頁面解析，提高穩定性。
- 透過 HTTP query parameters 實現篩選與分頁：limit 控制每頁筆數、sport_key 指定球種、match_status 過濾比賽狀態（0:尚未開始, 1:inplay, 2:stopped, 3:close）、start_from/start_to 指定時間範圍。
- 使用多欄位排序 (sort_by) 後取 limit 筆，優先順序為 tournament.priority 升冪、start_time 升冪、bets_count 降冪。
- 賽中位置區分常規運動 (sportType=regular) 與電子競技 (sportType=cyber)。
- 賠率數值來自 outcomes 中的 odds 欄位，原始值需除以 1000 得到實際賠率。
- 語系固定設為 en (language=en)。

## 注意事項

- ⚠️ - ⚠️ match_status 參數值 3 定義為 close，但有標注問號，需人工確認其語意。
- ⚠️ sport_type 參數值 'reguler' 應為 'regular' 的拼寫錯誤，程式實作時建議兼容兩種寫法。
- ⚠️ 分數欄位路徑 data[]["statistics"]["period_score"][]["home"] 中的雙層陣列索引未詳列，可能因不同運動而有差異。
