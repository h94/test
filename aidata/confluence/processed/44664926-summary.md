## 摘要

定義 NBA 球員數據爬取的技術流程：先調用 API 獲取所有球員基本資料以取得 ID，再逐一調用 ID 獲取詳細數據（基本、進階等），最後將每筆數據包裝成包含 gametype、source、send_time、provider_name、datas（含 Record）的 JSON 訊息發送至 Kafka。目前僅針對 Regular Season。此設計便於後續擴展數據欄位，並提供了具體的輸出格式範例。

## 關鍵設計決策

- - 採用兩階段調用：先獲取所有球員 ID，再逐個請求詳細數據，使未來擴展數據欄位時不影響 ID 獲取邏輯。
- 僅處理 Regular Season 數據，不包含季後賽或其他賽事類型。
- 最終數據通過 Kafka 異步發送，解耦下游消費者。
- 輸出格式固定，datas 區塊包含 Site、SiteID、Year、League、Name 及 Record，Record 內為各項統計數值。
