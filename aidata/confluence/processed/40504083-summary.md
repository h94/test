## 摘要

本文件定義了 kkk 爬蟲解析器的資料結構，包含比賽資訊（gid、日期、球種等）和賠率資料（主/客/和、盤口、賠率）的欄位索引，並列出棒球、籃球、冰球、足球、美式足球等球種的完整玩法代號對應表，例如讓分、大小、獨贏等在 pre-game 與 in-play 狀態下的代碼。對 AI 開發的幫助是提供解析外部資料時所需的欄位映射與玩法代號標準，確保資料轉換的一致性。

---

## 關鍵業務規則

- - 賠率類型欄位 type 的值定義：H 表示主隊，C 表示客隊，M 表示和局（棒球、美式足球等），足球另有 N 表示平局。
- con_mode 索引 0 為美式盤口球頭，con_mode_tw 索引 1 為台式盤口球頭。
- io 索引 6 為港式賠率，iou 索引 7 為美式賠率。
- 棒球全場讓分玩法代碼：pre-game 使用 R，in-play 使用 RE；全場大小 pre-game 使用 OU，in-play 使用 ROU。
- 足球波膽玩法使用特定兩位數編碼代表比分，例如 '10' 代表 1:0，'OT' 代表其他比分。
- 賠率呈現方式使用 JSON 結構，例如 {"HA":{"1.5":{"H":"1.2", "T":"2", "A":"123"}}}，其中 HA 可能代表盤口類型，1.5 為讓分數，H、T、A 分別對應主、總、客隊賠率。
