## 關鍵設計決策

- - 選擇先呼叫 API 取得「全部站台」與「已停用站台」兩份資料，推測是為了在同一個畫面中對比顯示，讓使用者知道哪些站台已停用，避免誤操作。（需人工確認具體互動設計）
