## 摘要

本文件描述「球王」專案中，在社群內新增版主預測推單功能。版主可在私人群組中選擇賽事與玩法進行預測，系統透過特殊 ChatType 推送預測單訊息至聊天室，一般使用者可查看版主推單內容。重點包括：版主權限控管、預測流程（選球種/聯盟/賽事/玩法）、已預測玩法不可重複、儲存後用回傳 ID 發送特定訊息，以及手機版 UI 呈現方式。對 AI 開發有助於理解版主推單的業務操作規範與前後端互動邊界。

---

## 關鍵業務規則

- - 預測功能僅限版主身份，非版主不顯示預測按鈕
- 只有在私人群組中才顯示所有操作按鈕（非私人群組無任何按鈕）
- 取得可預測賽事時，需根據球種、聯盟進行過濾，設計師提問是否需有熱門選項（待確認）
- 選定賽事後，API 應回傳該賽事可預測的玩法與賠率資料
- 版主已預測過的玩法不得再次預測，後端需根據版主過往預測單判斷哪些玩法不可選
- 預測確認送出後，需呼叫 API 儲存預測資訊，接收回傳的預測單 ID
- 儲存成功後，須以回傳的預測單 ID，透過 GameLiveService 送出特殊 ChatType（predict?）的訊息
- 看版主推薦功能需傳入版主與 user 身份（用於判斷解鎖狀態），呼叫 API 取得預測資料
