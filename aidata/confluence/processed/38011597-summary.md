## 摘要

這份文件記錄了 StockSite 的會員模組 API 設計，包含註冊（含驗證）、登入、第三方登入、登出、使用者資訊查詢、搜尋次數管理、密碼處理等端點，並規範帳號與密碼格式、token 驗證與 Redis 快取策略。另包含 StockRuleService 的交易日查詢端點。對開發 memberservice 的 API 實作與規則校驗有直接幫助。

---

## 關鍵業務規則

- - 帳號格式：4~10 個中英數字符
- 密碼格式：6~12 個中英數及特殊符號
- 會員註冊後需透過驗證信驗證，驗證連結使用 validateToken
- 第三方登入直接建立帳號（帳號為第三方帳號），密碼隨機生成，不經過註冊驗證流程
- 所有會員操作必須先使用 token 取得會員資料

---

## 關鍵設計決策

- - 採用 token 機制進行會員身份驗證，所有操作需要 token
- 會員登入成功後，將會員資料快取到 Redis，以加速後續查詢
- 針對股票搜尋次數進行計數，提供獨立的 actionType 來區分 broker、stock、backtesting 等操作
- 修改現有 API 路由，可能為了區隔股票模組而加 /stock/ 路徑
