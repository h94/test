## 摘要

这份文件描述了为支持前端 RWD（响应式网页设计），多个股票数据 API 的响应结构进行了精简，移除了移动端或 RWD 视图中不需要的字段（如开盘价、最高价、成交量等），但仍保留在响应中（值设为 0 或 null）。对于 AI 开发，这意味着在调用这些接口时，不能假设所有字段都有有效值，必须根据实际业务显示需要来选择性使用字段，且警示相关的 reason 字段被新增用于展示预警原因。

## 關鍵設計決策

- - API 响应字段精简：为配合前端 RWD 设计，/v1/stock/stockdata 和 /v1/stock/stockdata/warning 等接口的响应中，部分价格与财务指标字段（openPrice, highestPrice, lowestPrice, volume, per, pbr 等）不再提供有效数据，取值固定为 0，前端不再依赖这些字段进行渲染。
- 字段保留但置零：虽然部分字段不再使用，但并未从 JSON 响应中移除，而是将其值设为 0 或 null，以保持 API 响应结构的向后兼容性（需人工确认兼容性意图）。
- 新增警示原因字段：在 warning 相关接口的响应中，新增了 `reason` 字段用于返回股票警示的具体文本原因。
- 路径参数差异化：/v1/stock/stockdata/warning/{code} 与 /v1/stock/stockdata/{code} 的 New API Response 部分在文件中未明确列出，结合上下文推测其变更模式应与上述接口保持一致，即仅保留核心字段并新增/保留 reason 字段（已有 AI 推断，需人工确认 spec 细节）。
