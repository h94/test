## 關鍵設計決策

- - 采用两种渲染模式：通过 script 标签中 idToToken 参数触发预先渲染；未传参数时通过函数调用按需渲染。
- 由 API 返回已组装好的 HTML 和 CSS，避免前端自行拼装，降低集成复杂度。
- idToToken 为非必填参数，用于决定是否需要对指定元素自动渲染。
