## 摘要

文件定義 ESPN 爬取 30 天內賽事資料的技術方案，包括目標球種（BS、FL、BK、HL）與對應 API 端點，並說明將由舊框架轉移至新框架，同時新增未來賽事爬取能力。提供了不同球種聯盟的 main 與 other API 結構與日期參數格式，直接可用於開發爬取邏輯。

---

## 關鍵業務規則

- - 爬取時間範圍固定為 30 天內的賽事資料。
- 僅處理四種球種：BS（mlb）、FL（nfl）、BK（nba）、HL（nhl）。
- 每種球種使用指定 API：BS、BK、HL、FL 使用 main API，SC（足球）使用 other API，但 SC 未列入目標球種，僅作參考。
- API 日期參數格式為 YYYYMMDD（例如 day=20230323）。

---

## 關鍵設計決策

- - 決定改用新框架取代舊有實作，以提高可維護性。
- 新增爬取未來賽事 API 以擴展功能。
- 統一套用 main API 端點處理多數北美運動，足球例外使用獨立 other API。
