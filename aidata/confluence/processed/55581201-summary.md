## 摘要

本文件定義了從 HGA 足球數據提供商 V2 獲取賽前、賽中、賽果數據的 API 請求方式與參數。賽前需透過三步驟（取得聯盟列表→取得比賽簡易資訊→取得單場詳細資訊）；賽中可直接請求 live 比賽列表；賽果則分為主賽果頁（完整 HTML 丟 Kafka）與單場賽果（僅擷取 var gdata、var heads 陣列），且需從主頁 HTML 判斷比賽類型（FullTime 或 Cornor）。開發者可依據此文件實作爬取 HGA 數據的標準接口。

---

## 關鍵業務規則

- - 賽果主頁的完整 HTML 須直接發送到 Kafka 的 result topic。
- 單場賽果僅需提取頁面中 var gdata 和 var heads 陣列的資料，發送到 Kafka 的 singleresult topic。
- 單場賽果必須附帶 page type 資訊，其值為 FullTime 或 Cornor（角球）。
- page type 由主賽果頁 HTML 中是否包含「角球數」字樣來判斷，若出現該字樣則為 Cornor，否則為 FullTime。
