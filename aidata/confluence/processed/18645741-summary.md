## 摘要

這份文件定義了 PriceCenterSite 前端站點的 .NET Core Auth API，提供登入、註冊、忘記密碼、修改個人資料等會員相關操作的端點。除 Token 驗證 (AuthCheck) 於本地執行外，其餘功能均轉發至後端 Member Service 處理。對 AI 開發的幫助在於釐清前端與會員服務的介面合約，包括請求/回應模型與雙階段密碼重設流程，避免直接呼叫內部服務時參數混淆。

---

## 關鍵業務規則

- - 忘記密碼流程分為兩階段：第一階段 POST /auth/request_pwd 僅需 account 與 finger；第二階段 POST /auth/forget_pwd 需提供 password、finger 及由第一階段取得的 token。
- 註冊後必須透過 POST /auth/validate 提交 token 與 finger 完成驗證。
- 修改密碼 (UpdatePassword) 與修改使用者暱稱 (UpdateUserName) 必須在登入狀態下進行，請求需附上有效的 token 與 finger。
- 所有請求 Header Content-Type 必須設定為 application/json; charset=utf-8。

---

## 關鍵設計決策

- - AuthCheck 端點不呼叫外部服務 (Call Service = False)，直接於 Auth API 本地驗證 Token 有效性，以降低延遲並減少對 Member Service 的依賴。
- 登入、註冊、密碼重設等業務操作全數委派給 Member Service，Auth API 僅作為前端適配層，遵循微服務邊界。

## 注意事項

- ⚠️ - ⚠️ 文件最後修訂於 2021/05/10，距今已超過兩年，可能部分 API 端點、參數或流程已變更，需人工確認當前實作狀態。
- ⚠️ AuthCheck API 說明文字提到驗證 Cookies 中的 Token，但 Request 範例卻為 JSON body，存在描述不一致，實際傳輸方式需釐清。
- ⚠️ Base API URL 為 localhost:5000，僅供開發環境參考，正式環境需置換為實際域名或閘道位址。
