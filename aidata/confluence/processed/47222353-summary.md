## 摘要

本文件描述為 au8tw 爬蟲擴充賽後比分與各局比分抓取功能。技術實作上透過新增獨立 thread 取得賽果，先登入獲取 cookies/headers 後調用兩個 API（取得 events 及 leagues），再由 Parser 解析不同球種的比分結構並更新資料庫。開發時特別需注意 BS、HL、ES、TN、SC 等球種的比分格式差異及 GID 組成規則，以正確解析並存入 DB。

---

## 關鍵業務規則

- - 賽果 GID 由 gtime、gdate、league、team 四個欄位組合而成，作為唯一標識。
- 球種 BS 一場比賽會有三種結果，應忽略 (Hits+Runs+Errors) 和 (15 Games) 的資料。
- 球種 HL 有兩個分數：regulation time 和 OT included，需要分別處理。
- 球種 ES 在站台上無顯示，但仍可透過 API 代碼取得比分。
- 球種 TN 的總比分放在 Sets 中，各 SET 比分放在 Games 中。
- 球種 SC 的角球比分會另外獨立存放，需特殊處理。
- 球種代號對應表請參考 Confluence 頁面 ID 44665323。

---

## 關鍵設計決策

- - 採用獨立 thread 來獲取賽果資料，避免阻塞爬蟲主流程。
- 先進行登入取得 cookies 和 headers，再呼叫目標 API，以維持有效會話狀態。
- 使用 GID（gtime+gdate+league+team）作為比賽唯一識別碼，便於後續比分匹配與 DB 更新。
