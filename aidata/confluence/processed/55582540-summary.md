## 摘要

本文件定義新版社群討論區 API，包含依球種新增文章、回文、取得文章與回文分頁列表、取得分類標籤、取得關注賽事等功能。文章分為一般討論與賽事推薦兩種，賽事推薦文章需帶 PredictContent 並於轉預測單時附帶文章 ID。文章與回文均採分頁機制（每頁 20 筆），並提供多種篩選條件。此設計為球王社群改版的核心 API 規格，直接指導 communityservice 的開發。

---

## 關鍵業務規則

- - 文章類型分為 normal（一般討論）和 predict（賽事推薦），若為一般文章，PredictContent 須為 null 或不帶。
- 新增文章成功後會回傳完整的文章資料，包含 id、圖片路徑、按讚數等。
- 討論區文章列表與回文列表皆為分頁形式，每頁固定 20 筆。
- 取得球種文章頁面（GET community/{gameType}/article/page）使用 index 參數（文章建立時間戳）進行游標分頁。
- 取得回文頁面（GET .../comment/page）使用 page 參數，初始不請求時預設為第 1 頁。
- 球種分類 API（取得 hashtags）需考慮語系，且快取時間為 15 分鐘。
- 賽事預測文章轉換成預測單時，需將文章 ID 一併加入預測單的 args 中。
- 新增回文時，若為回覆其他回文，需帶入 RespCommentID，否則 respComment 為 null。
- 編輯文章時，可更新 ArticleType 與 Content。
- 刪除文章需提供 authKey 驗證。

## 關鍵設計決策

- - 賽事推薦文章功能在本次迭代中略過（PredictContent 先不用帶），未來補上。
- 文章與回文的點讚系統移到下一個 sprint 完成，本次不實作。
- 討論區顯示的聯盟賽事只顯示特定幾個預先定義的聯盟（如足球五大聯賽、NBA、MLB、CPBL、NPB），並非全部賽事。
- API 路由設計遵循 RESTful 風格，以 gameType 區分球種，並將文章、回文等資源嵌套在社群路徑下。
