## 摘要

本文件為 ps3838 爬蟲功能擴充的技術需求，目標是新增 AF 和 HL 兩種球種的資料爬取。文件提供了四個具體的 API 端點，分別對應足球與籃球的今日及早盤數據，做為爬蟲的資料來源。這份文檔對 AI 開發的幫助在於明確了需要接入的數據接口 URL，以及透過參數區分球類(sp)和即時/早盤(mk)的規則。

## 關鍵設計決策

- - 數據源選用 ps3838 的 compact/events API，透過參數 sp(運動種類) 和 mk(即時/早盤) 過濾特定數據。
- 本次擴充僅針對足球(sp=4)和籃球(sp=29)進行開發，並未涵蓋其他運動項目。
- 讀取今日數據的 API 參數設定為 mk=1，早盤數據設定為 mk=0。
