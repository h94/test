## 摘要

這份文件是前端 UI 改進與 bug 修正的待辦清單，涵蓋版權資訊、免責連結、間距調整、策略展開邏輯、回測狀態顯示、刪除條件後未刷新、API 失敗提示、gmail 登入顯示欄位等多項具體規則。可作為前端開發與測試的驗收標準，確保使用者體驗與功能正確性，並幫助 AI 開發了解邊界處理要點。

## 關鍵業務規則

- - 首頁底部版權信息需顯示「ZB Digital CO., LTD」，與 LOGO 一致。
- 需放置免責聲明的連結，內容指向指定頁面。
- 手機版與電腦版均需加入操作說明與免責聲明的連結，並在文件區與功能區之間加一條白線分隔。
- 若使用者有儲存的策略，登入後第一次進入該畫面須預設展開該策略。
- 手機版「新增回測」按鈕應改名為「新增回測」。
- 文件類型頁面須提供「回上一頁」的按鈕或圖示。
- 按鈕和下拉選單的間距需拉開，避免誤點，策略新增修改頁面也適用。
- 需提供按鈕可直接跳轉至「新增我的券商」畫面。
- 連結的上下間距須加大，以改善點擊體驗。
- 使用 gmail 登入時，應顯示 gmail 的 email account 內容，不可顯示 gmail id。
- 刪除條件後儲存並重新整理，策略條件仍會出現，此 bug 需修正（一般帳號與 gmail 登入皆會發生）。
- UI 呼叫過水 API 失敗時，需跳出訊息提示使用者「網路不穩，請重新整理」。
- 回測仍在測試中時，勝率欄位應顯示減號（-）而非 0%。
- 點擊 checkbox 本體無反應，但點擊旁邊會跳出需高級會員的訊息，需修正點擊區域。
