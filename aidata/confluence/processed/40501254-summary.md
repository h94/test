## 摘要

本文件定义 CrawlerAgent 如何从 HGA 数据源整合比赛结果信息，产出统一的 result_info JSON 结构。核心内容是约 60 种比赛事件类型的中英对照码表（涵盖进球、角球、罚牌、点球大战等）以及按时间区间划分的例子。同时记录了5项已知的赔率/比分修正规则（如 Odd/Even 赔率需扣本金、O-Spread 需还原原始球头等），用于确保 result_info 输出格式正确、与站台显示一致。对 CrawlerAgent 开发而言，这篇文档提供了完整的 result_info 字段映射表和需要特殊处理的数据清洗规则。

## 關鍵設計決策

- - result_info JSON 结构整合多项比赛事件，用英文描述作为 key（如 'First Goal Method', '1st Corner'），中文作为站台显示文案
- 时间区间字段用中文区间值作为 key（如 '0~15min', '15~30min'），值为两队在该区间的进球数组 '[主队得分, 客队得分]'
- 盘口名称 O-Spread 应还原为原始球头（Original-Spread），而非直接复用 Spread 值，以保留站台原始球头与开盘方向信息
- 赔率 Odd/Even 原始数据含本金，输出时需扣除本金再写入 result_info（例：2.04→1.04, 1.84→0.84）
- 赔率值为 0 时，若该选项不应存在则直接不送；若之后改为 0 则送 -1 表示关闭
- 角球/罚牌的第N个事件（如第14个角球）若无事件则输出 '沒有角球' 或类似中文描述
- 上半/下半场时间区间映射：AGM(0~15min)/BGM(15~30min)/CGM(30~45min) 为上半场，DGM(45~60min)/EGM(60~75min)/FGM(75~90min) 为下半场
- 加时赛时间区间映射：TARU(0~5min)/TBRU(5~10min)/TCRU(10~45min) 为加时赛上半场，TDRU/TFRU 为加时赛下半场（具体起止时间有重叠，需人工确认边界）

## 注意事項

- ⚠️ - ⚠️ 时间区间 5~10min 出现在加时赛(TBRU)和常规时间(需确认是否有常规赛对应区间)的码表中，但未在 result_info 示例中出现，需人工确认其使用场景
- ⚠️ 点球大战回合的中文 key 带有 '主点'/'客点' 字眼（如 RSCA 为 '1st Penalty Shootout #客点'），但 JSON key 统一使用 '1st Penalty Shootout'，需确认是否需要区分主客场
- ⚠️ 'Corner-Full Time', 'Corner-Half Time', 'Card-Full Time', 'Card-Half Time' 四个统计字段仅出现在表格中，但未在最终的 result_info JSON 映射表(问题下方的映射 JSON) 里定义，需人工确认是否纳入
- ⚠️ 部分翻译名称与常见用语有差异（如 'Qualifying Method' 译为 '晉級方法'、'Winning Method' 译为 '獲勝方法'），需要在 AI 解析时注意多语言一致性
- ⚠️ 文档最后更新于 2022-08-23，已有超过 2 年历史，可能已有后续变更，建议与当前爬虫代码对照确认
