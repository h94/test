## 摘要

本文件說明 1xbet 站點需新增支援的歐洲語系清單，並定義如何透過 POST API 上傳聯賽與隊伍的 name map 標準化資料。內容包含支援的語系列表（移除簡體中文）、API 端點及 JSON 請求格式（區分聯賽與主客隊欄位）。此資訊可協助開發正確構建爬蟲名稱對應請求，確保多語言名稱正確映射。

---

## 關鍵業務規則

- - 1xbet 站點必須支援以下語系：en-US, ja-JP, ko-KR, zh-TW, vi-VN, th-TH, es-ES, fr-FR, de-DE, pt-PT，不再支援 zh-CN（以刪除線標示移除）。
- 名稱映射必須透過 POST https://ls.zbdigital.net/api/site/namemap 提交，請求格式為 JSON 陣列，每個物件需包含 GameType、Site、SiteLid（聯賽 ID）、CountryCode、Name；若有 SiteTid 則表示該筆為球隊名稱（主隊或客隊），無 SiteTid 則為聯賽名稱。

---

## 關鍵設計決策

- - 採用統一的 name map API，將聯賽與球隊名稱透過同一陣列區分（有/無 SiteTid），簡化客戶端對應邏輯。
- 移除對簡體中文的支援，僅保留繁中及其他歐洲語系，可能因應 1xbet 市場策略變更。
