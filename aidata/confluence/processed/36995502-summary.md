## 摘要

本文件定義了排行榜後台系統的架構，使用中繼層 Proxy 將前端請求轉發至 memberservice 和 leaderboardservice。提供了排行榜使用者帳號管理（新增、查詢、修改密碼、登入）與排行榜內容管理（新增、查詢、更新、模板）的 API 端點對應，以及 Embedded JS 端點用於前台嵌入排行榜內容。後台前端採用 Vue3 TypeScript，中繼層與後端 API 服務共用 Nuget 套件以共用模型。對 AI 開發而言，此文件明確了後台 API 路由設計、服務依賴，以及取得使用者列表時的權限控制規則。

---

## 關鍵業務規則

- - 取得排行榜使用者時，須傳入 account 參數以驗證是否為管理者；非管理者帳號不能取得所有使用者列表及其他使用者的密碼。

---

## 關鍵設計決策

- - 採用中繼層 Proxy 模式統一轉發 API 請求至 memberservice 和 leaderboardservice。
- 管理後台前端使用 Vue3 TypeScript 開發。
- 中繼層與後端 API 服務共用 Nuget 套件，以減少重複程式碼並共享資料模型。
- Embedded JS 端點直接回傳 HTML 字串，用於客戶端嵌入排行榜內容，而非讓前台直接呼叫 API。
