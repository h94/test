## 摘要

本文描述為 Tonybet CrawlerAgent 新增三個歐洲語系（西班牙文、法文、德文），並定義一個用於寫入名稱映射的 API。API 接收一個 JSON 陣列，每個物件包含 GameType、Site、SiteLid/SiteTid、CountryCode 和 Name，透過 POST 發送到 ls.zbdigital.net/api/site/namemap，用於建立不同語系下的聯賽與隊伍名稱對應。對 AI 開發而言，這份文件說明了 CrawlerAgent 如何將原始爬取的名稱根據語系和站點儲存到名稱映射服務。

## 關鍵設計決策

- - 使用統一的 API 端點 (ls.zbdigital.net/api/site/namemap) 來處理聯賽與隊伍的名稱映射，不拆分不同端點。
- 透過 JSON 陣列批量提交多筆映射資料，每筆物件包含 GameType、Site、ID（SiteLid 或 SiteTid）、CountryCode 和 Name。
- 聯賽名稱只帶 SiteLid，隊伍名稱則同時帶 SiteLid 和 SiteTid，透過欄位區分對象類型。
