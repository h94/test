## 摘要

這份文件描述 GameSettingSite 服務中人工停啟用站台 API 的設計。此 API 會調用 GameSettingService 來執行站台的啟用或停用，同時從 GameDataModules 讀取各站台支援的球種資訊，供前端顯示。API 的請求模型為 SiteStop，包含公司代碼 (Company) 與站台清單 (Sites)。
