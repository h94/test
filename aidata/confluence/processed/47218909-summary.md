## 摘要

此文档定义了若干新增的 SportKing 相关 API，包括伤兵列表、联盟收藏、球队/球员技术统计、NBA 积分榜、NBA 赛事分析以及联盟时段赛事查询。每个 API 详细描述了路由、HTTP 方法、参数格式和响应结构，可直接作为 pricecentersite 服务的接口开发参考与 AI 功能调用规范。

---

## 關鍵業務規則

- - 伤兵 API（injury/getinjurylist）支持三种查询模式：仅提供 gtype、date、league、team 则返回单一球队名单；提供 gtype、league、date 则返回指定联盟所有球队名单；仅提供 gtype 和 date 则返回该日所有球队伤兵信息。
- 联盟收藏 API（collect/getleaguemap/{gtype}）使用 POST，请求体为联盟 ID 数组，返回每个 ID 对应的联盟多语言名称映射。
- 球队技术统计（game/siteleagues/teams/players/{gametype}）查询需提供 site、date、league、team 参数，返回球员统计数据，record 字段为 JSON 字符串，包含 MIN、FGM、FGA 等指标。
- 球员技术统计（game/siteleagues/players/records/{gameType}）按球员 siteID 查询，返回该球员的赛季统计数据，结构与球队技术统计类似。
- NBA 积分榜（analysis/overviews/nba）按日期查询，响应按东/西分区及其下属分组组织，包含球队胜负、连胜/连败、近期赛果数组。
- NBA 赛事分析（analysis/headtohead/nba）需传入 date、gameID、leagueID，返回主/客队近期状态（得分均值、胜负序列）以及历史交锋和主客队近10场记录，其中包含盘口信息（ATS、总分）。
- 联盟时段赛事（games/{gameType}/{lid}）通过 startDate、endDate 获取指定联盟内赛程，返回赛事 ID、主客队名称与 ID、比赛日期时间、状态等。
