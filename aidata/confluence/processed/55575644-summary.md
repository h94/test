## 摘要

這是一份 Sprint 139 的開發進度同步記錄，列出了球王 App 共 17 個功能模組的完成狀態，其中賽事內頁 websocket 串接、個人資料編輯大頭貼、高手榜優化、個人預測 API 拆分為本次 Sprint 的主要交付項目。文件後半列出 12 月 1 日為止現有頁面仍需修改的項目，包含設定頁的排序邏輯、賠率切換、莊殺標準顯示需求等，可作為 AI 理解球王 App 功能邊界與目前開發成熟度的參考。

## 關鍵業務規則

- - 個人預測頁的今日推薦與歷史推薦需拆分成兩支獨立的 API
- 高手榜前三名下方需新增「看預測」按鈕
- 高手榜獲利點數需加上千位分隔符號
- 個人預測頁關注人數右側需新增莊殺圖示
- 個人預測頁（查看自己）需在今日推薦/歷史推薦按鈕左側新增本期莊殺標準顯示
- 賽事排序規則：聯盟排序為 已收藏賽事（聯盟名稱＞開賽時間）→ 熱門聯盟（聯盟名稱＞開賽時間）→ 普通聯盟（聯盟名稱＞開賽時間）
- 賽事排序規則：時間排序為 已收藏賽事（聯盟名稱＞開賽時間）→ 熱門聯盟（聯盟名稱＞開賽時間）→ 普通聯盟（開賽時間）
- 設定頁面需提供切換顯示賠率的功能

## 關鍵設計決策

- - 個人預測的今日推薦與歷史推薦拆分為兩支 API，而非單一 API 用參數區分，推測是為了效能或前端獨立渲染考量
- 設定頁的賽事排序與首頁賽事排序連動，排序邏輯依賴設定頁的選項
