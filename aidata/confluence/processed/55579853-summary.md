## 摘要

本文檔說明了兩項功能需求：1) 版主走地預測時，原本僅記錄足球比分，現在需擴展到其他球種（如籃球、網球等），讓跟單玩家能參考預測當下的比分；2) 新增會員推薦分潤交易明細查詢 API，可依年月取得被推薦會員的逐筆交易時間與金額。這些規則直接影響 PriceCenterSite 的預測模組與支付模組，AI 開發時應對現有 API 進行向後兼容的調整。

---

## 關鍵業務規則

- - 版主發起走地預測（非足球球種）時，必須記錄該預測當下的賽事比分，以提供跟單玩家更多評估資訊；原有足球比分記錄邏輯保持不變。
- 會員推薦分潤查詢 API 需提供指定年月的被推薦會員交易明細，回傳內容依帳號分組，每筆明細包含交易日期時間（格式 YYYY-MM-DD HH:mm:ss）和交易金額（數值）。
- 版主預測 API（POST predict/moderator/{authKey}/bets/{gameType}）路徑、請求參數與回應格式均不變更，僅調整內部比分記錄邏輯。
