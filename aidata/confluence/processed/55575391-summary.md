## 摘要

定义了赛事会员身份验证相关的 REST API，包括上传证件图片、新增验证记录、查询验证列表/详情、更新验证结果等端点，并给出了对应的 Cassandra 表 verifygameusers 的字段结构。对 AI 开发的帮助在于提供了清晰的 API 契约和数据库模型，可以据此生成 client 调用代码和数据库访问层。

---

## 關鍵業務規則

- - 验证状态 status 字段含义：0 - 尚未验证，1 - 已验证，2 - 验证失败
- 上传证件图片时，通过 query 参数 uploadType 指定类型：id1（身份证正面）、id2（身份证反面）、passbook（存折）、headshot（大头贴）
- 新增验证记录时，必须提供 account、bankcode、bankaccount、bankaccountname、withdrawpwd 等字段，且 status 初始为 0
- 更新验证结果时，需提供 status 和 remark，status 只能为 0/1/2
- 返回数据中 withdrawPwd 字段为加密后的值（可见于 GET 响应示例）
