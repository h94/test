## 摘要

文件記錄將台灣銀行匯率爬蟲（原以 Go 實作）重構為 Python 的專案。內容定義從台灣銀行網頁以正則擷取幣別代碼、現金買入／賣出匯率的技術細節，並規範當任一匯率值為 '-' 時略過該幣種。最終資料以 JSON 格式寫入 Kafka。另包含使用 Cursor AI 輔助轉寫的實驗心得：轉換完成度高但需人工清理冗餘程式碼。

---

## 關鍵業務規則

- - 幣種匯率資料須同時有買入(Bid)與賣出(Ask)數值，若任一數值為 '-'（即無效匯率），則該幣種不發送 Kafka。
- 爬蟲解析 HTML 時，幣別代碼從 <div class="hidden-phone print_show xrt-cur-indent"> 的內容以正則擷取括號內代碼（如 USD），買入從 <td data-table="本行現金買入" class="rate-content-cash text-right print_hide"> 擷取，賣出從 <td data-table="本行現金賣出" class="rate-content-cash text-right print_hide"> 擷取。

---

## 關鍵設計決策

- - 採用對目標網站直接 request，從 HTML 中以正則表達式擷取匯率資料，而非使用 API，原因為台灣銀行未提供公開 API。
- 輸出資料結構統一為 JSON array，每筆包含 Site、Name、Datum、RequestTime、SendTime、Bid、Ask 欄位，以利 Kafka 下游消費。
- 嘗試以 Cursor AI 將舊 Go 專案轉寫為 Python，雖然語法轉換完整度 5/5，但產生多餘邏輯（可用性 3.5/5），最終仍需人工簡化，視為輔助而非自動化方案。
