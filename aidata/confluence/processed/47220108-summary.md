## 摘要

此文件記錄 PredictService 新增足球和網球預測結算機制的實作細節。新增 API 支援傳入開賽時間 (GTime)，並擴充設定殺手週期查詢。莊家殺手定時任務改為每週日 14:00、15:00、16:00 執行。DB 變更包含 predictbets 加入解鎖會員與開賽時間欄位，settings_killer 加入平均賠率，killeraccounts 加入會員暱稱，設定殺手週期加入起迄時間。開發時需注意足球和網球結算不分聯盟，殺手週期預設以今日為基準近 10 期計算。

---

## 關鍵業務規則

- - 足球和網球預測結算時不分聯盟，所有賽事視為同一處理範圍
- 莊家殺手定時任務每週日 14:00、15:00、16:00 執行（原先時間已變更）
- 取得殺手週期 API (GET /predictservice/api/settings/killer/cycles/{gameType}/{lid}) 若未帶 date 參數，預設使用當天日期
- 殺手週期查詢回傳近 10 期記錄

---

## 關鍵設計決策

- - 為支援更精確的結算與殺手計算，predictbets 表新增 gtime (開賽時間) 欄位，以區分同日期不同時段的賽事
- settings_killer 新增 avgodd (平均賠率) 欄位，用於莊家殺手演算法計算
- predictbets 新增 unlock_accounts (解鎖會員) 欄位，可能用於記錄特定會員在殺手週期內是否可被解鎖（具體邏輯需人工確認）
- killeraccounts 新增 username (會員暱稱)，方便前端展示
- settings_killer_cycle 新增 starttime / endtime 以明確定義每個殺手週期的起迄時間
- API 擴充：新增 GTime 參數允許提交賽事時指定開賽時間，並新增查詢介面以支援依日期、帳號過濾投注記錄
