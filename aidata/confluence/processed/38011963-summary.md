## 摘要

這份文件定義了一個新的 API 端點 (Get Taiwan Market Price)，用於查詢台灣股市大盤（上市 TSE/上櫃 OTC）的歷史價格資料。AI 開發人員可以透過此文件了解 API 的請求方式（GET）、參數格式（開始日期、結束日期、市場別）以及回應的資料結構，包含開高低收、成交量、成交額等欄位。文件也說明了當 Market 參數不帶時，會同時回傳上市與上櫃的資料。

---

## 關鍵業務規則

- - API 回傳的資料順序必須由開始日期到結束日期排列。
- Market 參數若不帶入，則同時回傳 TSE（上市）與 OTC（上櫃）的資料。

---

## 關鍵設計決策

- - API 路徑設計支援兩種呼叫方式：1) 將開始與結束日期放在 URL 路徑中；2) 以查詢參數 (Query String) 方式傳遞 Market 參數。
- 回應格式採用 JSON 陣列，每個元素包含日期、開盤價、最高價、最低價、收盤價、漲跌、成交量、成交筆數及成交額等完整大盤資訊。
