## 摘要

這份文件定義了用於 Kafka 傳輸的加密貨幣（cryptodata）與外匯（forexdata）數據結構，包括抓取站點、幣種對、毫秒級時間戳，以及價格、漲跌幅、成交量等基本行情欄位。同時提供了 Go 與 .Net 的對應 Model，方便跨語言開發。但訂單簿（CryptoOrderBook）與即時交易（CryptoMarketTrades）部分僅預留結構，尚未定義具體字段。

## 關鍵設計決策

- - 使用 Site 字段標識數據來源，支援 huobi、binance 等站點。
- 使用 Type 字段區分交易對類型：Crypto（虛擬幣/虛擬幣）與 Stable（虛擬幣/美金穩定幣）。
- 時間戳採用 13 位毫秒級 Unix 時間戳，以 RequestTime 標示爬取時間、SendTime 標示發送時間。
- 將行情數據拆分為 CryptoBasic（基本報價）、CryptoOrderBook（五檔訂單簿）、CryptoMarketTrades（即時成交）三個子對象，實現模組化設計。
- 同時提供 Go Struct 與 .Net Model，確保不同技術棧的服務使用一致的數據契約。
