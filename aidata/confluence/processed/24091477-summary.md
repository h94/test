## 摘要

本文件描述一個針對台灣證券交易所買賣日報表分點進出資料的爬蟲代理設計。透過 get page API 派發當日待爬取的股票代碼給多台機器，以 Selenium 爬取 https://bsr.twse.com.tw/bshtm/，並使用 page 表管理爬取狀態。文中一併估算使用 GCP Vision API 破解圖形驗證碼的成本。

---

## 關鍵業務規則

- - 每個股票代碼在 page 表中為唯一主鍵，代表一個待處理任務
- 需透過 getstock API 取得待爬取的股票代碼，完成後呼叫 removestock API 移除該代碼
- 爬取來源為台灣證交所的買賣日報表查詢系統

---

## 關鍵設計決策

- - 採用 get page API 集中分配股票代碼，再由多台機器平行爬取，以實現分散式爬蟲架構
- 使用 Selenium 模擬瀏覽器操作，因目標網站可能依賴 JavaScript 渲染或需要處理驗證碼
- 利用 GCP Vision API 進行圖形驗證碼識別，並根據每月約 1000 次呼叫量估算成本約 945 台幣
- 以 page 表的 handle 欄位記錄處理狀態，實現簡單的任務隊列管理

---

## 注意事項

- ⚠️ - ⚠️ 文件中的 API 端點使用內部 IP (192.168.9.16)，可能僅為開發或測試環境，正式部署時需確認正確的服務位址
- ⚠️ 成本估算基於 2022 年 GCP Vision API 定價，目前可能已調整，需重新評估
