## 摘要

本文說明了 StockBacktestingService 為支援多國（台、韓、美、A 股）回測，採用了每個國家獨立的 backtesting 與 backtesting_view 資料表，並在所有相關 API 中新增 Kind 參數來區分國家，初始值設為 'tw' 以維持相容性，待前端更新後將移除預設值。文件詳細列出各 API 加入 Kind 參數的方式，有助於 AI 在呼叫 API 時正確傳遞國家參數，以及在資料庫操作時依據 Kind 選擇對應資料表。

---

## 關鍵業務規則

- - Kind 參數用於區分國家，值為 'tw'（台）、'kor'（韓）、'usa'（美）、'a'（A 股）
- Kind 參數可選，未傳入時預設為 'tw'，前端完成修改後將移除預設值，改為必填
- 每個國家擁有獨立的回測資料表與回測明細資料表（後綴 _kor, _usa, _a）
- 所有涉及國家資料操作的 API（新增、更新、查詢）皆須傳遞 Kind 參數，以確保操作正確的資料表

---

## 關鍵設計決策

- - 採用每個國家獨立資料表而非在原有資料表加國家欄位，目的是最小化對現有系統的影響
- API 新增 Kind 參數並預設為 'tw'，以確保在未傳遞參數時不會破壞原有台灣市場的回測邏輯
- 計畫在前端處理好國家選擇後移除 Kind 的預設值，避免誤修改到非目標國家的資料
