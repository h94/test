## 摘要

文件定義兩個 API 變更：1) 殺手合牌預測資訊 API 移除近七天勝率和獲利欄位，以符合新機制；2) 採用現有第三方登入 API 支援 Apple 登入，透過 site=apple 參數區別。開發時應據此調整相關服務的 API 回應與參數處理。

---

## 關鍵業務規則

- - 殺手合牌預測資訊 API (GET predict/bets/popular/killerinfos) 的回應中不再包含近七天勝率、近七天獲利欄位
- Apple 第三方登入使用 POST users/login/thirdparty 端點，請求參數 site 值為 "apple"

---

## 關鍵設計決策

- - 因殺手合牌機制變更，殺手資訊不需顯示近七天勝率和獲利，故 API 回應移除這些欄位
- Apple 登入機制與其他第三方不同無法相容，因此沿用現有第三方登入 API，以 site 參數標示登入來源

## 注意事項

- ⚠️ Apple 登入的後端實作細節（如 token 驗證、帳號綁定邏輯）未在本文件說明，需查看會員服務具體設計
