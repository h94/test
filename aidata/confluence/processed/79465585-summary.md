## 摘要

本文件規範高手頁及至尊球王頁面導入「球王爭霸戰」相關功能，含廣告彈窗的新增與移除、常見問題與球王項目說明新增、訂閱方案頁面文案更新、至尊球王頁面選項變更為球王爭霸戰/球王榜/球王名人堂，並定義球王榜無資料時的假資料顯示文字、球王名人堂的佔位圖與說明文字。對 AI 開發而言，需實作爭霸戰週期時間範圍顯示、球王榜假資料渲染邏輯、訂閱方案頁三點利益說明，以及配合 API 取得至尊球王頁面比例數值。

---

## 關鍵業務規則

- - 高手頁需新增「球王爭霸戰」廣告彈窗，且移除預測頁原有的廣告彈窗
- 常見問題頁面與高手球王項目需新增球王爭霸戰說明，說明文案參考外部 Google Docs 文檔，數值部分顯示「查看當期設定」
- 訂閱方案頁面內容改為三點：1. 解鎖無限：不限次數解鎖「賽前高手推薦」；2. 專屬賽道：「百萬主推王」、「單月主推金盃」獎金競賽；3. 完全沉浸：啟用「球王模式」，自動隱藏廣告與干擾（保留自動合牌）
- 至尊球王頁面的選項變更為「球王爭霸戰」、「球王榜」、「球王名人堂」三個頁籤
- 「球王爭霸戰」頁面需顯示進行中的期數時間範圍
- 球王爭霸戰評選出來的贏家放置於「球王榜」上，球王名人堂改為另一獨立機制
- 球王榜無資料時，頭像與評選分數中間區塊顯示特定引導文字，完整內容為：「🌟 這裡，還沒有名字。但下一筆，將由你寫下。『球王榜』記錄每季唯一【至尊球王】的誕生，是征途的頂點，也是傳說的起點。現在，只差一人，敢以實力，登上這座王座。」
- 球王名人堂區塊先放提供背景圖並顯示說明文字：「🏛️ 球王名人堂｜傳奇不朽，只為極致征途 🔱 這裡，還沒有名字。但很快，就會有第一個。這不是排行榜，而是 inplayz 的聖殿。每一塊石碑都為傳奇預留，只待那一位用實力、熱血與堅持，寫下不可撼動的預測史詩。」
- 至尊球王頁面的比例數值需透過 API 動態提供，而非靜態設定
