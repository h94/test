## 摘要

本文檔定義球王內頁所需 API 的修改方案，包含取得聯盟賽事數量、賽事詳細資訊、隊伍分析、盤口賠率、賠率歷史走勢、莊家殺手預測人數、傷兵名單及排行榜等多個端點。主要變更為路由結構統一為 /games/{gameType}/{lid}/{gDate}/{gid}，增加 lang 國際化參數，部分端點從 POST 改為 GET，並提供詳細的請求與回應格式範例。對 AI 開發價格中心網站服務時，可明確 API 契約與資料結構。

---

## 關鍵業務規則

- - 盤口玩法固定取 HA（讓分）和 OU（大小）兩種，由 appsettingprovider 設定。
- 盤口資訊依照球種對應不同站台，配置在 appsettingprovider 中。
- 所有 API 支援 lang 查詢參數以對應多語系。
- 取得莊家殺手預測人數的 API 需要 authKey 驗證。

---

## 關鍵設計決策

- - 路由標準化：從 game/{gameType}/{gid} 改為 games/{gameType}/{lid}/{gDate}/{gid} ，讓路徑包含聯盟與日期，提升可讀性。
- 部分查詢端點由 POST 改為 GET，簡化客戶端整合並符合 RESTful 設計。
- 新增 lang 參數以滿足多語系需求。
- 原先提供 odd 查詢 sitegame 列表的端點（分析/sitegame/{gameType}/{gameID}）移除，不再支援。
