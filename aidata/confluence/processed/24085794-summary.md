## 摘要

本文件定義 Betfair 即時賽事資料的爬蟲解析規則，包含棒球(BS)、籃球(BK)、足球(SC)三種運動的賠率市場名稱與內部代碼的對應關係，以及每個市場在 Betfair 頁面上應擷取的欄位結構。這些規則供爬蟲 parser 開發使用，確保將 Betfair 獨特的名稱（如 Run Line、Money Line）正確轉換為系統內部標準代碼與欄位資料，為後續盤口數據處理提供規範。

---

## 關鍵業務規則

- - 棒球(BS)市場名稱對應內部代碼：Money Line → HA（讓分1X2，滾球碼RBHA），Run Line → HA（讓分，滾球碼RBHA），Total runs → OU（大小，滾球碼RBOU），1st Half Run Line → HalfHA/HalfRBHA，1st Half Total Runs → HalfOU/HalfRBOU，各局(如1st Inning) Total Runs → 1InnOU/1InnRBOU，各局 Run Line → 1InnHA/1InnRBHA，單隊 Total Runs → T1 Score 或 T2 Score / T1/T2 RBScore，Total Runs Odd/Even → Odd/Even / RBOdd/Even
- 籃球(BK)市場名稱對應內部代碼：Money Line → HA/RBHA（讓分1X2），Handicap → HA/RBHA（讓分），Total Points → OU/RBOU（大小），各節(1st~4th Quarter) Handicap → QuarterHA/QuarterRBHA，各節 Total Points → QuarterOU/QuarterRBOU，1st Half Total Points → HalfOU/HalfRBOU，1st Half Match Betting(2 way) → HalfHA/HalfRBHA（上半場1X2），各節 Odd/Even → QuarterOdd/Even / QuarterRBOdd/Even
- 足球(SC)市場名稱對應內部代碼：Match Odds → HA/RBHA（讓分1X2，有平手），Handicap Match Result → HA/RBHA（讓分），Correct Score → Correct Score / RBCorrect Score，Half Correct Score → HalfCorrect Score / HalfRBCorrect Score，Over/Under → OU/RBOU（大小），Total Goals Odd/Even → Odd/Even / RBOdd/Even，Half Result Markets → HalfHA/HalfRBHA（上半1X2），Handicap First Half → HalfHA/HalfRBHA（上半讓分），Over/Under First Half → HalfOU/HalfRBOU，Home/Away Team Over/Under → T1/T2 Score 對應 T1/T2 RBScore，Half Time/Full Time → 該市場碼 / RBHalf Time/Full Time，Corners Match Bet → CornerHA / RBCornerHA（角球讓分1X2），Corners Over/Under → CornerOU / RBCornerOU
- 滾球盤口辨識：表中「IN GAME英文代碼」欄位用於區分滾球（帶 RB 前綴，如 RBHA）與賽前盤口，開發時需根據比賽狀態動態選擇合適代碼
- 各市場在 Betfair 頁面上的欄位結構規範如下：OU 市場（棒、籃）固定欄位為「賠率名稱、大、大賠率、大盤口值、小、小賠率、小盤口值」；足球 OU 上半/下半場為「大/小盤口、大/小、大賠率、小賠率」；足球 CorrectScore 為「主隊贏比數及賠率、平手比數及賠率、客隊贏比數及賠率」；足球半全場為「名稱、賠率、平手、平手賠率」；其它市場詳見文件內圖片描述（如單隊大小、角球等）
- 部分市場在內部系統中不支援（標注「MAP 沒有」）：足球 Half RBCorrect Score、RBHalf Time/Full Time、RBCornerHA、RBCornerOU，開發時需跳過或特殊處理

## 注意事項

- ⚠️ - ⚠️ 文件最後更新於 2021-10-07，Betfair 網站可能已改版，市場名稱與欄位結構可能發生變化，應核對當前 Betfair 頁面後再使用
- ⚠️ 棒球「Money Line」說明為「讓分 1X2」，但實際上 Money Line 在博彩中通常指不讓分 1X2，而「Run Line」才是讓分，此處描述可能混淆，需人工確認內部 HA 代碼的準確語意
- ⚠️ 表格中部分市場的代碼重複使用 HA（例如 BK 的 Money Line 與 Handicap 都對應 HA），可能需額外上下文區分，需確認 parser 如何區別不同市場的數據
