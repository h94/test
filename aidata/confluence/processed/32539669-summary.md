## 摘要

這份文件記錄了 188bet 爬蟲（CrawlerAgent）針對桌球、排球、羽球三種球類的資料擷取規格。內容定義了球種代碼對應（桌球 TB、排球 VB、羽球 BM）、各球種支援的玩法類型（如 1X2、全場讓分、全場分數讓分、全場分數大小、單局分數讓分等）及其對應的 API 代碼（HA、PointHA、PointOU 等）。文件也展示了爬蟲從網頁 HTML 中解析出的賠率資料結構，以 JSON 嵌套格式呈現（例如 HA : {'1X2' : { 'H' :'2.23', 'A' : '3.4'}}），並特別標注桌球與排球的 1X2 玩法無平手賠率。對 AI 開發爬蟲服務的幫助是：提供明確的目標球種、玩法代碼映射表與預期的資料輸出結構，可直接作為爬蟲解析器開發與測試驗證的規格基準。

---

## 關鍵業務規則

- - 桌球（TB）與排球（VB）的 1X2 玩法中，賠率資料僅包含主場（H）和客場（A），無平手（D）賠率
- 球種代碼對應規則：桌球使用 TB、排球使用 VB、羽球使用 BM
- 全場讓分玩法代碼為 HA，資料結構包含讓分值與對應的主客隊賠率（例如 '-1': {'H': '2.35', 'A': '1.48'}）
- 全場分數讓分玩法代碼為 PointHA，全場分數大小玩法代碼為 PointOU，單局分數讓分為 1st PointHA，單局分數大小為 1st PointOU
- 所有賠率資料以 JSON 結構呈現，外層 key 為玩法類型代碼，內層包含讓分值或分數門檻值，最內層為賠率方向（H/A 或 O/U）與賠率值

---

## 關鍵設計決策

- - 桌球和排球的 1X2 玩法被設計為只返回兩項結果（H/A），不包含平手選項，這反映了這兩種運動在該博彩網站的實際開盤規則
- 羽球（BM）的表格中玩法與資料欄位為空白，可能表示當時羽球的爬取規格尚未定義或該網站無羽球盤口，需人工確認
