## 摘要

本文件定義在 StockKing 選股與回測功能中新增支援美股、韓股、A股的業務需求。前端需增加地區選擇按鈕與模態框，並以 cookie 記憶用戶選擇；切換至非台股時隱藏「券商買賣超」與「警示股」Tab。同時列出後端 .NET 與 Python API 需要新增 country 參數的完整清單，並附帶 Figma 設計稿連結。對 AI 開發的幫助：明確地區切換的前端行為、cookie 邏輯、需隱藏的 UI 元件，以及後端 API 的參數變更範圍。

---

## 關鍵業務規則

- - 使用者可在 StockKing 中選擇台股、美股、韓股或 A 股進行選股與回測。
- 地區選擇透過點擊按鈕後彈出 modal 進行，手機版亦有對應 UI 元件。
- 系統必須以 cookie 記錄使用者最後選擇的地區，下次進入頁面時自動沿用。
- 當選擇美股、韓股或 A 股時，前端必須隱藏「券商買賣超」與「警示股」兩個 Tab 頁籤。
- 所有與選股、自選股、回測相關的 API 讀取或寫入時，均需傳遞 country 參數以區分市場。

---

## 關鍵設計決策

- - API 採用 query 參數或 request body 的 country 欄位來識別市場，而不是建立完全分離的端點，達到最小變更。
- 前端以 cookie 記錄地區選擇，而非後端記住，避免增加伺服器端狀態。
