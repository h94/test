## 摘要

本文件為籃球球員資料 API 的技術設計草稿，定義了一個 GET 端點根據球種查詢年度球員資料，並設計了 MySQL 資料表 BK_SitePlayers 來儲存球員統計數據。內容包含 API 基本路由及完整的資料庫欄位定義（含命中率、籃板、助攻等多項進階統計）。但 API 的參數與回應格式仍留白，許多實作細節尚未確定，對 AI 開發的幫助在於提早確認數據模型與介面雛形。

## 關鍵設計決策

- - 資料庫選用 MySQL，資料庫名稱規劃為 BK_Players（但實際使用表名為 BK_SitePlayers）
- 為避免 MySQL 保留字衝突，將「失誤」欄位命名為 TOV（而非 TO）
- 球員數據包含多項命中率與百分比欄位（FG%, 3P%, FT%），使用 float 型態儲存
- API 端點初步設定為 /pricecenter/api/，預計以 GET 方法傳遞球種等篩選條件
