## 摘要

此文件是 PriceBackendService 的 API 規格，列出所有端點的 HTTP 方法、路徑、請求參數、回應格式與欄位備註，涵蓋支付紀錄查詢、討論區管理、會員管理、賽事系統設定與訂閱者管理等後台功能。用於 AI 開發時，可直接根據此表建立 API 客戶端、撰寫整合測試，並理解各欄位的業務意義，無需猜測請求/回應結構。

---

## 關鍵業務規則

- - 儲值紀錄查詢：Status 欄位 1=成功、0=失敗、2=審核中
- 專家文章審核：Result 欄位 0=未通過、1=通過
- 賽事站台一般/專家會員：Rank 欄位 3=專家、5=一般
- 編輯賽事站台會員狀態時，Status 為必填（例 Status: 2）
- 修改賽事站台會員 Rank 時，僅能設為 3 或 5
- 股票站台使用者註冊僅支援 Local 環境
- 修改訂閱者使用者密碼時，僅在需要變更時才傳遞 Password 欄位

---

## 關鍵設計決策

- - API 統一使用 /pricebackendservice/api/ 前綴，區分 Payment、Forum、Member、GameSetting 等模組
- 大部分 GET 請求使用 query string 傳遞過濾參數，POST/PUT 使用 JSON body 傳遞資料
- 回應格式多數使用 Code + Message 的結構表示操作結果
