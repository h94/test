## 摘要

本文件定義股票後台策略管理的 REST API 規格，包含對 /backend/rules 的 GET、POST、PUT 端點及 /backend/options 端點，返回 RuleDTO（含 ID、Enabled、Type、Indicator、Text、Parameter、Countries）與 OptionDTO。可用於開發股票後台策略配置功能時的 API 合約參照。

## 關鍵設計決策

- - 選用 RESTful 風格，/backend/rules 作為資源端點，支援查詢、新增、修改策略。
- RuleDTO 中以 Indicator 字串與 Parameter 列表分離辨識條件與參數，保持彈性。
- 獨立提供 GET /backend/options 端點，便於前端動態取得下拉選單項目（OptionDTO）。
- 策略啟用狀態以整數 Enabled 表示，與 OptionDTO 的 Enabled 欄位呼應。
