## 摘要

文件說明了在 GS 後台中查詢 LS 站台賽事的功能設計，使用者可分別查詢賽前與賽中賽事。透過呼叫 LS 提供的 PreMatch/GetEvents 與 InPlay/GetEvents API，並區分 packageId（賽前 2617、賽中 2616）來取得賽事資料。提供了請求範例與預想畫面截圖，可作為前端開發與 API 整合的參考。

## 關鍵設計決策

- - 採用 LS 的 Snapshot API 直接取得賽前/賽中賽事清單，不透過中介服務
- 賽前查詢使用 packageId=2617，賽中查詢使用 packageId=2616，共用相同的請求格式
