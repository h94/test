## 摘要

定義了彩池得獎名單的兩支 API：查詢彩池群組可用的得獎主題列表（依 moon, week, season 分組）與取得特定彩池的得獎名單。API 支援根據訪客 authKey 判斷是否返回個人排名（myIndex），若未登入或不在名單中則為 null。得獎數據來自 BackendService 生成的 JSON 檔案，並由 PredictService 儲存在 betpools_winners_newlottery 表中（以 gid 為分區鍵，btype 和 pid 為聚簇鍵）。對實作 NewLotterySite 的前端顯示與後端數據查詢有明確規範。

---

## 關鍵業務規則

- - 當提供 visitor=authKey 且該用戶存在於得獎名單中時，API 回應包含 myIndex 物件（含 userID, userName, rank, coin, avgOdd, winCount, loseCount, profitPoint, winPercentage），否則 myIndex 為 null。
- 得獎名單內容欄位固定包含：會員暱稱、名次、平均賠率、勝敗場次、總獲利點數、勝率、派彩鑽石數。
- 彩池群組得獎主題列表回傳的 topics 以彩池種類（moon, season, week）為鍵，值為可查詢的期數（pid）陣列（如 week:[5,4,3,2,1]）。
- API 路徑參數 gameType（如 BK）與彩池群組 id 為必填，查詢特定彩池需同時提供 bType（彩池種類）和 pid（期數）。

---

## 關鍵設計決策

- - 使用 PredictService 的 Cassandra 表 betpools_winners_newlottery 儲存得獎名單，分區鍵 gid 確保同一彩池群組數據集中，聚簇鍵 btype + pid 排序方便查詢特定種類和期數。
- 檔案由 BackendService 產生並儲存於 downloads/newlottery/cachefiles/betpoolgroups/{gid}/winners_{bType}_{pid}.json，便於非同步產生與快取。
- API 設計為 RESTful 風格，端點命名清晰區分主題列表與名單內容，與前端互動直覺。
