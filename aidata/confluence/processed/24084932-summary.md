## 摘要

本文件描述後台工具中「合併/原始聯盟隊伍資料維護」的四個 API 操作流程：顯示合併聯盟、修改合併名稱、修改翻譯名稱、顯示合併隊伍。所有操作均透過 PriceCenterService 與資料庫互動，預設球種為 BK；修改名稱 API 僅更新單一欄位並回傳成功或失敗。對 AI 開發者可了解 PriceCenterService 在後台工具中提供的基本 CRUD 介面。
