## 摘要

此文件為一個簡短的技術變更記錄。它描述為了支援台灣運彩文章，在既有的 NewsService 取得運動站台文章 API（GET /newsservice/api/sportarticles）上新增查詢參數 articleClass（例如 twsl）。此變更修改舊有 API 的輸出邏輯，以根據參數篩選特定類別的文章。閱讀後可知 API 擴充的方式與預期參數名稱，但缺少具體行為細節。
