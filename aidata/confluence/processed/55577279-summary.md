## 摘要

本文件定義了球王站台新增的社群與活動相關 API，包括會員賽事預測、社群群組管理、活動提領等功能。詳細說明了每個 API 的請求/回應格式、參數預設值與欄位含義，並列出業務規則（如版主預測單鎖定、活動提領聯絡方式規則、群組類型與 owner 限制）。另外也記錄 MemberService 需記錄會員最後活動時間，gameusers 資料表新增 memberships 與 lastactiontime 欄位，以及 PriceBackendSerice 回傳群組時新增 owner 與 description。對 AI 開發人員，可從中獲取 API 規格、參數驗證規則及會員身分處理方式。

---

## 關鍵業務規則

- - 若會員身分是版主（moderator），該會員的預測單一律鎖定（enabled 需強制設為 0 或等同鎖定）。
- 請求取得會員範圍日期賽事預測 API 時，應同時更新該會員的最後活動時間。
- 活動提領申請：若該帳號無任何提領紀錄，ContactNumber 必填；若有紀錄，ContactNumber 可選填，未填時自動沿用前次申請的號碼。
- 社群群組新增／更新時，GType 為 'personal' 則 Owner 必填；為 'test' 則 Owner 必填且該 Owner 必須擁有 'admin' 身份；其他類型 Owner 可選填。
- 群組 IconPath 為必填，但當 GType 為 'personal' 或 'test' 時可留空；留空時系統自動使用 owner 的大頭貼，若 owner 亦無大頭貼則報錯。
- Enabled 與 Seq 分別預設為 0，可省略不傳。
- 新增會員賽事預測 API 的回應中，newBets 欄位僅在請求者具版主身分時才回傳。
- 查詢球種聯盟預測賽事時，status 參數只允許 0（inplay）或 2（pregame），其他值直接報錯；status 非 inplay 時，比分相關欄位固定回傳 -1。
- 取得球種聯盟日期某賽事賠率時，otherPlayModes 參數預設為 false。
- 取得版主帳號預測賽事 API 只提供三天內預測注單，visitor 參數必填，lang 預設 zh-TW。
- 會員登入或第三方註冊登入時，必須更新最後活動時間。
- gameusers 資料表新增 memberships（list<text>，可包含 admin、moderator、vlsport）與 lastactiontime（bigint）欄位。
- 透過 API 可更新會員身分（memberships）或最後活動時間（lastactiontime），這兩組操作彼此獨立。

## 關鍵設計決策

- - 為了支援球王站台的個人社群功能，設計版主身份與鎖定預測單機制，確保版主預測內容不會被一般會員修改。
- 採用最後活動時間來確認會員活躍度，並在取得預測相關 API 時順便更新，減少額外請求。
- 活動提領沿用上次聯絡方式，避免會員重複輸入，提升體驗。
- 社群群組透過 GType 控制 owner 與 icon 行為，區分官方（official）、VIP、一般（normal）、個人（personal）及測試（test）類型，並限制 test 類型只有 admin 可擔任 owner。
