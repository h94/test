## 摘要

為第三方站點 uwin 設計的獨立 API，包含會員註冊／登入增加 ADSource 欄位、取得第三方帳號預測賽事（支援進行中／歷史過濾），並修改勝率計算機制：取消與和局不計入。對 AI 開發的幫助：明確了第三方站點預測資料的查詢規格，以及勝率業務規則的變化。

---

## 關鍵業務規則

- - 第三方站點預測記錄 API 不需要鎖定和解鎖機制（有別於內部預測功能）。
- 取消及和局的預測結果不納入勝率計算。
- GET /thirdpartysite/{site}/accounts/{account}/predictgames?final=false 取得未結束賽事，final=true 取得近 30 天歷史賽事。
- 使用者註冊、第三方登入及 X 登入 API 的 request body 需新增 "ADSource": "uwin" 欄位，以標記來源為第三方站點。

---

## 關鍵設計決策

- - 因第三方站點不需要鎖定／解鎖等內部機制，故獨立建立 API，避免耦合。
- 勝率計算排除取消與和局，以提高勝率指標的參考價值。
