## 摘要

本文件設計了社群直播功能的 API，定義了三組主要端點：取得社群群組列表（含直播賽事）、取得可預測聯盟且有動畫直播的賽事列表、以及更新社群直播設定。同時提供 GameLiveService API 用於取得聊天室最後訊息與更新群組直播設定。直播賽事設定儲存於 Redis，賽事結束後自動從列表移除。此設計讓開發者能清楚了解 PriceCenterSite 前後端互動，並實現社群動態顯示直播賽事的功能。

---

## 關鍵業務規則

- - 取得直播賽事列表時，只回傳可預測的聯盟且擁有動畫直播的賽事（aniurl 存在）
- 設定直播賽事後，資料記錄於 Redis；當直播賽事結束，該賽事不再呈現在社群群組列表上
- 更新直播設定時，ChatEnabled = 0 表示取消直播，ChatEnabled = 1 表示設定直播；若非取消，回應會包含該賽事的完整資訊
- 只有群組版主（owner）可以更新直播設定，若非版主則回應 "not the owner"，更新失敗
- AddCommunity Invoke 回傳 "success" 才代表社群加入成功，其餘皆為失敗

---

## 關鍵設計決策

- - 採用 Redis 儲存直播設定，以利快速讀取並支援賽事結束後的自動清除
- 使用 Invoke 機制（SendUpdateCommunityGroupLiveGame）即時推送賽事變更至所有相關客戶端，確保資料同步
- 前後端 API 分離，前端（PriceCenterSite）提供基礎社群與直播查詢，後端 GameLiveService 提供更完整的群組資訊與更新操作，以符合職責分離

## 注意事項

- ⚠️ - ⚠️ 需人工確認「取得社群群組」API 回應中的 liveGame 欄位為 null 時代表未設定直播，與設計文件中「直播賽事結束後則不呈現社群列表上」一致，但需確保 client 端正確處理 null 情況
- ⚠️ 文件未提及 Redis key 的命名規則與過期策略，實作時需補充相關細節
