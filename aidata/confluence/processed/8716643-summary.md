## 摘要

這份文件定義了 PriceCenterService 中的 UpdateBet365page API 需求。該 API 的作用是根據 CrawlerService 傳來的頁面資訊（pagename, pagetype, url, enabled）來更新資料庫中的 bet365page 表。這是一個供爬蟲系統調用的接口，用以控制和管理需要爬取的網頁設定。對 AI 開發的幫助是，可以明確知道當需要動態調整爬蟲目標頁面時，應該調用此 API 並傳入這四個具體參數。

---

## 關鍵業務規則

- - 更新 bet365page 資料表時，必須根據 pagename, pagetype, url, enabled 這四個欄位進行操作。
- 此 API 的觸發方為 CrawlerService（或其他爬蟲相關服務），而非前端用戶直接操作。
