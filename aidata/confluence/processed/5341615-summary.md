## 摘要

本文定义了 CrawlerAgent 处理完赛事数据后，通过 Nginx 的 /pricecenter/match.json 接口将数据写入 Kafka 的 matches topic（同时记录到 nginxlog topic），供 CrawlerService 订阅消费。提供了完整的 JSON 数据格式样例，包含比赛类型、来源、请求时间以及比赛列表，每个比赛含联盟、队伍、时间、比分、局数等字段。这为上下游服务的数据对接提供了明确的技术契约。

## 關鍵設計決策

- - 采用 Nginx 作为中间代理接收 HTTP 请求并转发至 Kafka，以实现统一的请求日志记录（写入 nginxlog topic），而非由 CrawlerAgent 直接写入 Kafka。
- 规定数据格式以 matches topic 承载赛事实体，使用 JSON 数组包含当天所有变更的比赛，下行服务可一次获取批量数据。
