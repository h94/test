## 摘要

定義 StockKing App 的訂閱功能，包含方案頁面、個人設定中的訂閱狀態與紀錄。付款頁面需傳入方案編號與 user token，方案列表透過 /api/v1/payment/plans 取得。個人設定使用現有 API /auth/users/settings 並擴增訂閱相關欄位。開發時需根據登入狀態與會員階級控制 UI 顯示，並注意方案有效期間控制。

---

## 關鍵業務規則

- - 訂閱方案頁面：未登入時顯示導向登入頁按鈕，已登入則依會員階級顯示或隱藏購買按鈕
- 個人設定頁面顯示客戶階級、訂閱日期、到期日、使用天數、倒數天數，並根據客戶階級顯示「訂閱導向」或「中斷續約」按鈕
- 訂閱紀錄頁面顯示客戶階級、訂閱日期、付款金額
- 付款頁面路由 /home/index?sub={方案編號}&ut={user token}，sub 與 ut 為必填
