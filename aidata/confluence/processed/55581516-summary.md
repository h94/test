## 摘要

本文件定義 Tonybet 體育數據爬蟲的實作規格，包含球種、語言、比賽狀態對應表，以及取得比賽列表與單場細節的 API 端點與參數。流程圖說明透過兩階段 API 取得完整資料後上傳 Kafka，供後續盤口處理。對於開發 crawlerservice 的 tonybet provider，可依此實現數據拉取與參數映射。

---

## 關鍵業務規則

- - 球種 ID、game_type 與 site code 的對應關係（如足球 SC - 1、籃球 BK - 2 等），需正確傳入 API 參數。
- 語言代碼對應（en-US → en, es-ES → es, fr-FR → fr, de-DE → de），用於 API 的 lang 參數。
- 比賽狀態 status_code：prematch 使用 0，inplay 使用 2。
- 比賽列表 API 使用分頁（limit=500，page 從 1 開始），需循環取得所有比賽。
- 單場比賽 API 必須指定 relations=league, odds, result, competitors, sportCategories, statistics 以獲得完整資訊。

---

## 關鍵設計決策

- - 採用官方 API (platform.tonybet.com) 直接取得結構化數據，而非網頁爬蟲，以確保穩定性與完整性。
- 分兩階段 API 呼叫：先取得比賽列表，再逐一請求詳細資料（含賠率等），避免單次請求過重。
- 資料最終推送至 Kafka，便於下游服務（如 pricecenterservice）統一消費，解耦爬蟲與業務邏輯。
