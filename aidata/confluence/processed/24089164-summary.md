## 摘要

本文件定義了 Bwin 提供的賽事玩法（BK 籃球、SC 足球）與系統內部 PlayMode 代碼之間的映射規則。涵蓋 PreGame 與 In Game 兩種狀態，In Game 的代碼會加上「RB」前綴以示區別。對於 AI 開發，可用來建立外部賠率源 (Bwin) 的玩法識別邏輯，確保滾球與賽前盤的正確分派，以及單節、單隊等變體的參數化處理。

---

## 關鍵業務規則

- - PreGame 狀態下，BK 的 Totals → OU，Money Line / Spread → HA，1st Half Spread → HalfHA，2nd Half Spread → 2nd HalfHA。
- In Game 狀態下，上述代碼均加入「RB」前綴，例如 RBOU、RBHA、HalfRBHA、2nd HalfRBHA。
- 單節玩法（如 1st Quarter）可在代碼中以「1st QuarterHA」表示，並支援括號內的其他節次替換（2nd/3rd/4th QuarterHA），In Game 則變為「1st QuarterRBHA」等。
- SC 足球的 Match Result 對應 HA（PreGame）/ RBHA（In Game），Total Goals 對應 OU / RBOU，上半/下半同理加 Half/2nd Half 區段。
- Correct Score 玩法代碼為 Correct Score（PreGame）與 RBCorrect Score（In Game），不加 HA/OU 尾綴。
- 部分代碼尾部有「Score」字樣（如 T1 Score / T2 Score）表示單隊大小，In Game 時可能結合 RB 及 OU 組合，如 T1 RBScore 或 T1HalfScoreRBOU，需對照表格。
