## 摘要

本文件定義了從 NHL 官方 API 爬取賽事數據的技術規格，包括兩個主要端點（當場賽事與一週賽程），並詳細說明如何從 JSON 回應中解析 game_id、game_status、主客隊資訊、得分、play_by_play 等欄位。特別指出 game_date 使用 UTC 時間且需轉換為美國時間。這些規範為 AI 開發 crawlerservice 實現 NHL 數據採集提供明確的數據源與字段映射規則。

---

## 關鍵業務規則

- - 使用 api-web.nhle.com 的 gamecenter landing 端點（帶 gid 參數）取得當場賽事詳細資料。
- 使用 api-web.nhle.com 的 schedule 端點（帶日期參數）取得一週賽程。
- game_id 從 API 回應的特定路徑提取（具體路徑依附圖）。
- game_status 由 JSON 欄位 "gameState" 判斷，如值為 "OFF" 代表比賽結束。
- 主客隊資訊（team_home, team_away）及其 ID 由回應中對應 JSON 結構提取。
- 球隊標誌 (logo) 從 API 回應中取得。
- game_date 使用 "startTimeUTC" 欄位，且必須從 UTC 轉換為美國當地時間。
- 主隊/客隊得分 (scores_h, scores_a) 從回應中多層嵌套結構取得（見文件截圖）。
- match_h/match_a 欄位可能從兩種來源之一獲取（存在兩組不同 JSON 路徑）。
- play_by_play 數據從 API 回應的另一節點或另一請求中解析（見文件附圖）。

---

## 關鍵設計決策

- - 選擇使用 NHL 的官方 web API（api-web.nhle.com）而非解析官網 HTML，以獲得結構化數據。
- play_by_play 數據可能通過獨立請求或從 landing 回應的附加部分取得，設計上需處理可能的異步請求。
- 時間處理：基準採用 UTC 時間，輸出時轉換為美國時區，避免後續業務中的時區混亂。
