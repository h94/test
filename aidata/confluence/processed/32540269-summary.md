## 摘要

本文件定義了股票站台使用者相關的後端 API 設計，包含註冊、登入與操作 Log 記錄三個端點。這些 API 統一歸屬在 MemberService 下，路由前綴為 /memberservice/api/stock/。對 AI 開發而言，這份文件提供了與股票前台（StockSite）進行身分驗證與行為記錄的介面定義，有助於理解會員服務如何支援股票業務模組的使用者管理功能。

## 關鍵設計決策

- - 股票站台使用者相關 API 被統一設計在 MemberService（memberservice）這個服務中，而非獨立成另一個服務，暗示股票使用者被視為會員系統下的一個子類型，共用 MemberService 的基礎設施。
- API 的 Response 統一使用 MsgCode Model（包含 Code 和 Message 欄位），保持與其他內部服務一致的回應格式。
- 操作 Log 的記錄（API 3）將帳號（Account）、操作類型（Type，例如「分點進出」）與資訊（Info）作為輸入，設計上為事後記錄而非即時阻斷，屬於非同步的稽核記錄模式。
