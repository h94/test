## 摘要

本文件定義一個用於爬取 Investing.com 股票歷史資訊的技術方案。爬蟲對象為中國A股、美股、韓股，先取得各國股票列表，再透過 HistoricalDataAjax API 獲取 2012-01-01 至昨日的每日 OHLCV 數據。請求間需 sleep 5 秒以避免被封鎖。對 AI 開發爬蟲服務時，可直接參考 API 端點、參數與速率限制設計。

## 關鍵設計決策

- - 使用 cn.investing.com 的兩個 API 取得股票列表與歷史數據，而非網頁解析。
- 爬取國家代碼：中國 37、美國 5、韓國 11。
- 請求頭需偽裝 User-Agent 為 Chrome 瀏覽器，Content-Type 設定為 multipart/form-data。
- 歷史數據 API 需提供 curr_id（來自基本資訊）、日期區間、interval_sec=Daily、action=historical_data 等參數。
- 請求過於頻繁會被阻擋，因此每次請求後需暫停 5 秒。
