## 摘要

本文档描述了一个新的定时任务触发的API，用于生成预测筛选排行榜快照文件。流程由 xxl-job 调度 PriceBackendService，依次调用 PredictService 获取预测数据、MemberService 获取会员数据、PriceCenterService 获取赛事联盟队伍数据，最终组装排行榜并存储到 NAS 路径 downloads/leaderboard/sportsite/filter/{gameType}/{date}。API 仅提供一个 POST 端点接收 gameType 和 date 参数。文档给出了排行榜响应的完整 JSON 结构，包含按预测赢利排序的会员及其预测明细，对 AI 理解数据流转和结果结构非常有用。

## 關鍵設計決策

- - 排行榜采用离线生成方案，由 xxl-job 定时触发 PriceBackendService，避免实时计算压力。
- 快照文件存储于 NAS，路径格式为 downloads/leaderboard/sportsite/filter/{gameType}/{date}，便于前端或其他服务直接读取。
- API 仅暴露 POST 方法同步生成，但实际依赖多个下游服务并行获取数据。
- 排行榜排序依据为 ProfitPoint（盈利点数）或 Seq_Score 等字段（具体排序规则需人工确认，示例中未明确说明）。
- 响应中每个 PredictAccountFilterInfo 包含该会员指定 FilterType 的预测列表、预测总数、胜场数、盈利点数等聚合信息，并附 WinLose_Detail 用于可视化历史胜败日历。
