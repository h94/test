## 摘要

文件描述 PriceCenterService 的 Get Hot Game API 改寫需求，將以 GameLive 服務提供的比賽資料為基礎，根據球種 BS、BK、SC 各自預設的熱門聯賽進行篩選，並透過新的 API 端點 /pricecenter/api/hotgamemapping 回傳 List<RedisTodayGame> 格式的熱門賽事清單。此設計可幫助 AI 開發者理解熱門賽事的數據來源規則與 API 回應結構。

---

## 關鍵業務規則

- - 球種 BS 預設熱門聯盟：MLB, CPBL, Japan NPB, KBO
- 球種 BK 預設熱門聯盟：NBA, Australia NBL, Korea KBL, WNBA
- 球種 SC 預設熱門聯盟：England Premier League, Spain Primera Liga, Germany Bundesliga I, France Ligue 1, Italy Serie A
- 熱門賽事篩選資料基底為 GameLive 服務提供的比賽資訊

---

## 關鍵設計決策

- - 採用 GameLive 作為資料來源，以既有比賽資料驅動熱門賽事邏輯
- API 端點設計為 GET /pricecenter/api/hotgamemapping，回傳 RedisTodayGame 模型列表
- 各球種的預設熱門聯賽以靜態定義方式處理，保持簡單且易於維護
