## 摘要

本文件描述為球種玩法新增定時變更偏移量功能的 API 設計。在 PlayModeSettings 模型中擴充 UseAlarm、AlarmBeforeGameRate、AlarmRate 三個欄位，支援以時間點為鍵的偏移量設定。設計了兩個 Patch API，分別對應 GameSettingService 與 PriceBackendService，接收遊戲類型與 PlayModeSettings 列表。現階段不包含第三方資料解析與自動更新。

## 關鍵設計決策

- - 選擇直接在 PlayModeSettings 模型上擴充三個新欄位（UseAlarm、AlarmBeforeGameRate、AlarmRate）來儲存定時偏移量設定，而非建立獨立模型。
- AlarmBeforeGameRate 與 AlarmRate 使用 Dictionary<string, RateSetting> 結構，以時間字串為鍵，支援不同時間點的偏移量。
- 同時為 GameSettingService 與 PriceBackendService 提供相同的 Patch API，使兩服務皆可寫入設定。
