## 摘要

此文件定義了股票相關功能的 REST API 端點、請求參數、回應模型，涵蓋登入、券商篩選、股票數據查詢、策略管理、回測等功能。對於 AI 開發而言，可據此了解如何獲取股票報價、技術指標篩選條件、券商買賣超明細以及回測結果的資料結構。

## 關鍵設計決策

- - API 路由採用 /stock/ 前綴，並以 account 作為使用者資源的區隔，例如 /stock/brokers/{account} 用於取得已儲存的券商篩選紀錄，實現多用戶隔離。
- 策略與券商篩選紀錄的儲存採用 PUT 更新、POST 新增、DELETE 刪除的標準 REST 風格，並以 ruleName 或 favoriteBrokerName 作為資源識別。
- 回測資料以 addTime 和 hashKey 作為查詢與刪除的複合鍵，推測是為了支援多次回測記錄並避免命名衝突。
- 部分查詢（如取得股票資訊）需要傳入預組好的條件字串（例如 '日K9大於32'），將前端條件組裝後放入 StockStrategy 的 TargetIndex.Text，減少後端解析邏輯。
