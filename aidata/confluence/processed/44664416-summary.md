## 關鍵業務規則

- - 相似度預設至少0.85以上，部分圖形要求0.99以上
- 槌子線：相似度0.99以上；收盤價等於最高價；(開盤價 - 最低價) / (最高價 - 最低價) >= 2/3
- 倒狀槌子：兩天皆非平盤；第二天上引線比例 >= 2/3；第一根(開盤-收盤)/開盤 < 0.01的視為無效；第二根為紅K時：第二天收盤價 > 第一天最低價，第二天開盤價 <= 第一天收盤價；第二根為黑K時：第二天黑K >= 第一天最低價；第二根無下引線且上引線 >= 第一天實體中點
- 十字線：相似度0.99以上；最低價 = 開盤價；(最高-最低)/開盤(最低) < 0.01視為太短無效
- 母子線：第二根K棒收盤價和開盤價不超過第一根K棒開收價之間（不可等於）
- 晨星：第二根K棒收盤價與開盤價位於第一根K棒收盤價與開盤價之間（不能等於），且第一根不能收平盤；滿足第二天收盤 > 第一天開盤 > 第一天收盤 > 第二天開盤
- 三星：每一根K棒的(開-收)/開 < 0.003；且第二天開盤與收盤相等、第一天收盤 = 第二天開盤 = 第二天收盤 = 第三天開盤；第一、三天收盤 > 開盤
- 棄嬰：第二根收盤 < 第一天開盤，第二根開盤 > 第一天收盤；第三根收盤高於第一天開盤；所有K棒不能平盤；第三根開盤 < 第一天最高價
- 雙鴉躍空：二天非平盤且皆為黑K；兩天收盤價、最低價皆相同且最低價等於收盤價；(最高-最低)/最低 < 0.01視為太短無效；第一根上引線比例超過1/3無效
- 頸上線：第二根收盤價 > 第一根開收中點且小於第一根收盤價；第二根開盤價 < 第一根收盤價
- 貫穿線：第二根K棒收盤價位於第一根K棒開收價之間（等於允許，因原刪除線劃掉不能等於）；開盤價在第一根K棒開盤價與最低價之間；兩根K棒不可收平盤；(開盤-收盤)/開盤 < 0.01太短無效
- 大陽線前阻線：相似度99%；下引線長度比例 >= 2/3；開盤價等於最高價
- 空頭反攻：第一天開盤 == 第一天最高 > 第二天高點 > 第一天收盤 == 第二天收盤 > 第二天開盤
- 多方缺口：兩天非平盤；第二天開盤在第一天實體K以上；實體K比例都在0.5以上；高低差 >= 0.02
- 夜星：第三天開盤 <= 第一天收盤；第一、三天不能平盤，且實體K位置不低於第二天開盤或收盤取大；第二天收盤 >= 實體K中點
- 空頭遭遇（標記X，已棄用）：第一天最高 > 第二天收盤 == 第一天收盤 > 第一天開盤；第二天開盤 > 第二天收盤；第一、二根上引線比例1/3以下
- 多頭反攻（標記X，已棄用）：多頭遭遇實驗失敗，暫時不使用
- 低價配：第二天收盤 <= 第一天實體K中點；第二天開盤 >= 第一天收盤；第二天收盤 >= 第一天開盤；第一天非平盤
- 陽線吞噬：第二天實體K在第一根實體K之中，第三天收盤在第一天開盤之下
- 上方並列線：第二天收盤價或開盤價等於最低價並且此最低價 > 第一根收盤價，且第二根上引線比例 >= 2/3；兩天非平盤；第一根實體K比例 > 0.301；(最高-最低)/最低 < 0.01無效
- T字線：(最高-最低)/最低 > 0.01；開盤價 == 收盤價 == 最高價 > 最低
- 一字線：(最高-最低)/最低 >= 0.01；收盤 == 開盤
- 十字線（狹幅）：(最高-最低)/最低 < 0.01；最高 > 收盤 == 開盤 > 最低
