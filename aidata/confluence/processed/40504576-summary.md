## 摘要

文件描述修復股票系統兩個頁面的技術方案：將選股策略紀錄與回測結果查詢中的操作者、日期選擇器從 ElementUI select 改為一般 input，表格統一替換為 components/global/Table.vue。因後端 API 未提供排序參數，選股策略紀錄的排序功能改由前端自行實作。提供 Figma 設計稿連結，供開發參考。

## 關鍵設計決策

- - 操作者欄位與日期選擇從 ElementUI select 改為一般 input 欄位，降低對特定 UI 庫的依賴，簡化互動。
- 表格统一使用 components/global/Table.vue，確保全域表格行為一致，便於維護。
- 選股策略紀錄的排序功能由前端實現，因為原 API 未提供排序參數，避免後端改動，由前端自行處理排序邏輯。
