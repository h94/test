## 摘要

本文件定義了 PriceCenterService 新增的寫入聯盟/隊伍多語言名稱 API。該 API 接受包含 GameType、Site、SiteLID、SiteTID、CountryCode 與 Name 的列表，寫入 SiteLeague 與 SiteTeam 資料表的 name_map 欄位。CountryCode 採用語言代碼（如 zh-TW），Name 為對應語言的隊伍/聯盟名稱，寫入前需驗證 CountryCode 的有效性。此文件對 AI 開發 PriceCenterService 的多語言資料寫入功能與相關 DB 操作提供了明確的規格。

---

## 關鍵業務規則

- - CountryCode 必須是有效的語言代碼，格式為 language-region（如 zh-TW、en-US），寫入前需進行驗證
- 聯盟/隊伍各語言名稱需寫入 SiteLeague 與 SiteTeam 表的 name_map 欄位，而非獨立的多語言表
- API 回傳寫入是否成功的狀態，供調用方（CrawlerAgent）確認
