## 摘要

本文件定義了 PriceBackendService 新增的預測管理與社群管理 API，包含球種預測設定的增/查/改、球種清單與聯盟名稱取得、週結算日誌與預測注單查詢，以及社群群組的 CRUD。回應格式與參數枚舉值（如分類開關、啟用狀態、注單模式、Win/Loss 狀態、群組類型）均具體描述，可作為實現後端或與前端對接的規格參考。

---

## 關鍵業務規則

- - 預測設定中 Classified 為 true 表示分聯盟，false 表示不分聯盟；Enabled 為 0 停用，1 啟用。
- 取得球種聯盟名稱時，{lang} 應傳入 'zh-TW'，若無對應語言名稱則顯示英文。
- 預測注單中 mode 值代表玩法：1X2（獨贏）、HA（讓分）、OU（大小）；oddType 為 H（主）、A（客）、T（平）；winLoss 狀態包括 W（贏）、WR（贏一半）、L（輸）、LR（輸一半）、N（沒輸贏）、C（取消）。
- 週結算日誌中 done 欄位為 0 表示未結算，1 表示已結算。
- 社群群組 GType 必須為 'official'（官方）、'normal'（一般）或 'vip'（訂閱專用）其中之一。
- 更新週數計算結果時，使用 PUT /pricebackendservice/api/predict/calculalogs/{weekID}/result/reset 重置。

---

## 關鍵設計決策

- - 社群管理部分操作直接使用 WebSocket (WS)，因此 REST API 僅提供群組的基本 CRUD。
- 預測相關 API 採用 RESTful 設計，路由包含 gameType 和 lid 作為路徑參數，以區分球種和聯盟。
- 多語系支援：社群群組名稱以 object 格式提供各語言版本（zh-TW, zh-CN, en-US）。
