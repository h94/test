## 摘要

該文件定義了兩個提供賽事查詢的 API 端點：根據 sitegid 取得單場遊戲資訊，以及根據球種 gid 取得遊戲列表。為支援日曆功能（需要 7 天後的賽事），計畫將 Redis 快取範圍從原先設定調整為前一天至七天後的賽事資料。
