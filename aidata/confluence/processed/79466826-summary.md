## 摘要

定義了從 SMBC 網站抓取美元兌日圓匯率的爬蟲（SMBCFAgentV2）的資料格式、發送窗口與解析規則。輸出 JSON 包含固定貨幣對 USD/JPY，Bid/Ask 用正則從 HTML 提取，且只在每日四個 20 分鐘時段內每分鐘發送；休市日參考 historck 日曆停止發送。這些規則是開發此爬蟲 agent 的核心業務需求。

---

## 關鍵業務規則

- - 輸出固定格式：Site=smbc, Name=USD, Datum=JPY, RequestTime 與 SendTime 為 epoch 毫秒, Bid/Ask 為浮點數
- 只在四個時段內每分鐘發送資料：06:50-07:10, 09:50-10:10, 13:50-14:10, 16:50-17:10（需確認時區）
- 當日若為休市日（依 https://histock.tw/holiday.aspx?id=NKY 判斷）則不發送任何資料
- Bid 取值規則：正則 <td class="tRight">(.*?)</td> 全頁匹配後取清單第 0 個元素
- Ask 取值規則：同上正則，取清單第 1 個元素
- Dashboard 訊息顯示上一次成功發送的時間（HH:MM 格式）
