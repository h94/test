## 摘要

本文件定義了 PriceBackendService 分潤系統的 8 個 API，涵蓋運動站台報表的生成與查詢、提領紀錄的查詢與審核、以及會員驗證。對 AI 開發來說，提供了每個 API 的請求方式、參數格式、回應範例及關鍵狀態定義，有助於理解後端如何處理分潤與提領流程。

---

## 關鍵業務規則

- - 報表生成 API (POST /pricebackendservice/api/payment/sport/reports) 由 xxl-job 定時任務觸發，非人工直接呼叫。
- 驗證會員的 status 欄位值：0=處理中，1=完成，2=失敗；查詢時預設為 status=0。
- 更新提領紀錄結果 (PUT .../sport/withdrawlogs/{account}/{dateTime}/result) 時，若 status 設為 2（失敗），Remark 欄位不可為空。
- 更新驗證會員結果 (PUT .../member/game/verifyusers/{account}) 時，若 status 設為 2（失敗），Remark 欄位不可為空。
- 更新運動站台報表結果 (PUT .../sport/reports) 接受 dateTime 參數，格式為 yyyy-MM，預設值為當月的前一個月。
