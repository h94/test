## 摘要

本文件定義了 CrawlerAgent 從 betsapi 爬取多家博彩公司賽前與賽果數據的技術細節。包含各公司（bet365、bwin、betfair、sbo、1xbet）對應的 API 端點、請求參數及返回結構範例。明確列出須抓取的球種（sport_id）及對照表，僅少數主力球種如足球、籃球、棒球標記為抓取，inplay 資料只爬 bet365。為實作爬蟲服務提供可直接調用的 API 規格與篩選規則。

---

## 關鍵業務規則

- - 僅爬取球種表中標記為「O」的球種：bet365 只抓 Soccer(1)、Basketball(18)、Baseball(16)；bwin 只抓 Football(4)、Basketball(7)、Baseball(23)；betfair 只抓 Football(1)、Basketball(7522)、Ice Hockey(7524)；sbo 只抓 Soccer(1)。
- inplay 資料僅針對 bet365 進行爬取，其餘博彩公司不抓 inplay。
- 爬取內容包含各博彩公司的 pregame/upcoming 與 result 兩類資料，1xbet 亦提供對應端點但未列於主要目標中（需人工確認是否納入執行範圍）。

---

## 關鍵設計決策

- - 透過單一 API Token（115238-wN7vYiLlDnusyf）存取所有 betsapi 服務，以簡化授權管理。
- 依博彩公司區分不同的 API 路徑前綴（如 /v1/bet365/...、/v1/bwin/...），並依照官方文檔結構回傳 JSON。
- 球種篩選採用 betsapi 提供的 sport_id 作為過濾參數，直接在 API request 中傳入，不另行後處理。
