## 摘要

這份文件提供一個 NYSE（紐約證券交易所）的 API 端點，用於查詢歷史上因合併（Merger Effective）而下市的美股。透過調整 reason 參數可以查詢不同下市原因，haltDateFrom 可指定查詢起始日期，max 控制回傳筆數上限。此資訊可用於爬蟲程式抓取已下市股票清單，確保系統不再查價或顯示已終止交易的股票。對 AI 開發的幫助是：明確知道資料來源、參數格式，以及如何過濾已下市標的。

## 關鍵設計決策

- - 使用 NYSE 官方 API 的歷史停牌過濾端點來獲取下市資料，而非依賴第三方資料源
- 透過 reason=Merger%20Effective 篩選已合併公司，這些公司確定不會再出現交易股票
- 可透過 haltDateFrom 參數指定起始日期，實現增量爬取而非每次全量撈取
- max 參數設定為 9999 以單次請求取得最大筆數，減少分頁請求次數
