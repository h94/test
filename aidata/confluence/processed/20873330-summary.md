## 摘要

定義 ps3838 棒球/籃球賠率頁面的 HTML 抓取規則，包括時間、隊伍、1X2/半場1X2、讓分/半場讓分、大小分/半場大小分等欄位的對應標籤與屬性。提供最終輸出的 JSON 結構：每場比賽包含多個 PlayMode（HA, OU, Others-HalfHA, Others-HalfOU），每個 PlayMode 下含多組 Spread 與 Odd 值。對 AI 開發爬蟲 parser 提供明確的資料對照與統一的輸出格式。

## 關鍵設計決策

- - 使用 HTML class 名稱（如 col-time, col-name, col-1x2, col-hdp, col-ou）和 <td> 結構定位數據，避免依賴易變的 DOM 路徑。
- 透過 <a> 標籤的 data-oddsid, data-date, data-team-type 等屬性獲取賠率與隊型標記，並用 id 編碼區分玩法與盤口（格式範例：1335539455|0|1|0|0|0）。
- 輸出 JSON 設計採用 PlayMode 區分全場/半場 HA/OU，Spread 值記錄讓分或大小分數，Odd 物件的鍵（A/H/O/U/D）代表 Away/Home/Over/Under/Draw，值為賠率數字或 -1（表示未開盤/無賠率）。
