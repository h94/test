## 摘要

此文件定義了 CommunityService 的社群報表功能，包含四個後端 API，用於統計特定時間範圍內留言板的發文、回文、讚數量。提供全域統計和會員個人統計，支援依球種（game_type）和文章類型（arttype）過濾。回應格式涵蓋總數統計與明細資料，明細包含文章、回文、按讚及被按讚的詳細記錄。對 AI 開發而言，可明確了解報表查詢的輸入參數限制（如時間戳格式、必填/選填）、輸出欄位意義，以便整合或實作報表服務。

---

## 關鍵業務規則

- - 所有時間查詢參數 start 和 end 必須為 13 位毫秒時間戳，且 end 必須大於等於 start。
- 全域統計 API (/article_statics) 僅需 start 和 end，回傳文章總數、回文總數、按讚總數。
- 文章明細 API (/article_statics/detail) 的 game_type 參數為選填，預設不限球種。
- 會員統計 API (/user/<user>/statics) 回傳 fields: article_count（發文數）、comment_count（回文數）、like_count（按讚數）、receive_like_count（被按讚數）。
- 會員明細 API (/user/<user>/statics/detail) 的 user 欄位接受一個 list，最少須提供一個用戶；game_type 選填。
- 回應中的 like_count 欄位為物件，包含 like（或其他 emoji）的計數，但文件未詳述其他可能的 emoji 類型，需人工確認。
