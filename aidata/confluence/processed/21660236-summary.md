## 摘要

這是一份 FrontEndSite（.NET Core）的 API 規格文件，定義了一個 GET /adv/advertisingData 端點，接受 type 字串參數，回傳 List<Advertising> 結構（包含 Type、Title、Path、Url、Seq 五個字串欄位）。此 API 會進一步呼叫後端服務（Call Service = True），用途為取得指定類型的廣告資料。對 AI 開發的幫助：若 AI 需要在前端呈現廣告，可藉由此 API 取得廣告列表與相關跳轉資訊。

## 關鍵設計決策

- - 採用 HTTP GET 方法，以 query string 傳遞 type 參數進行廣告類型篩選
- 回應模型 Advertising 統一包含 Type、Title、Path、Url、Seq 五個欄位，前端可直接取得廣告標題、圖片路徑、導向連結與排序號
- API 層作為 BFF，Call Service 標記為 True，隱藏後端服務細節，實作上會轉發請求至對應的廣告服務
