## 摘要

本文定義了從 TWSL 官方網站抓取中文隊名與聯盟的爬蟲需求。需呼叫 TWSL GameResult API，使用不同 GameType（SC/BK/BS）、DayNum、Page 參數分批取得賽事資料，從回應中解析聯盟代碼、主客隊中文名稱，再透過內部 API 寫入資料庫，提供給賽事合併模組使用。開發時可依此文件建立爬蟲任務的參數範圍與欄位對應。

---

## 關鍵業務規則

- - 爬取來源為 TWSL API: https://www.sportslottery.com.tw/api/services/app/GameResult/GetPagedSearchResult
- API 參數 GameType 對應運動類型：SC=441, BK=442, BS=443
- DayNum 參數可填 1/3/7/21/30/90，對應不同回朔天數
- Page 參數範圍 1-10，每種運動每日最多取得 10 頁
- 從回應 JSON 中提取聯盟欄位為 'ln'，主隊為 'htn'，客隊為 'atn'
- 整理後的隊伍與聯盟資料需透過內部 API POST 到 DB（未指定 API endpoint）
- 本爬蟲係以現有 TWSL Result 爬蟲為基礎擴充或重用（設想階段）
