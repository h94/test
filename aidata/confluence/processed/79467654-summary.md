## 摘要

本文件定義在彩池遊戲相關服務中新增「Hot」欄位以支援首頁熱門設定。PriceBackEndService 的更新彩池 API 增加 Hot 欄位，並強化原本的狀態更新限制：當 Status=1 時只能修改特定欄位，Status=0 時可修改全部；PredictService 的快取生成、查詢和更新 API 也同步加入 Hot 欄位。對 AI 開發而言，提供了明確的請求/回應結構變更與業務驗證規則，可直接用於生成前端表單、後端校驗或自動測試案例。

---

## 關鍵業務規則

- - PriceBackEndService 更新預測彩池遊戲 (PUT /pricebackendservice/api/predict/betpool/games/{id})：如果 Status = 1，只能更改 FeedRate、BonusProfitZcoin、Status；如果 Status = 0，則可以更新全部欄位。
- BasicProfitZcoin、FeedRate、ZcoinPrice、BonusProfitZcoin 不得小於 0。
- Names 語系至少要有 zh-TW。
- Status 只能是 0 或 1。
- BetOptions 至少要有兩個，且內容中至少要包含 zh-TW 語系。
- 在 PriceBackEndService 和 PredictService 的相關 API 中，Request/Response 皆新增 Hot 欄位（boolean 型態）。
