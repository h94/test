## 摘要

本文件定義了爬取 HUANG CHUANG 網站全場及半場賠率的技術方案。透過 Selenium 自動登入取得 headers，再利用 POST 請求獲取所有比賽 matchid，最後根據 matchid 查詢各比賽賠率。說明了 API 請求參數與流程。

- - 採用 Selenium 自動登入以取得必要的 headers，而非直接模擬登入請求，推測因網站有複雜的前端驗證。
