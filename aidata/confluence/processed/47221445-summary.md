## 摘要

本文件定義在 pricecenter schema 的 sitegames_result 表新增多個欄位，以支援棒球賽事的進階統計顯示。這些欄位包括系列賽場次、初始賠率、主客隊本季勝率、當前連勝情形，以及三種歷史對戰記錄（客隊對非主隊、主隊對非客隊、兩隊直接對戰）。歷史記錄以 JSON 陣列字串儲存，便於前端直接解析展示。此設計為後續賽事分析與數據呈現的基礎。

---

## 關鍵業務規則

- - series 欄位表示該場為系列賽的第幾場，預設值為 1。
- firstspread 為初始賠率，mainspread 為收盤賠率。
- winrate_h / winrate_a 以字串形式表示主／客隊本季勝率，如 “0.434”。
- currentstreak_h / currentstreak_a 表示連勝情況，正數為連勝場數，負數為連敗場數（例如 +3 表示連贏 3 場，-1 表示輸 1 場）。
- latest_10_a_any / latest_10_h_any / latest_10_same_team 分別儲存客隊與非主隊、主隊與非客隊、以及兩隊間的最近多場歷史對戰記錄，格式為 JSON 陣列，每筆紀錄包含日期、時間、賽事 ID、比分、對戰隊伍與狀態等。

---

## 關鍵設計決策

- - 歷史對戰紀錄以 VARCHAR 儲存 JSON 字串而非正規化為獨立表，降低讀取時的 JOIN 成本並保持 API 輸出簡潔。
- 地圖類型欄位（resultinfo, otherinfo, moneylineodd）使用 MAP 結構提供動態屬性的彈性。
- 表以 (site, sitelid) 為分區鍵，並按 gdate DESC 進行叢集排序，有利於查詢特定站點的最新賽事。
