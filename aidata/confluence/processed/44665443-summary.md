## 摘要

文件說明如何為 Python API 在 PRD 環境設定 Gateway，包含六個步驟：更新 K8S PortList 登記 port、在 Gateway 管理介面新增 API、設定 API Clusters、API Teams（PRD 需勾選 ZB）、以及設定 API Routings 路徑。核心規則包括 Gateway port = docker port + 10000、URIPath 必須以 API 名稱小寫開頭且包含 'api' 字樣。此文可協助開發人員正確部署新服務到 Gateway，避免 port 或路徑設定錯誤導致請求無法路由。

---

## 關鍵業務規則

- - K8S PortList 中的 port 必須依照順序填寫（不可跳號）。
- Gateway 上設定的 port = docker port + 10000（PRD 環境）。
- API Routings 的 URIPath 第一個字必須是 API 名稱（小寫），且路徑中需包含 'api' 字樣，例如 /sitegameoddservice/api/odd/history/main。
- PRD 環境的 API Teams 設定必須勾選 ZB，LOCAL 環境則取消勾選 ZB。
- API Clusters 和 API Routings 的設定需各自點選儲存，不可批次儲存。
