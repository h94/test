- - Sprint 開始前需完成需求確認、Sprint 建立、分支建立及 Sonarqube 掃描取得警告數與 UT 覆蓋率

- 新增 Service 或 API 接口時，需檢查 Gateway 是否已配置對應路由

- Code Review 後須確認所有審查意見均已被修改或記錄
