## 摘要

本文件定義 PriceCenterSite 提供給球王平台的 RESTful API 清單，涵蓋身分驗證申請與查詢、提領紀錄新增與查詢、分潤報表查詢等功能。所有 API 均以 authKey 進行授權，身分驗證狀態有 0(處理中)、1(成功)、2(失敗) 三種，分潤報表包含月收入、解鎖次數、分紅比例等欄位，有助於 AI 理解對第三方平台開放的價格中心站點服務邊界與資料結構。

---

## 關鍵業務規則

- - 身分驗證狀態(status)列舉值：0=處理中，1=成功，2=失敗
- 分潤報表明細中 finishing 為 boolean，用於標記是否已結算
- 所有 API 端點均需透過 authKey 進行授權存取
- 提領紀錄新增時，必須提供 Amount (提領金額) 與 WithdrawPW (提領密碼)

---

## 關鍵設計決策

- - 採用 authKey 作為每個使用者的安全令牌，統一管理 API 存取控制
- 身分驗證資料使用外部圖片 URL (inplayz.com) 儲存，而非直接上傳文件流
