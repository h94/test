## 摘要

本文件說明如何透過 NFL 官方 API 取得賽程、賽事詳情與即時球員數據，包含兩個主要端點（weeks/date 與 weekly-game-details）、授權 token 的取得方式（Selenium 操作 localStorage）、以及 API 回應的欄位對應規則。這對 AI 開發爬蟲與解析模組有直接幫助，能快速建立 NFL 即時資訊的資料擷取流程。

---

## 關鍵業務規則

- - 比賽狀態依據 summary 欄位判斷：若 summary 不存在則 status = '2' (未開始)；若 summary.phase = 'INGAME' 則 status = '0' (進行中)；若 summary.phase = 'FINAL' 則 status = '1' (已結束)。
- league 固定為 'nfl'；game_type 固定為 'FL'，因為本專案僅處理 NFL 比賽。
- 比賽日期與時間使用 API 回傳的 time 欄位進行時區轉換。

---

## 關鍵設計決策

- - 授權部分：API 請求需帶 Bearer token。token 不透過一般登入獲取，而是以 Selenium 打開 NFL 官網，接受 cookies 後從 localStorage 讀取 'nfl.refreshableToken.v3' 中的 accessToken，以繞過複雜的前端授權流程。
- 資料擷取分三步驟：先呼叫 /weeks/date/{today} 取得當週與賽季資訊，再以 season 和 week 呼叫 weekly-game-details 取得當週所有比賽總覽，最後可選用 stats/live/player-statistics/{game_id} 取得單場詳細數據。
- 解析規則：將 API 回傳的 JSON 欄位直接對應到系統需求的固定結構，如主/客隊名稱、分數、各節分數、比賽時間等，並明確定義了 playbyplay 的呈現格式（例如 'Q3 00:58'）。
