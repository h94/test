- - 每日會議需確認成員問題，若影響時程應立即回報上級。

- 測試階段需監控 Bug 數是否收斂。
- 測試後期應要求成員補齊分析文件。
- 下班前確認 JIRA 問題與回覆均已填寫。
- 若線上問題需長期關注，應於 JIRA 開立 Task 追蹤。
- 如有新增 Service 或 API 接口，需檢查 Gateway 配置並更新對應的 swagger.json。
- Sprint 結束後需回報 PRD 監控結果。
