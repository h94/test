## 摘要

本文件定義新運彩專案中兩個功能模組：1) 買賣牌功能，使用者可在「我的競猜」中設定是否上鎖及解鎖價格，預設為公開狀態；2) 會員大頭貼上傳功能，使用者點擊頭貼選擇圖片後即時上傳。大頭貼會顯示在多個頁面，包括討論區文章列表、文章內文、關注列表、玩家搜尋等，但部分頁面（彩池得獎名單、排行榜）目前 API 回傳尚未包含大頭貼資訊，需人工確認後續實作範圍。

---

## 關鍵業務規則

- - 買賣牌：使用者可自行設定是否上鎖，預設為公開狀態
- 買賣牌：使用者可自行設定解鎖價格（需人工確認價格單位與限制）
- 會員大頭貼：點擊頭貼選擇圖片後即時上傳，無需額外確認步驟
- 會員大頭貼：討論區文章列表、文章內文（作者、留言者、按讚紀錄）、關注列表、玩家搜尋等頁面均需顯示用戶大頭貼
- 會員大頭貼：彩池得獎名單頁面目前 API 回傳無大頭貼資訊（⚠️ 需人工確認是否需補上）
- 會員大頭貼：排行榜頁面目前 API 回傳無大頭貼資訊（⚠️ 需人工確認是否需補上）
