## 摘要

本文件定義了球王主推闖關活動（nba-mainwinstreak）所需的六個 REST API，涵蓋活動商品兌換紀錄、商品列表、使用者兌換紀錄、主推連勝排行榜、勝率排行榜和會員活動紀錄。文件提供了完整的請求與回應格式、狀態碼含義，並在設想區塊說明了關鍵業務規則：連勝排行會排除中斷或已兌換獎勵的用戶，單月獲利排行只顯示正獲利的前9名，連勝次數對應商品價格（規則未詳述）。這些 API 規格可直接用於開發活動頁面與後端邏輯。

---

## 關鍵業務規則

- - 主推連勝排行榜：若玩家中途兌換獎勵或中斷連勝，則從榜上除名。
- 單月獲利排行只取前9名且會員必須有正獲利才顯示。
- 連勝次數與活動商品價格存在對應關係（具體對照表未提供，需人工確認）。
- 商品狀態 status=1 代表販售中，status=2 代表已售完。
- 兌換紀錄狀態 status=0 代表申請中，status=1 代表成功，status=2 代表失敗。
- 商品 redeemTime 欄位為 true 表示可兌換時間，false 為不可兌換。
- 連勝排行榜未登入或不在榜上時，userDetail 為 null；勝率排行榜未登入或不在榜上時，monthlyUserRanking 為 {}，僅有排行的月份才有對應資料。
- 勝率排行榜的 monthList 按月份由大到小排序。

## 關鍵設計決策

- - API 採用 RESTful 設計，將 site 與 activityEvent 作為路徑參數，authKey 用於身份驗證（部分端點的查詢參數）。
- 排行榜回應分開 leaderboardDetails 與 userDetail，便於前端同時展示整體排行與登入用戶自身排名。
- 勝率排行榜按月組織，月列表獨立提供，並以 monthWinRateLeaderboards 陣列包含各月詳情，便於前端切換月份。
