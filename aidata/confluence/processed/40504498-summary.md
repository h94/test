## 摘要

本文件規劃在 inPlay/pregame 分析頁新增賽事賠率 Log 走勢圖。前端使用 Canvas 繪製，依 show_mode 決定繪製 only_spread（僅盤口變動）或 spread_odd（盤口與賠率皆變動）。時間範圍可選擇「當前往前區間」或自訂起迄時間，X 軸自動根據時間跨度採用 24 小時或 12 小時為刻度單位，Y 軸則由資料 range 決定。提供取得 sitegame 的 API 規格與 Figma 設計稿，為開發該圖形元件提供清楚的規格依據。

---

## 關鍵業務規則

- - 時間區間選擇有兩種模式：以當下時間為結束往前選定區間，或直接指定開始與結束時間。
- X 軸時間刻度規則：計算結束時間與開始時間的秒差，依序嘗試除以 86400 秒（24 小時制）及 43200 秒（12 小時制），若結果 >= 1 則採用該單位作為間隔；起始刻度為開始時間，之後每隔一單位標記時間（例如 00:00→04:00... 或 00:00→02:00...）。
- 圖形區分兩種模式：only_spread（球頭會變，賠率不變）和 spread_odd（球頭會變，賠率會變），由 API 參數 show_mode 決定繪製哪種型別。
- 縱軸範圍直接使用資料提供的 range，不經前端計算。

## 關鍵設計決策

- - 選擇 Canvas 而非 SVG 繪製走勢圖（文件未說明原因，推測效能與複雜度考量）。
- 由 API 的 show_mode 參數控制走勢圖顯示類型，將兩種場景整合在同一組件，透過模式切換繪製。
- 時間單位自動化判斷機制，先以 24 小時為基準，若時間跨度不足再降級為 12 小時，確保 X 軸刻度不致過密或過疏。
