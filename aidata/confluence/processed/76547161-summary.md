## 摘要

這份文件定義了 CrawlerAgentAipredict 服務擴充抓取 MLB 和 NHL 賽事預測數據的技術方案。對 AI 開發的幫助在於：明確規定了從四個外部站台（sportsline、oddstrader、dimers、picksandparlays）抓取 AI 預測的 API 架構、資料格式及解析流程。文件詳細說明了如何透過 DataProvider 和 DataTransformer 的流程區分站台、如何解析各站台特定的 HTML 或 JSON 資料，以及最終存入 DB 前所需生成的預測值（predict_OU, predict_HA）和遊戲 ID 的組合規則。

## 關鍵設計決策

- - 採用 page_type（網站名稱）區分不同來源的數據解析方法（sportsline、oddstrader、dimers、picksandparlays）。
- game_id 的產生方式：串接 league, team_home, team_away, game_date, game_time 五個欄位，再使用 MD5 哈希生成，確保唯一性。
- league 欄位的定義規則：使用「網站名稱_聯盟」格式區分，例如 sportsline_NBA、dimers_MLB。
- AI 預測結果的封裝方式：將預測的大小分（predict_OU）與讓分（predict_HA）以及投注建議（bet_OU, bet_HA）統一放入 Match 物件的 OtherInfo 欄位，以 JSON 格式儲存。
- sport_id 的對應關係：oddstrader 中不同聯盟需使用特定 ID（如 NBA 為 5, MLB 為 3）進行 API 請求，更多 ID 需參考其他文件。
- 數據解析策略差異化：sportsline 和 oddstrader 需解析 HTML 並從 JS 變數中提取 JSON，dimers 和 picksandparlays 則直接使用 API 返回的 JSON。
