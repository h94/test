## 摘要

為控制 PriceCenter 中 Page 資料的增長，需定期刪除 Bwin 與 Betfair 來源、Enable 欄位為 0（已結束）的賽事。刪除作業須記錄於 Log 表，並提供兩支 HTTP DELETE API 端點供排程或外部呼叫，此規則對 AI 開發 PriceCenter 服務時需實作定時清理與操作記錄功能。

---

## 關鍵業務規則

- - 系統必須支援定期刪除 Bwin 與 Betfair 中 Page.Enabled = 0 的賽事資料。
- 每次執行刪除時，被刪除的賽事記錄必須寫入 Log 表（交易日誌）。
- 提供 API 端點供觸發刪除：DELETE v1/bwin/RBG/delete（處理 Bwin 賽事）與 DELETE v1/betfair/RBG/delete（處理 Betfair 賽事）。
- 此功能優先級為「極高」。
