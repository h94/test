## 摘要

此文件定義了玩運彩爬蟲的技術實作細節。內容包括爬取目標（聯盟賽事、國際盤球頭預設賠率 0.95、棒球先發投手、預測人數百分比）、API 格式與參數、棒球專屬的先發投手本季戰績與近五場對戰紀錄爬取邏輯、以及主客隊團隊打擊數據的爬取。也包含了部署位置（SRV32/114/126 的 playsport 容器）和資料最終寫入 other_info 欄位的 JSON 結構。

---

## 關鍵業務規則

- - 國際盤球頭沒有給賠率時，預設為 0.95。
- 棒球賽事需額外爬取先發投手資訊（名稱、防禦率、本季戰績、近五場對戰紀錄）。
- 足球賽事格式與其他聯盟不同，唯一提供賠率的聯盟，且沒有提供 teamid。
- 投注比率有兩種格式（HA 讓分盤、OU 大小盤）。
- pregame 和 result 兩種資料格式不同，需分開處理。
- 爬取預測人數百分比。
- 2025.08.04 新增：在 parser 中判斷是否為棒球，若是則進入單場頁面解析先發投手本季戰績及近五場對戰紀錄。
- 2025.08.06 新增：爬取主客隊團隊打擊數據，包含主場、客場、對戰、近七場、本季、本月、面對左右投、日夜場等多種情境數據。

---

## 關鍵設計決策

- - 選擇以 API 直接呼叫 https://www.playsport.cc/predictgame.php 取得賽事資料，而非 HTML 爬取，提高穩定性。
- 棒球賽事的先發投手資訊需進入單場頁面解析 HTML 取得，因為 API 未直接提供。
- 所有非結構化或額外爬取的資訊統一寫入 other_info JSON 欄位，保持主資料表結構不變。
- 團隊打擊數據根據不同聯盟提供不同情境的統計（如 MLB 提供 at_home、at_away、vs_home、last_7games、this_season、this_month、vs_right_pitchers、vs_left_pitchers、day_game、night_game），其他聯盟可能只提供部分，需在爬取時動態判斷。

## 注意事項

- ⚠️ - ⚠️ 足球賽事格式特殊，沒有 teamid，需注意 parser 的例外處理。
- ⚠️ 投注比率有兩種格式（HA 和 OU），資料結構可能不同，需確認 parser 相容性。
- ⚠️ 先發投手的 use_hand 欄位不一定有值，開發時需處理空值情況。
- ⚠️ 團隊打擊數據中，不同聯盟提供的統計項目不同（如 CPBL 只提供 this_season），爬蟲和 parser 需有條件判斷邏輯。
- ⚠️ 部署位置提到 Local、PRD2、PRD3 不同環境，需確認容器名稱和環境變數配置。
