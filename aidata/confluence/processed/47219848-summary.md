## 摘要

本文說明如何透過 MLB Stats API 取得賽程與比賽資料，包含兩個端點：主體比賽資料 API（依日期獲取當日所有比賽摘要與逐局分數）與 playbyplay API（根據比賽 ID 取得詳細攻守過程並解析為標準格式）。內容提供實際回應範例與欄位說明，可直接用於 CrawlerAgent 的爬取與解析邏輯實作。

---

## 關鍵業務規則

- - 主體比賽資料 API 使用日期格式 YYYY-MM-DD 作為參數，例如 2023-03-23
- playbyplay API 的 URL 須代入比賽 ID，格式為 https://statsapi.mlb.com/api/v1/game/{gamePk}/linescore
- playbyplay 結構須從 linescore 回應中提取當前局勢、投打資訊、壘包狀態與好壞球數
