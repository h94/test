## 摘要

定義廣告服務的 REST API 與資料庫結構，包含新增、修改、取得廣告三個端點。取得廣告時可按 Type 篩選，並以 seq 降冪排序展示。DB 表格 advertising 記錄廣告名稱、類型、圖片路徑、活動連結、排序、啟用狀態及有效時間，可作為實作廣告管理和前台展示的技術基底。

---

## 關鍵業務規則

- - 廣告展示順序依 seq 欄位降冪排序，數值越大越優先展示。
- 廣告狀態 (enabled) 0 為關閉，1 為開啟。
- 取得廣告時需傳入 Type 參數進行篩選，Type 值代表廣告類別（如 promotion 或 advertising）。
- createdby 欄位值 'promotion' 表示自家優惠，'advertising' 表示客戶廣告。

---

## 關鍵設計決策

- - API 採用 POST 方法進行新增與修改，GET 方法進行查詢，符合常規資源操作慣例。
- DB 主鍵 id 採用 text 類型而非整數或 UUID，可能用於存入自定義唯一標識。
