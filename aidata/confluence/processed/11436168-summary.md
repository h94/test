## 摘要

这份文档展示了 Pinnacle API 返回的 Match Data 和 Odds Data 的 JSON 结构示例。包含比赛基本信息、联赛、参与者、时段、盘口类型（独赢、让球、大小、球队总分）以及赔率、限额等字段。对 CrawlerAgent 解析 Pinnacle 数据格式、映射到内部结构有参考价值。

## 關鍵設計決策

- - Period 字段 0 表示全场，1 表示上半场。
- 盘口类型由 type 字段区分：moneyline, spread, total, team_total。
- 赔率 price 正数表示净赢金额（如 +398），负数表示需投入金额赢 100（如 -143）。
- 每个盘口附带 limits 数组，包含 maxRiskStake 类型，表示最大风险投注额。
- key 字段编码了运动类型、时段、盘口类型和点位，例如 's;0;m' 表示足球全场独赢。
- isAlternate 字段标记是否为替代盘口（非主要盘口）。
