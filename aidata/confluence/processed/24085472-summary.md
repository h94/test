## 摘要

本文件定義討論區付費文章功能之前端與支付服務串接設計。重點包含：區分需付費與免付費貼文、查詢會員購買記錄、購買文章時扣除點數的 API 規格。提供前端渲染付費標示與購買介入點的 PHP 檔案修改位置。對 AI 開發 paymentservice 與前端討論區模組，可理解服務邊界、API 請求/回應格式，以及需與 memberservice 協作的點數扣除行為。

---

## 關鍵業務規則

- - 貼文渲染時需顯示價格標示，並區分需付費與免付費貼文。
- 系統須提供個人已購買貼文查詢功能，前端以此判斷使用者是否已購買特定貼文。
- 使用者購買貼文時，後端應扣除對應點數（Price 欄位），完成購買交易。

---

## 關鍵設計決策

- - 購買文章 API 採用 POST /api/payment/buyarticles，傳遞 AuthKey、P_id、P_name、Price。
- 會員購買文章紀錄查詢 API 採用 GET /api/payment/getmemberarticle，透過 authkey 與 p_id 查詢。
- 前端修改點：貼文連結邏輯位於 wpforo 插件的 functions-template.php 第 3053 行；文章標題顯示邏輯位於 topic.php 第 34 行。
