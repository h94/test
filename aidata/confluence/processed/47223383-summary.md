## 摘要

本文件記錄了在 PriceCenterSite 下新增「球王冥燈排行榜」與「球王社群聊天室」的兩項功能需求。對 AI 開發而言，這份文件說明了 predictservice 的排行榜 API 回應中會新增「lastSevenWorst」欄位來支援冥燈排行榜，以及 communityservice 需要支援社群群組圖片上傳與列表查詢。文件也暗示社群聊天室功能可能獨立於現有排行榜邏輯之外。

---

## 關鍵業務規則

- - 預測排行榜 (predict/leaderboard) API 的回應中新增 lastSevenWorst 欄位，用於呈現「冥燈排行榜」，包含帳號、勝率、獲利點數等資訊。
- 社群群組 (community/groups) API 需支援以 lang 參數查詢不同語系的群組資料。
- 上傳社群群組圖片 (community/groups/{id}/upload) 使用 POST 方法，並以 form-data 格式上傳 file 欄位。

---

## 關鍵設計決策

- - 冥燈排行榜的數據來源與表現形式與現有預測排行榜相同，僅篩選條件不同（表現最差者），故決定在現有 API 回應中新增一個 lastSevenWorst 的資料區塊，而非建立新端點。
- 社群聊天室的功能被拆分為獨立的 group 資源，透過 community 相關路徑操作，與預測功能解耦。
