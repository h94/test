## 摘要

這份文件列出了 BacktestingService 的所有 REST API 端點，包含新增策略、更新自動化狀態、取得待回測頁面、回傳計算結果、查詢與刪除策略等功能。開發者可藉此了解回測引擎的互動方式，例如如何提交策略（含技術指標定義）、如何獲取回測任務、以及如何回寫已計算的損益與詳細明細。其中註明一個 API（closepage）已廢棄但保留為 pass，另一個依 hashkey 查詢的 API 已被停用。

## 關鍵設計決策

- - 策略資料以 account + addtime + hashkey 作為複合唯一鍵進行識別與操作。
- 回測結果分為 soldout（已賣出）、unsold（未賣）兩類，分別記錄實現損益與未實現損益，並計算總體預期報酬。
- closepage 端點已標示無用，但 API 仍存在並直接 pass，屬於相容性保留。
- 以小工具 GET /api/v1/stock/backtesting/countrestore 將 COUNT3 歸零，暗示內部計數器需手動重置。
- 策略中策略規則以 JSON 結構表示，包含技術指標名稱、參數、比較運算符與描述文字（如 {"value":["SMA","5","大於","0"],"text":"SMA5乖離率大於0"}）。
