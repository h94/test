## 關鍵業務規則

- - 如有新增 Service 或 API 接口，必須檢查 Gateway 是否已配置相關路由
- 如有新增 Service 或 API 接口，必須修改對應的 swagger.json 文件（修改步驟參見 Confluence 頁面 ID 5341691）
- 測試後期需請開發成員補齊需求分析文件（Confluence Page）

- 測試階段需關注 Bug 數量是否收斂，若未收斂應及時反應
- 若出現需長期關注的線上問題，應於 JIRA 開立 Task 持續監督
