## 摘要

本文件說明 StakeProvider 爬蟲如何從 Stake.com 擷取體育賽事與賠率資料。核心技術包含使用 GraphQL API (固定 query 字串與動態 variables) 取得聯盟所有比賽及單場比賽的多玩法；透過 undetected_chromedriver 繞過 Cloudflare 5 秒盾，再以 curl_cffi 模擬 TLS 指紋處理不同 IP 的防護機制；並透過 x-language Header 設定多語系。對 AI 開發爬蟲服務而言，本文件提供了 StakeProvider 的完整實作藍圖與防封鎖對策。

## 關鍵設計決策

- - GraphQL 查詢字串因不同用途（聯盟比賽 vs. 單場比賽）而異，故將各個 query 字串寫死在程式碼中，呼叫時動態帶入變數，維持請求結構一致且易維護。
- 單場比賽資料一次請求即可取得多個 groups (玩法組)，減少 API 呼叫次數，降低被封鎖風險。
- Cloudflare bypass 區分兩類 IP：有 5 秒盾的 IP 用 undetected_chromedriver 取得 cf_clearance 與 User-Agent 後，透過 curl_cffi.Session 後續請求；無 5 秒盾但會檢查 TLS 指紋的 IP 則直接以 curl_cffi 模擬指紋，避免 requests 403 錯誤。
- 球種僅抓取常用項目（足球、籃球、棒球、冰球、美足、網球、桌球、水球、羽球），因站台防護嚴格，減少不必要的請求以降低風險。
