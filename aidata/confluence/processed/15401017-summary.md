## 摘要

本文件提出一個 Chrome Extension 方案，作為抓取 Bet365 SCG 頁面 HTML 的第二方案。需先模擬點擊以展開頁面標籤，再爬取完整 HTML，並將資料發送到 Kafka。對 AI 開發而言，可了解 Crawler 服務如何處理需要互動的動態頁面，以及資料流的傳遞方式。

---

## 關鍵業務規則

- - 爬取 SCG 頁面 HTML 前，必須先模擬點擊以展開頁面上的標籤（需求極高）
- 爬取完成的 SCG 頁面 HTML 必須讀取後送至 Kafka（需求極高）

---

## 關鍵設計決策

- - 採用 Chrome Extension 而非其他抓取方式，因需處理動態標籤展開，此為第二方案，暗示第一方案可能無法滿足需求
- 從 Page 表取得網址，進入後模擬點擊再抓取，確保取得完整展開後的 DOM
- 資料傳輸選用 Kafka，以非同步訊息方式將 HTML 送往後續處理
