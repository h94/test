## 摘要

本文件规划前端多语言功能的实现方案，支持繁中、简中、英文、日文四种语言切换。静态界面内容由 i18n 套件处理，动态数据（如队伍名称）通过调用 API 获取翻译映射表来转换。该设计分离了前后端翻译职责，对 AI 理解多语言数据流和翻译服务接口有帮助，尤其需关注 translateservice 如何提供映射数据及前端如何消费。

## 關鍵設計決策

- - 前端采用 i18n 套件管理静态文案，与后端 API 翻译映射解耦
- 动态内容（如队伍名称）的翻译数据由后端 API 提供 mapping 表，保证数据一致性
- 用户可自行选择网页语言，语言选项包括繁中、简中、英文、日文
