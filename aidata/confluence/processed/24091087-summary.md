## 摘要

本文件定義了新版爬蟲代理 (pesa parser) 針對不同球種及玩法的解析規則。核心內容是一個「球種-玩法-代號」對照表，記錄賽前(Pre-Game, 用 id 識別)與走地(In-Game, 用 type 識別)的同一個玩法可能有不同的代號。同時也記錄了各玩法的原始 JSON 資料結構與畫面對應圖，作為 AI 開發爬蟲規則時的關鍵參照。

---

## 關鍵業務規則

- - 賽前(Pre-Game)的玩法識別欄位為 id，走地(In-Game)的玩法識別欄位為 type，同一個玩法可能對應不同的 id 與 type 數值。
- 足球：亞洲讓分(HA)賽前代號 51，走地代號缺失需人工確認；亞洲上半讓分(HalfHA)賽前代號 53，走地代號缺失。總入球數賽前代號 202，走地代號缺失。
- 足球：全場讓分賽前代號 10，走地代號 2，但全場大小賽前代號 52，走地代號 259，走地代號可能比賽前代號大。
- 足球：角球讓分、每15分讓分大小等玩法在表格中走地部分有 In-Game 標記 'X'（表示無走地）或代號留空，但角球大小走地代號為 7478，賽前代號缺失需人工確認。
- 籃球：第一至四節讓分走地玩法有兩種代號格式（如 1st QuarterRBHA 對應 6847，1st QuarterRBHA (1X2) 對應 6981），需在解析時區分。
- 冰球：全場讓分區分「不包括加時」與「包括加時」，前者的 id 可能與足球共用（代號 10⚠️需人工確認），後者代號為 378。全場大小同樣區分，不包括加時代號 60，包括加時代號 377。
- 網球：盤數讓分(GameHA)走地代號 311，對應賽前代號 51；局數讓分與大小僅列出走地代號或賽前代號缺失，賽前 X 標記表示無賽前玩法。
- 棒球與電競：表格中玩法、代號皆為空白，表示尚未實作或未定義規則。
- 格鬥/拳擊：全場讓分表格中列出兩個代號 382 與 20，可能代表不同細項玩法，但玩法名稱欄位為空，需人工確認。
- 同一球種的讓分玩法可能同時存在 1X2 格式與非 1X2 格式，兩者代號不同（如籃球全場讓分 HA-1X2 賽前為 382，HA 賽前為 51）。

---

## 關鍵設計決策

- - 採用表格統一對照所有球種的玩法名稱、賽前代號(id)、走地代號(type)及 JSON 結果範例，便於爬蟲程式直接參照。
- 明確區分亞洲盤（讓分/大小）與 1X2 盤口的代號，反映 PesA 資料源的特殊結構。

---

## 注意事項

- ⚠️ - ⚠️ 多個走地代號或賽前代號在表格中為空（如角球、罰牌、電競、棒球），可能為未完成的需求或文件過時，開發時需檢查實際資料來源是否包含這些欄位。
- ⚠️ 冰球全場讓分（不包括加時）的代號為 10，但足球全場讓分賽前代號也是 10，可能為共用代號，需在程式邏輯中依球種區分。
- ⚠️ 格鬥/拳擊的第二個玩法代號 20 缺少對應的 In-Game 標記與玩法名稱，需人工確認其業務意義。
- ⚠️ 表格中網球、電競等球種的走地與賽前支援標記（O/X）可能已過時，需對照當前 PesA API 回應。
