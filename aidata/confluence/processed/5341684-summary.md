## 摘要

本文件詳列 PriceCenter Service 使用的 Cassandra 資料表結構，包含依 GameType 區分的賽事相關表格（_BS、_BK、_HL、_FL）與站台帳號、爬蟲頁面設定等輔助表格。提供自動建表 API (v1/system/autocreatetable) 的運作方式：透過 AppSetting 新增 GameType 後，API 會先檢查表格是否存在，若無則自動建立；但若需修改欄位，必須手動更新此 API 程式碼。部分表格（如 performance）不會被自動建表流程涵蓋。此定義是理解與操作 PriceCenter 資料庫的核心技術規格。

---

## 關鍵業務規則

- - 自動建表 API 在創建表格前會先檢查該表格是否已存在於 DB，僅在不存在時才執行創建。
- 在 AppSetting 中新增欲支援的 GameType 是使用自動建表功能的前置必要步驟。
- autocreatetable API 不涵蓋 'performance' 表格的建立。

---

## 關鍵設計決策

- - 採用 Cassandra 資料庫，以 (site, gamedate, sitegid) 等組合作為分區鍵與聚簇鍵，並建立物化視圖（如 odds_BK_view）以支援不同查詢方向。
- 自動建表 API 提供動態擴展 GameType 的方案，但欄位結構的變更仍需手動修改 PricecenterService 內的 autocreatetable API 程式碼，而非全自動化。
- 表格依 GameType 後綴區分（如 _BS、_BK），使不同運動類型的資料隔離，結構相似但獨立儲存。

---

## 注意事項

- ⚠️ - ⚠️ 若需新增或更動資料表欄位，必須手動至 PricecenterService 修改 autocreatetable API，此設計可能導致程式碼與實際表格結構不同步的風險。
- ⚠️ 文件內 INSERT 語句範例的日期為 2020/09/21，可能僅為初始設定，實際運作值需人工確認。
