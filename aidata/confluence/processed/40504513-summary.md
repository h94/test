## 摘要

這份文件定義了賠率走勢圖的 API 設計，包含請求參數規範與兩種賠率變化模式的響應格式。對於 AI 開發 crawleroddtrend 服務的幫助在於：了解 API 需要從 pricecenter 資料庫的 odds_his_{game_type} 表查詢歷史賠率資料，並根據不同站台特性採用 only_spread 或 spread_odd 兩種模式組裝座標資料回傳給前端繪圖。

---

## 關鍵業務規則

- - 賽前玩法 mode 參數值為 HA 或 OU，賽中玩法 mode 參數值為 RBHA 或 RBOU
- only_spread 模式適用於 ku888、nk.net、kkk.net 三個站台，其餘站台使用 spread_odd 模式（需人工確認其餘站台是否全為 spread_odd）
- only_spread 模式中，o_spread 值為原始資料（如 1+50、1-50），spread 值為經公式轉換後的量化資料，圖形縱軸定位用 spread，但顯示標籤需用 o_spread

---

## 關鍵設計決策

- - 選擇以 API 形式提供座標點而非直接渲染圖形，由前端自行繪製走勢圖
- only_spread 模式需要同時回傳原始資料(o_spread)與量化資料(spread)，因為 1+50 和 1-50 這種格式無法直接比大小，必須先套公式轉換再定位座標點
- spread_odd 模式按球頭分組回傳，每個球頭下包含時間序列的 H/A 賠率變化
