## 摘要

本文件定義了一組用於 PriceCenterSite 球王功能的 API，包含取得會員今日/歷史預測賽事、取得使用者今日預測賽事，以及更新會員大頭貼。對 AI 開發的幫助在於：明確了更新大頭貼 API 的 Route、Request Body 格式，以及一個關鍵的業務規則——大頭貼圖片路徑只驗證是否以「https://inplayz.com/sport/」開頭，這暗示更新機制是從預設選項中選擇而非自由上傳。文件標題雖為『球王API』，但 API 表格中的功能描述與標題不完全對應，需人工確認。

---

## 關鍵業務規則

- - 大頭貼圖片路徑只驗證是否以「https://inplayz.com/sport/」開頭，因此會員僅能從該路徑下的預設頭像選項中選擇。
- 更新會員大頭貼的 API 為 PUT users/{authKey}/headshotpath，Request Body 需包含 HeadShotPath 字串欄位。

---

## 關鍵設計決策

- - 大頭貼功能設計為『選項選擇』而非『自由上傳』，因此後端僅驗證路徑前綴，不處理檔案上傳邏輯。
