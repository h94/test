## 摘要

記錄 Selenium 擴充套件 sa8888 的改版細節：1. 要求增加 API 參數接收的錯誤處理，防止因網路問題導致程式直接中止；2. 定義送入 Kafka 的標準訊息格式，包含 tczb、machinename 等 XML 標籤與 ===END=== 分隔符，並附帶抓取的完整 HTML 內容。

## 關鍵設計決策

- - 接收 API 參數時若發生網路錯誤，不應直接結束程式，必須實作重試或異常捕捉邏輯（避免「抓不到就停止」）。
- Kafka 訊息格式設計為：固定 XML 區塊（<tczb>、<machinename>、<timestamp>、<gametype>、<selectdate>）後接 '===END===' 分隔字串，再加 HTML 內文，便於消費者解析。
