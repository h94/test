## 摘要

這份文件列出了 Bwin 在不同國家的站點代號（如 de-at、es）與內部使用的 namemap 代號（如 de-DE、es-ES）的對應關係，並標注哪些站點未進行爬取。同時提供了 name map API 和 bwin API 的 URL 作為爬取時的參考。對於負責 Bwin 數據爬取的開發人員，可以用來確保 API 請求中的語言（lang）參數正確，並了解哪些目標站點需要處理或已排除。

## 關鍵設計決策

- - 使用內部 namemap 代號（如 de-DE）作為統一站點識別，對接 Bwin 原始代號（如 de-at）
- 對於未進行爬取的站點（如希臘、波蘭等）無需在映射表中建立對照
- name map API 端點提供動態映射能力，可能用於實際爬取流程
