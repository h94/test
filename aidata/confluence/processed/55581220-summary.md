## 摘要

本文件定義一個新的「主推排行榜」API，用於取得高手頁中各球種聯盟的主推排行。API 採用 GET 方法，回傳包含玩家資訊與預測統計的排行榜列表，並明確排序規則（先依 WinStreakDays 再依 ProfitPoint 降冪），且不受玩家有無預測紀錄影響。同時給出與 API 回傳結構一致的檔案路徑供前端下載，對 AI 開發而言可快速掌握此 API 的請求/回應結構與業務規則。

---

## 關鍵業務規則

- - 排行榜排序依序為 WinStreakDays（連勝天數）與 ProfitPoint（獲利點數），均為降冪排列。
- 無論玩家是否有預測紀錄，皆會顯示於排行榜中。
- 檔案格式與其他篩選排行榜一致，路徑為 downloads/leaderboard/sportsite/filter/{gameType}/{lid}_mainbet.json。

---

## 關鍵設計決策

- - 採用 API 與靜態檔案雙軌提供排行榜資料，檔案路徑與篩選排行榜保持統一結構，簡化前端整合。
- 回傳內容包含 hasPending 欄位，標示玩家是否有進行中的預測，供介面做狀態區分。
- FilterType 固定為 main_winstreak，明確此排行榜專注於主推連勝排行。
