## 關鍵設計決策

- - 選擇以 Python 重構舊版美股解析器。
- 資料來源選用 moneydj.com 網站，需登入會員(帳密: djgwgi / w59RX@NpDe)才能存取。
- API 回應缺少漲跌幅與漲跌幅百分比，決定由程式端自行計算: 漲跌幅 = 今日收盤價 - 昨日收盤價; 漲跌幅% = (漲跌幅 / 昨日收盤價) * 100。
- 取得個股歷史股價 API 的參數 c 至少需設為 3(取得最近 3+1 天資料)，以確保有足夠數據計算漲跌幅。
- 寫入資料庫時採用批次處理，每累積 5 筆資料發送一次請求。
- 股票價格資料表依年份動態命名: stockprice_usa_{year} (西元年)。
