## 摘要

這份文件定義了預測系統中數個API的變更，包含新增會員主推預測功能、調整高手排行榜與殺手殿堂的週期取得方式，以及修改個人預測頁資訊。
對AI開發而言，此文件提供了主推預測、篩選器報告(filterReports)和殺手週期(killer cycles)等新功能的請求/回應格式、錯誤碼與業務限制，是理解和實作這些API的核心依據。

## 關鍵設計決策

- - 新增 `PUT /predict/bets/{authKey}/main` API，讓使用者在已預測的比賽中，設定當日的主推（一天一次）。
- 新增 `filterReports` 屬性至現有的 `/predict/honor/{account}` API 回應中，以根據自訂的過濾條件（如聯盟、玩法、時間範圍）回傳該會員的預測成績。
- 修改 `/predict/killer/cycles/{gameType}/{lid}` API：移除 `date` 參數，並將回傳結果從原本的10期改為近3期結算週期。
- 修改 `/predict/header/details/{authKey}/today` API：從原本只回傳「未開賽」的賽事，改為回傳該使用者的全部預測賽事，並在 `predictBets` 物件中新增 `mainBet` 布林屬性以標記主推。
- 排行榜 API `/predict/leaderboard/master/{gameType}/{lid}/profit/{cid}` 的 `myIndex` 屬性，當請求中 `authKey` 為空或為查無此人的帳號時，將回傳 null。
