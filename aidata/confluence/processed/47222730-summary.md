## 摘要

此文件定義 PriceCenterSite 的訂閱相關 API，包含取得付費方案、查詢會員訂閱紀錄、取消自動訂閱，以及綠界支付通道的整合介面。核心業務規則：非即時性支付方式（如 ATM、超商）必須等到收到成功付款結果後，才建立會員訂閱紀錄。這份 API 設計幫助 AI 開發者理解訂閱流程的端點規格、請求/回應結構，以及支付成功後的觸發邏輯。

---

## 關鍵業務規則

- - 除了信用卡，其它支付方式（WebATM、ATM、CVS、Barcode）因為付款結果非即時，必須在收到綠界成功支付的回呼後，才會新增會員訂閱紀錄。
- 取得所有訂閱付費方案 API 回傳的方案物件中，enabled 欄位（0/1）決定方案是否可用，startDate/endDate 定義方案有效期間。
- 各方案可支援多種支付方式，每種支付方式有 payType（如 CreditCard、WebATM）、mode（period 或 disposable）及 enabled 狀態。
- 取消會員自動訂閱時，API 會在 SubEndTime 設定結束時間（格式 YYYY-MM-DD HH:mm:ss），且 AutoSub 欄位仍為 true（可能代表狀態變更前的舊值或仍顯示自動續訂，需人工確認語意）。
- 綠界通道 URL 支援動態 payType 路徑參數，並以查詢字串傳遞 subID、authKey、lang，lang 未帶時預設為 zh-TW。

---

## 關鍵設計決策

- - 訂閱方案設計為多語言支援（names 物件包含 en-US、zh-CN、zh-TW），以適應不同地區使用者。
- 支付方式區分為 period（定期定額，如信用卡）和 disposable（一次性，如 ATM、超商）兩種模式，反映不同支付工具的特性。
- 會員訂閱紀錄查詢使用 authKey 作為會員識別，而非傳統的會員 ID，增加安全性。
- 取消自動訂閱使用 PUT 方法，傳入 SubID 等資訊，但回應中仍包含取消前的 SubEndTime，可能用來記錄取消時間點（需人工確認是否為邏輯刪除）。
- 綠界支付通道路由設計為 /ECPay/{payType}，並區分 Local 與 PRD 環境，方便開發測試。
