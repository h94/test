## 摘要

定義 NewLotterySite 服務的會員註冊／登入、驗證、代幣錢包查詢與彩池資訊 API 規格。包含帳號密碼格式限制、驗證碼存活時間、註冊必填欄位等業務規則，並提供具體的 API 路由、參數範例與回應格式，可直接用於生成前端介面或後端 API 實作。

---

## 關鍵業務規則

- - 帳號為 6-20 位英數字組合
- 密碼為 8-20 位字元
- 暱稱為 2-50 位字元
- 註冊時 email、手機均不可重複
- 社群聯絡方式（line、wechat、whatsapp）至少必填一項
- 註冊後需進行手機驗證，驗證碼存活時間 5 分鐘，逾時需重新發送
- 忘記密碼驗證通過 email 通知
- 登入成功後回傳 authKey，若為空值代表帳號未完成驗證
- 註冊驗證類型為 RegisterValidate，忘記密碼驗證類型為 ForgetPassword
