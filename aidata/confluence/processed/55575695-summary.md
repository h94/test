## 摘要

文件說明如何使用 i18n-sync 工具，透過 Google Sheets 統一管理多語系翻譯，並利用 npm script 同步至前端 JSON 翻譯檔。內容涵蓋 Google Sheets API 設定、服務帳戶認證步驟，以及巢狀 key 以雙底線 '__' 表示的轉換規則。對 AI 開發而言，可了解翻譯工作的自動化流程與相關設定，若需修改或擴展國際化功能時可作為操作參考。

---

## 關鍵業務規則

- - 巢狀翻譯 key 在 Google Sheets 中使用雙底線 ("__") 分隔，同步時會自動轉換成嵌套 JSON 結構（例如 Time__AM 轉為 {Time:{AM:...}}）。
- 同步指令執行後會自動使用 prettier 格式化翻譯檔案。
- 必須將 Google Sheets 共用給 i18n 服務帳戶（client_email），否則無法讀取內容。

---

## 關鍵設計決策

- - 採用 Google Sheets 取代直接編輯各語系設定檔，主因是可同時編輯多語系、降低手動維護錯誤，並允許非開發人員（如 PM）協作。
- 使用 Google Sheets API 搭配服務帳戶與 JSON 金鑰進行程式化存取，確保安全且可控。
- 在前端專案中提供 npm run i18n-sync 統一指令，簡化開發者同步流程。
