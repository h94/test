## 摘要

這份文件整理各爬蟲站台取得隊伍 LOGO 的方式與資料來源能力，紀錄哪些站台本身有提供 LOGO、哪些需要從資料源拼裝或額外呼叫 API。對 AI 開發爬蟲或前端顯示功能時，能夠快速查詢不同站台的 LOGO 取得邏輯，避免重複研究。

## 關鍵設計決策

- - 依資料源特性，LOGO 取得分成三類：(1)資料源 API 直接包含 LOGO URL；(2)資料源 API 未含，需從其他端點或拼裝 ID 取得；(3)資料源無 LOGO，須依賴站台靜態資源。
- LeisuParser、CrawlerAgentBetsapi、CrawlerAgentSofaScore 等站台的資料源已提供 LOGO，可直接取用。
- CrawlerAgentCovers、crawleragentespnofficial 等站台的 LOGO 雖有 API 返回，但需自行組合 URL（如 image id）。
- 有些爬蟲（如 CrawlerAgentVbetInplay、crawleragentvbet）的 LOGO 需點擊 Static 頁面才能取得；CrawlerAgent8bo 則需進入單場分析頁面才看得到。
