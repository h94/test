## 摘要

定義 PS3838V2 爬蟲代理需要新增 VB（排球）、BM（棒球）、CK（板球）三種球種，並詳細列出各球種在 Matches 或 Money Line 頁面下，HA、OU、1st PointHA、1st PointOU 等玩法的賠率資料結構（含層級與字段映射），以及示例賠率值。對開發爬蟲解析邏輯時，可據此實作對應球種的數據提取規則。

## 關鍵業務規則

- - VB 球種在 Matches 頁面下，HA 玩法結構：第一層 0=HA，第二層 0，第三層 index 2 為球頭，index 3 為主隊賠率，index 4 為客隊賠率。
- VB 球種在 Matches 頁面下，OU 玩法結構：第一層 1=OU，第二層 0，第三層 index 0 為球頭，index 2 為主隊賠率，index 3 為客隊賠率。
- VB 球種在 Matches 頁面下，另一 HA 玩法（第一層 2=HA）結構：第二層 index 1 為主隊賠率，index 0 為客隊賠率。（推測為全場勝負 1X2）
- VB 球種在 Matches 頁面下，1st PointHA 玩法結構：第一層 0=1st PointHA，第二層 0，第三層 index 2 為球頭，index 3 為主隊賠率，index 4 為客隊賠率。
- VB 球種在 Matches 頁面下，1st PointOU 玩法結構：第一層 1=1st PointOU，第二層 0，第三層 index 0 為球頭，index 2 為主隊賠率，index 3 為客隊賠率。
- VB 球種在 Matches 頁面下，另一 1st PointHA 玩法（第一層 2=1st PointHA）結構：第二層 index 1 為主隊賠率，index 0 為客隊賠率。
- BM 球種在 Money Line 頁面下，HA 玩法結構：第一層 0=HA，第二層 0，第三層 index 1 為主隊賠率，index 0 為客隊賠率。
- CK 球種在 Money Line 頁面下，HA 玩法結構：第一層 0=HA，第二層 0，第三層 index 1 為主隊賠率，index 0 為客隊賠率。
