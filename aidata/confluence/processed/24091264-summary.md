## 摘要

本文件定義新增188bet站台足球賠率parser的業務規則。內容詳細列出超過20種玩法（讓分、大小、獨贏、正確比分、總入球數、單雙、角球等）的代碼、Pre-Game與In-Game支援範圍、以及對應的JSON輸出格式，並區分全場/上半場與滾球（RB前綴）模式。文件亦提及未來可能排除「eFootball - Battle - 8 Mins Play」電競聯盟。此文件對AI開發crawler parser的資料標準化與轉換邏輯有直接指導價值。

## 關鍵業務規則

- - 全場讓分（Handicap）：代碼「HA」，JSON結構為 HA: {'盤口' : { 'H' : '主賠率', 'A' : '客賠率'}}，例如 HA: {'-1/1.5' : { 'H' : '0.94', 'A' : '0.98'}}。滾球模式對應「RBHA」，結構相同。
- 上半讓分（1st Half Handicap）：代碼「HalfHA」，結構同讓分，但限定上半場。滾球模式「HalfRBHA」。
- 全場大小（Over/Under）：代碼「OU」，JSON結構為 OU: {'盤口' : { 'O' : '大分賠率', 'U' : '小分賠率'}}，例如 OU: {'2.5' : { 'O' : '1.03', 'U' : '0.87'}}。滾球模式「RBOU」。
- 上半大小（1st Half Over/Under）：代碼「HalfOU」，結構同上。滾球模式「HalfRBOU」。
- 全場獨贏（1X2）：代碼「HA(1X2)」，JSON結構為 HA: {'1X2' : { 'H' : '主勝賠率', 'T' : '平賠率', 'A' : '客勝賠率'}}。滾球獨贏代碼「RBHA(1X2)」。
- 上半獨贏（1st Half 1X2）：代碼「HalfHA(1X2)」，結構同上。滾球上半獨贏代碼「HalfRBHA(1X2)」（代碼與滾球上半讓分重複，需人工確認）。
- 全場正確比分（Correct Score）：代碼「Correct Score」，JSON結構為 Correct Score: {'比分' : { 'Value' : '賠率'}}，例如 '1-0' : 19。滾球模式「RBCorrect Score」。
- 上半正確比分（1st Half Correct Score）：代碼「HalfCorrect Score」，結構同上。滾球模式「RBHalfCorrect Score」。
- 總入球數（Total Goals）：代碼「Total Score」，JSON結構為 Total Score: {'0-1' : { 'Value' : '賠率'}}，例如 '0-1' : 3.1。
- 上半總入球數（1st Half Total Goals）：代碼「Half Total Score」，結構類似，使用對應比分範圍。
- 全場主隊總得分大小（Team Goals Home O/U）：代碼「T1 Score」，JSON結構為 T1 Score: {'盤口' : { 'O' : '大分賠率', 'U' : '小分賠率'}}。滾球模式「T1 RBScore」。
- 全場客隊總得分大小（Team Goals Away O/U）：代碼「T2 Score」，結構同上。滾球模式「T2 RBScore」。
- 全場單雙（Odd/Even）：代碼「Odd/Even」，JSON結構為 Odd/Even: {'Odd/Even' : { 'Odd' : '單賠率', 'Even' : '雙賠率'}}。滾球模式「RBOdd/Even」。
- 半場單雙（1st Half Odd/Even）：代碼「HalfOdd/Even」，結構同上。
- 先得分/最後得分（First/Last Goal）：代碼分別為「FirstScore」與「LastScore」，歸屬玩法「FT_TTS」，JSON結構為 FirstScore: {'FirstScore' : { 'H' : '主賠率', 'A' : '客賠率'}}。
- 半全場（Half Time/Full Time）：代碼「Half Time/Full Time」，JSON結構為 Half Time/Full Time: {'結果組合' : { 'Value' : '賠率'}}，例如 'H/H' : 12.5。
- 角球讓分（Corners Handicap）：代碼「CornerHA」，結構與讓分類似。滾球模式「CornerRBHA」。上半場角球讓分代碼「CornerHalfHA」。
- 角球大小（Corners O/U）：代碼「CornerOU」，結構與大小類類似。滾球模式「CornerRBOU」。上半場角球大小代碼「CornerHalfOU」。
- 角球獨贏（Corners 1X2）：代碼「CornerHA」，結構同獨贏（需注意與讓分代碼重複，人工確認）。上半場角球獨贏代碼「CornerHalfHA」。
- 所有玩法皆標記In-Game與Pre-Game可用性（表格中O表示支援），滾球模式代碼前綴「RB」表示走地盤。
- 未來可能排除電競聯盟「eFootball - Battle - 8 Mins Play」，當前先納入parser範圍。
