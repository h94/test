## 摘要

本文件說明如何串接 footballant 資料來源。賽前資料透過 API 直接指定日期（今天與明天）取得；賽中資料呼叫 getMatchListByState API，傳入狀態參數；賽後資料則從 https://footballant.com/matches/ended 頁面，以正則表達式擷取 class="matchInfo" 區塊，每個區塊包含一個聯盟及該聯盟所有已結束比賽。文件也列出多語言站台及其 API 語言代號對照，並指出越南文無對應 API 代號。這些資訊可直接用於開發 crawlerservice 的 footballant provider，實作對應的抓取邏輯。

---

## 關鍵業務規則

- - 賽前：須抓取今天與明天的比賽，透過 https://api.footballant.com/api/v4/getMatchList?date={YYYY-MM-DD}&lang=en&device=3 取得，日期直接修改即可
- 賽中：調用 https://api.footballant.com/api/v3/getMatchListByState?status=1&type=1&dateTimeStamp&lang=en&device=3 獲得進行中比賽
- 賽後：解析 https://footballant.com/matches/ended 頁面，尋找 class="matchInfo" 的 div 元素，每個 div 內包含一個聯盟及該聯盟所有已結束比賽
- 多語言：API 中的 lang 參數可使用 de、es、ja、ko 等代號，對應站台請參考文件列表，越南文 (vi-VN) 無對應 API 代號，須注意

---

## 關鍵設計決策

- - 賽前與賽中使用 API 取得結構化 JSON 資料，避免解析 HTML；賽後因無專用 API，改用頁面解析搭配正則表達式提取 class="matchInfo" 元素
- 賽前日期範圍固定為今天與明天，直接變更 API 的 date 參數即可，無需翻頁或其他參數
