## 摘要

定義賽事實況與賽事結果需新增的 OtherInfo、ResultInfo、單節比分等資訊，以及各球種（GameType）對應顯示的站台清單。提供相關 API 的請求與回應格式，包括 GameResult.json 及 LanguageMap.json 的結構。移除無作用的單場賽事實況與論壇頁面。

---

## 關鍵業務規則

- - 賽事實況須輸出 OtherInfo（天氣、地點等）、單節比分、playbyplay 資訊。
- 賽事結果須輸出 ResultInfo（天氣、地點等），包含在 GameResult.json 中。
- 各球種顯示站台規則：BS、BK、HL 顯示 zba,ku888,nk.net,vbet,1xbet.com,ps3838.com；SC 顯示 zba,hga.com,ku888,vbet,188bet,1xbet.com；等（詳見球種顯示站台表）。空白站台的球種（SQ,FB,FS,RU,RL,BD,BV,BW,GS,PL,BL）可能不顯示任何站台，需人工確認。
- 移除無作用頁面：單場賽事實況、論壇。
- API /pricecenter/api/system/gameresult 會同時儲存 GameResult.json（含 ResultInfo）及 LanguageMap.json（語言對照）。
