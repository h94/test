## 摘要

定義了 CrawlerAgent 在 Pinnacle 環境中的中央控制邏輯：從 API 取得待監控的賽事 GameID，並控制同時監控數量；需要實作賽事結束特徵偵測，並在結束時回呼 API；需定期發送心跳維持連線；程式結束時需優雅清理所有執行緒。這些規則構成了爬蟲代理的核心排程與生命週期管理基礎，開發時需確保賽事切換與資源釋放的正確性。

---

## 關鍵業務規則

- - 從 API 取得 GameID 以決定要監控的賽事，並須控制同時監控的賽事數量。
- 當觀察到賽事結束特徵時，必須呼叫 API 告知賽事結束。
- 須以固定間隔發送心跳，以維持連線或回報存活狀態。
- 程式結束時必須通知並清理所有相關執行緒，避免資源洩漏。
