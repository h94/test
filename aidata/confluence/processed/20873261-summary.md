## 摘要

本文档说明了如何开发一个赔率分析折线图工具。首先从 PriceCenter API 获取赛事资料，再依据场次取得各网站的让分(Spread)与大小(OU)历史赔率，以及比分变化。最后将数据按时间序列整理，并使用 Python 绘图库画出包含赔率线、最终比分线及浮水印的双轴折线图，存档至外部挂载目录。

---

## 關鍵業務規則

- - 必须被分析的网站范围：bet365, KU, TWSL（以这些网站为主）。
- 图表需输出为 PNG 格式，并 mount 到 SRV63 的外部文件夹 (/usr/local/openresty/nginx/html/downloads)。
- 数据整理成 DataFrame 时，若不同玩法(HA/OU)的赔率笔数长度不同，需以最长者为基准，使用 fillna method 以前一笔数据(forward fill)补足缺失值。
- 棒球(BS)的让分赔率计算规则：图表 Y 轴需显示 '1+60' 格式，但实际画线数值需转换为 '1x200 - 60 = 140' 或 '1x200 -(-40) = 240'（需人工确认转换公式的通用性）。
- 图表需包含标示最终比分和与比分差的水平线(平行于X轴)。
- 图表必须包含浮水印。

---

## 關鍵設計決策

- - 数据获取分三步：第一步获取球种对应的所有赛事，第二步获取单场赛事所有网站的赔率，第三步合并整理。
- DataFrame 索引使用时间序列，以便按时间画出变化线。
- 使用双轴图呈现赔率变化，一个Y轴用于赔率，另一个用于比分（因为数值范围差异大），或使用双轴图解决 match 比分合数值过大导致赔率线被压缩的问题。
- 图表直接保存为文件 (plt.savefig) 到 Docker 容器挂载的外部文件夹，而非通过 API 返回流。
- 各网站线条颜色需参考 matplotlib 3.1.0 命名颜色表决定。
