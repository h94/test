## 摘要

本文件定義了兩個 REST API：一個用於取得特定比賽隊伍的技術統計資料（含各場次累積數據），另一個用於取得隊伍名稱的多語言映射。目的為支援 SportKing 前台隊伍資訊頁面，並填補 aiscore 僅支援籃球、足球以外的球種缺口。對 AI 開發者而言，可直接參考請求參數與回應格式實作相關功能或測試。

## 關鍵設計決策

- - API 路徑使用 `game/siteleagues/teams/players/${gtype}` 及 `teams/namemap/${gtype}/${tid}`，將隊伍資訊查詢拆分為統計資料與名稱多國語言映射兩個端點。
- 技術統計回應中的 record 欄位以 JSON 字串儲存多種統計數據，前端需自行解析。
- 隊伍名稱映射支援多種語言，以物件 key-value 形式回傳，方便國際化展示。
