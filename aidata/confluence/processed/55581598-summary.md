## 摘要

這份文件定義了 SportPesa 網站的爬蟲技術規格，包含賽前與賽中比賽資料的 API 端點、參數格式與球種代碼對照表。對 AI 開發的幫助在於：明確了資料來源結構、撈取順序（先取得比賽列表與 ID，再以 ID 單查詳細賠率），以及 Kafka 上傳的目標。了解這些 API 的請求格式與分頁邏輯，有助於正確實作 crawler 並進行後續的資料清洗與審核。

## 關鍵設計決策

- - 賽前與賽中比賽皆採用兩段式查詢：先獲取比賽列表並儲存 ID，再依據該 ID 批次取得單場比賽詳細賠率，以降低單次 API 請求的資料量。
- 賽前比賽列表使用 unix timestamp 的日期範圍進行查詢過濾 (`from` 與 `to` 參數)，實現分日拉取。
- 賽中比賽列表採用分頁參數 `count` 與 `offset` 進行資料擷取。
- 賽中比賽的即時動態 (play-by-play) 是透過另一個不同的 domain (betstream.betgenius.com) 取得，需要獨立的 API 呼叫。
- 賽果資料使用 POST 請求，並以 `yesterday_timestamp` 作為請求體參數進行查詢。
