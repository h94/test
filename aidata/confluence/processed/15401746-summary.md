## 摘要

定義一個台灣運彩歷史賽果爬蟲（CrawlerAgent）的需求：針對足球、棒球、籃球三種球類，透過台灣運彩官網的 GetPagedSearchResult API 取得 JSON 資料。需依照不同球類使用特定 URL 參數（s）辨別，並處理分頁（p）。重要欄位包括聯盟（ln）、客隊（atn）、主隊（htn）、Unix 時間戳（kdt）、分數（ss）。要求定時每 20 分鐘爬取一次。提供 API 端點範例與參數範例，可作為 CrawlerAgent 實作的輸入規格。

---

## 關鍵業務規則

- - 爬蟲需支援足球、棒球、籃球三種運動類別，透過 URL 查詢參數 s 區分，範例顯示 SC (足球) 使用 s=441，BK (籃球) 使用 s=442，BS (棒球) 在文件中同樣標示為 s=442（需人工確認是否正確或是否為筆誤）
- 爬蟲必須考慮分頁，透過 URL 查詢參數 p 控制頁碼
- API 回應為 JSON 格式，必須擷取欄位：ln (聯盟)、atn (客隊名稱)、htn (主隊名稱)、kdt (日期時間，為 Unix 時間戳格式，需轉換)、ss (分數)
- 定時執行週期為 20 分鐘，用於持續更新歷史賽果資料
- API 基礎端點為 https://www.sportslottery.com.tw/api/services/app/GameResult/GetPagedSearchResult，並帶有其他固定參數如 c=0, l=0, o=1, g=1, z=-480, ct=en-us（文件未說明其用途，可能為固定值）
