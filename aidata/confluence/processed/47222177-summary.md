## 摘要

提供內部搭建的 ChatGPT API 代理（http://192.168.9.233:22342/api）的使用方式，封裝了 OpenAI GPT-3.5-turbo 模型。說明了請求格式、Response 範例、Python 呼叫範例，並附上費用、用量查詢、Token 計算機等資源鏈接。指出目前僅開放 GPT-3.5，GPT-4 尚未可用，且單次輸入有資料量限制。對 AI 開發的幫助：可直接使用此內部端點獲得 ChatGPT 回覆，避免在服務中直接管理 OpenAI 金鑰與費率限制。

---

## 關鍵業務規則

- - 目前支援的模型僅為 gpt-3.5-turbo，GPT-4.0 尚未開放。
- 請求必須為 JSON 格式，包含 "content"（詢問內容）和 "model"（指定模型）兩個欄位。
- 一次請求不能餵入過多資料（有 token 上限，見截圖提示）。
- 費用可透過 OpenAI 帳號查詢，免費版僅有 $5 USD 額度。

---

## 關鍵設計決策

- - 建立內部代理服務（chatgptapi）集中管理 OpenAI API key，對外提供統一的 HTTP 接口，降低各服務直接使用 OpenAI SDK 的複雜度。
- 範例程式碼使用 requests 直接 POST，而非安裝 openai 套件，簡化依賴與部署。
- 選擇 GPT-3.5-turbo 作為預設模型，可能基於成本與可用性考量，GPT-4 暫不開放。
