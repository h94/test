- - 比賽分數為 0 的記錄通常是錯誤資料，應予以排除，僅保留主客隊分數皆不為 0 的資料。

- 比賽分數差特徵（match_diff）應取絕對值，以表示實力差距幅度，而非勝負方向。

## 關鍵設計決策

- - 使用 pandas 原生方法（如 df['match_diff'] = (df['match_h'] - df['match_a']).abs()）取代 Python 循環，以提升效能。
- 選擇直接排除分數為 0 的記錄，而非使用兩倍標準差篩除異常值，因為差距雖大但仍是正確資料。
