## 摘要

這篇文件定義了 ForumService 後台的 API 契約，新增了討論區的 enabled 狀態欄位，支援後台管理員進行顯示/隱藏操作。對於 AI 開發後台功能來說，可以直接作為 API 實作的規格書，明確了 addForum、editForum、delForum、getPost、editPost、delPost 六個端點的請求參數與回應結構。

---

## 關鍵業務規則

- - forum 的狀態欄位 enabled 用於控制顯示或隱藏
- editForum 的 parentid 為選填，addForum 的 parentid 為必填（從 API 參數定義推斷）
- getPost 支援多個選填查詢參數：forumid, starttime, endtime, expertonly

---

## 關鍵設計決策

- - 所有後台操作 API（新增、修改、刪除）均採用 POST 方法
- forum DB 新增 enabled 欄位來管理顯示狀態，而非使用軟刪除等機制
