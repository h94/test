## 摘要

本文件定義了收藏聯盟功能的 API，提供 collect/getleaguemap/{gtype} 端點，透過 POST 傳入聯盟 ID 陣列，回傳以 ID 為 key 的物件，包含聯盟名稱及多語系名稱（en-US, zh-CN, zh-TW 等），用於前端顯示用戶的聯盟收藏清單，並可依球種類型 (gtype) 篩選。

---

## 關鍵業務規則

- - 收藏聯盟查詢必須帶入 gtype（球種類型）以篩選結果
- 請求時可傳送多個聯盟 ID 進行批次查詢

---

## 關鍵設計決策

- - 採用 POST 方法而非 GET，可能是為了避免 URL 長度限制，因請求參數為 ID 陣列
- 回傳結構以聯盟 ID 為 key，方便前端快速查找對應資訊
