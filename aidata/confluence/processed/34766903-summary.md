## 摘要

本文件定義了回測系統使用的兩個 Cassandra 表：backtesting 儲存回測設定（策略、交易條件、狀態），backtesting_view 儲存回測後的結果（損益、持股、統計）。明確了各欄位的類型、用途與枚舉值，如狀態、多空方向、買賣時機等，為回測功能的資料儲存提供設計參考。

---

## 關鍵業務規則

- - 回測狀態 (Status) 為整數枚舉：0=排隊中，1=計算中，2=完成，9=刪除。
- 多空方向 (BullBear) 使用整數：0 表示空，1 表示多。
- 進場時機 (BuyTiming) 與出場時機 (SellTiming) 使用整數：0 表示隔日開盤價，1 表示隔日收盤價。
- 進場策略 (BuyStrategy) 以 JSON 格式儲存，包含名稱 Name 與策略陣列 Strategy，每個策略項目包含 id、text 描述、value 參數陣列。
- 出場策略 (SellStrategy) 以 JSON 陣列儲存，每個元素為一個出場規則物件，包含 Name 和 Strategy（結構同進場策略）。
- backtesting_view 中的 SoldOut 欄位為已賣出股票的 JSON 陣列，每個項目包含股票代碼、名稱、賣出原因、損益、數量、買入價、賣出價、買入日期、賣出日期。
- backtesting_view 中的 Unsold 欄位為未賣出股票的 JSON 陣列，每項包含代碼、名稱、損益、交易量、買入日期、買入價格、最後日期、最後價格。
- 數據欄位如 TradingVolume（交易筆數）、Winrate（勝率%）、TradingFeeAmount（手續費）、TaxAmount（稅金）、BuyAmount（買入金額）、SellAmount（賣出金額）提供回測績效統計。
