## 摘要

此文件定義了 CoinbaseProSAgentV2 以 Python 重構的方案，透過 Coinbase Pro 的 websocket 訂閱 USDT-USD 的 ticker 頻道，並規範輸出的標準化訊息格式（包含 Site、Name、Datum、Price 與 Volume）。對 AI 開發助益為提供了此數據源的精確接取與傳遞規格，便於實作或維護相關的加密貨幣價格接取模組。

## 關鍵設計決策

- - 採用 websocket 通道訂閱 ticker_1000 頻道以取得即時價格，而非輪詢 REST API
- 輸出訊息統一包含 Site='coinbasepro'、Name='USDT'、Datum='USD'、Type='Stable'，以利下游服務識別來源與幣種
- Price 與 Volume 分別對應 websocket 回傳中的 'price' 與 'volume_24h' 欄位
