## 摘要

本文件定義了 LivechatService 整合 Telegram 的初期需求，目的是讓客戶能透過 Telegram 與 Agent 溝通。核心需求為：從 Telegram 讀取客戶訊息並存入 Redis，以及持續監聽 Redis 上 Agent 的訊息並發送到 Telegram。另外還需要一個寫入 DB 的 API 來儲存 Telegram Bot 帳號。對 AI 開發而言，這份文件揭示了 LivechatService 對第三方通訊平台的支援模式及 Redis 作為訊息中轉的機制，但細節非常不足，許多實作前提（如 Telegram API 能力）仍待確認。

---

## 關鍵業務規則

- - 客戶在 Telegram 傳送的訊息必須能被 LivechatService 接收並存入 Redis（需確認 Telegram API 是否支援服務端讀取訊息）
- Agent 回覆的訊息需寫入 Redis，再由 LivechatService 持續監聽並發送到 Telegram（需確認 Telegram API 是否支援發送訊息）
- Telegram Bot 帳號資訊需透過一個專用 API 寫入資料庫儲存
