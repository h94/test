## 摘要

本文件設計一個數值分析工具，從 bet365、KU、TWSL 等站台取得賽事與賠率歷史資料，繪製以時間為橫軸的雙折線圖（賠率與比分變化）。主要定義了兩個 API 端點（v1/gamedate、v1/log/odd）及其回傳格式，並說明資料 mapping 與圖表輸出流程（PNG、浮水印、分 pregame/inplay 目錄）。對 AI 開發有助於理解早期賠率數據的結構與可視化方式，但當時僅先支援 BK，BS 與 SC 的換算公式尚未實作。

---

## 關鍵業務規則

- - 初始階段僅支援 BK 球種，BS 與 SC 的賠率與 Spread 換算公式待後續開發
- 比分合及比分差也須找出換算公式（未實作）
- 圖檔輸出時，pregame 與 inplay 須掛載至不同的 Docker 外部資料夾

---

## 關鍵設計決策

- - 採用雙折線圖同時呈現賠率 (odds) 與比分 (match) 走勢，以時間為橫軸
- 圖檔以 PNG 格式儲存，並使用 PIL 套件添加浮水印
- 透過 plt.savefig 輸出至掛載的外部目錄，區分 pregame 與 inplay 路徑
- 資料整合步驟：先透過 API 取得賽事與站台賠率，再以 gameID mapping 相同賽事，最後合併歷史賠率資料繪圖
