## 關鍵設計決策

- - 踢人時間從原設定延長至3小時（Issue #2）。
- 棒球 BS 玩法移除 2~9 局的盤口，RB 玩法移除全部 1~9 局盤口（Issue #3）。
- 籃球 HL 移除 4th quarter 相關盤口，T1 移除 1~4 節 rbou（可能 key 錯）全部拿掉（Issue #4）。
- 足球 FL 移除 T1 1~4 節 rbou（Issue #5）。
- 聯盟、範本、賽事設定值的 Grid 改為前端排序（Issue #7）。
- 系統設定值切換球種後自動搜尋，不再需要手動點擊（Issue #8）。
- 賽事設定值維護的隊伍聯盟必須根據語系切換，後端 API 配合調整（Issue #9, #10）。
- 聯盟設定值與賽事設定值搜尋支援依語系搜尋聯盟名稱（Issue #11）。
- 聯盟設定值詳細資料中移除 zba（Issue #12）。
- 玩法不再顯示代號，改為依語系顯示全稱，並新增語系對照 API（Issue #14, #15）。
- 多個設定頁面增加預設排序欄位（賽事時間、聯盟名稱、設定值名稱等）（Issue #16）。
- 大量英文盤口名稱及翻譯修正，如 Asian Handicap、走地大小盤、角球、罰牌等（Issue #20-32）。
- 聯盟設定值新增失敗時切換球種導致玩法顯示異常修正（Issue #18）。
