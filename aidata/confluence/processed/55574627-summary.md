## 關鍵業務規則

- - 每週需執行 Daily Meeting 並判斷是否影響時程，及時回報上級
- 進入測試階段須關注 Bug 數是否收斂
- 測試後期需提醒成員補齊分析文件
- 下班前確認 JIRA 問題與回覆皆已填寫
- 如有線上問題需長期關注，應於 JIRA 開 Task 監督
- Story Point=13 時需召開 Design Review
- 如有新增 Service / API 接口，release 前需檢查 Gateway 是否已配置
- 新增 Service / API 接口需修改對應的 swagger.json，步驟參考特定頁面
- Launch 當天需安排人員 Merge 主線及監控上線系統狀況
