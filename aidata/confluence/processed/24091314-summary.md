## 摘要

此文件定義 PriceCenterService 針對 ZB 系列（聯盟、隊伍、遊戲）的特化合併功能。由於 ZB 系列不適用通用的相似度比對合併，故另建 API `/pricecenter/api/system/zbcombine`，接收 `gameType` 參數，內部依序調用 `AutoZBCombineLeagues` 與 `AutoZBCombineTeams` 完成合併。此設計延續既有 AutoCombine API 的架構，確保 ZB 系列資料能正確整併。

---

## 關鍵業務規則

- - ZB 系列資料（SiteLeague、SiteTeam、SiteGame）的合併必須透過專用端點，不可使用通用的 AutoCombine 機制。

---

## 關鍵設計決策

- - 因 ZB 系列結構不適用相似度比對合併，故不修改既有合併邏輯，而是獨立實作一套合併 API 與內部函數，降低對現有合併流程的影響。
- API 方法、路由與參數設計延續 AutoCombine API 的設定，維持呼叫一致性。
