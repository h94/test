## 摘要

本文件為 Sports 比分網前端 Vue3 改版的功能規格與 API 設計，說明了賽事頁面拆分為 PreGame、InPlay、Result 三個區塊，並新增我的最愛、置頂、聯盟排序等功能。文件中列出了各球種在 PlayByPlay 中應顯示的資訊，以及熱門賽事 API 由 GET 改為 POST 並加入 Favorite 參數的變更。對 AI 開發的幫助在於可了解改版後前端與後端互動的關鍵接口和功能範圍，但部分細節（如聯盟查詢）標注為尚未實作，且某些玩法和站台顯示規則仍待確認。

---

## 關鍵業務規則

- - 賽事頁面拆分為 PreGame、InPlay、Result 三個獨立頁面
- PreGame 與 InPlay 頁面新增：我的最愛、置頂、聯盟/時間排序功能
- Result 頁面新增：置頂、聯盟/時間排序功能
- HotGame 新增可標記我的最愛賽事
- 暫時移除 forums 與實況功能
- 熱門賽事 API 由 GET 改為 POST，Path 為 /api/game/hotgame，request body 新增 Favorite 陣列，每個元素包含 GameType 與 ID
- 球種對應 PlayByPlay 顯示內容依表規範（如 BK 顯示節數、開賽時間、比分、超時等）
- 聯盟查詢功能標注為「暫時未做」

---

## 關鍵設計決策

- - 賽事拆分成三個頁面是為了完善資訊呈現與改善使用者體驗
- 將熱門賽事 API 改為 POST 是為了支援傳遞我的最愛清單（可能因 GET 參數長度或結構限制）
