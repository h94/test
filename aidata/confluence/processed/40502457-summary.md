## 摘要

此文件定義 GameSettingSite（GS 站台）即時賠率列表需新增每筆資料的點擊按鈕，點擊後彈出 Result 畫面。此畫面會接收 API 回傳資料，並依賽事類型（全場、半場、大小、讓球、分鐘等）進行過濾分類，提供使用者切換顯示對應資料。對 AI 開發前端 teams 來說，明確了需要實作彈出視窗、API 串接與動態分類展示功能。

---

## 關鍵業務規則

- - 即時賠率列表中每一筆資料皆需提供可點擊按鈕（例如 view result 按鈕）。
- 點擊按鈕後必須彈出 Result 畫面，此畫面獨立顯示，不離開原列表頁面。
- Result 畫面需呼叫 API 取得完整賠率與賽事資料（API 端點未明定）。
- API 回傳的資料必須依據類型過濾，包含但不限於：全場、半場、大小、讓球、分鐘等分類。
- 使用者可點擊畫面上的分類選項，切換顯示對應的結果資料。
