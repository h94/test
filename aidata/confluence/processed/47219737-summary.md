## 摘要

本文件定義了兩個新 API：會員關注的增刪查 API 和預測聯盟賽事排行榜 API。前者讓會員可關注其他帳號並查看關注列表；後者依遊戲類型和聯盟 ID 返回多個時間區間（近30天/14天/7天/本月）的排行榜，項目包含勝負記錄、勝率、盈利點數和是否有待定結果。這些規格可直接用於 API 開發與前後端對接，但不包含排序規則或業務限制。

---

## 關鍵業務規則

- - 會員可透過 Focus_Account 陣列一次新增或取消多個關注對象
- 排行榜資料區分為 lastThirty、lastFourteen、lastSeven、thisMonth 四個時間區間
- 排行榜項目包含 account、userName、win/lose/draw、winPercentage、profitPoint、hasPending 等欄位
- 範例中 userName 顯示「名字最多只能十個字元」，推測使用者名稱最大長度為 10 個字元（需人工確認是否為正式規則）
