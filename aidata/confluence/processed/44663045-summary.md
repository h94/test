## 摘要

這份文件記錄了一次 Stock API 重構計畫，主要內容包括：清理未使用的 API、將 API 依功能分組為 Broker / Check / Company / FlowControl / Index / StockData / Tools，並定義了新舊路徑與參數的對照表。同時說明需要取得美、韓、中股票 240 天資料供指標使用，並列出受影響的程式模組（如 StockRedis、CandleMatch、Indicator 等）。對 AI 開發而言，這份文件提供了舊系統 API 端點的遷移歷史，有助於理解現行 API 的設計脈絡與版本演進。

## 關鍵設計決策

- - API 重新分組，將功能歸入 Broker、Check、Company、FlowControl、Index、StockData、Tools 等模組，以提高維護性
- 將 API 路徑從無版本號改為帶版本號（如 /api/index/v1/...），便於後續版本管理
- 刪除多個已不再使用的 API 端點（如 /api/brokervolume、/api/get_stockprice_data 等），減少維護負擔
- 部分 API 新增 kind 參數以區分國家（台灣可省略），支援多市場股票資料取得
