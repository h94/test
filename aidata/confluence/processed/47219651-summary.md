## 摘要

文件提供深圳、上海交易所下市股票清單的 Excel 下載網址。重點在於因 Python xlrd 套件不支援 xlsx 格式，故必須將請求參數中的 showtype 從 xlsx 改為 xls，才能正確以 xlrd 讀取；且回傳內容需從 response.text 轉為 binary content 再做處理。對 AI 開發爬蟲服務來說，這篇文件直接給出了可實作的 API 端點與格式轉換方法。

---

## 關鍵業務規則

- - 下載交易所 Excel 清單時，務必指定 showtype=xls，因為 xlrd 套件無法直接處理 xlsx 格式的檔案。
- GET 請求取得的文字內容需轉換為 binary content，才能交由 xlrd 讀取。

---

## 關鍵設計決策

- - 因相容性考量，深圳交易所的原始 API 預設提供 xlsx，實作時將參數改為 xls，以確保與現有 Python 套件 xlrd 相容。

---

## 注意事項

- ⚠️ - ⚠️ 若未將 showtype 改為 xls，會導致 xlrd 無法解析，需人工確認後續版本 xlrd 是否已支援 xlsx。
