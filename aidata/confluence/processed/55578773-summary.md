## 摘要

本文件记录后台会员管理功能的修改需求：将原有全玩家列表查询改为通过 email 或 account 查询单一玩家，并把编辑按钮拆分为“重设密码”和“修改状态”两个独立操作。提供了 PriceBackendService 和 MemberService 的相关 API 规格，包括 GET 查询（email 与 account 至少填一）、PUT 更新基本资料（用户名和状态）、PUT 重置密码（直接更新，跳过旧密码验证）。这些 API 大部分为既有接口，调整查询行为即可满足新需求。

---

## 關鍵業務規則

- - 查询玩家时，email 与 account 参数必须至少填写其中一个
- 更新会员基本资料接口仅允许修改 UserName 和 Status，由 AuthKey 指定目标用户
- 重置密码接口直接设置新密码，不要求验证旧密码

---

## 關鍵設計決策

- - 复用既有 API GetGameUsers，改为仅返回单一玩家记录，而非新增独立查询端点
- 将编辑功能拆分为重设密码和修改状态两个独立 API，避免单一接口混合不同职责
