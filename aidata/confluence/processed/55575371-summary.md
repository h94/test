## 摘要

文件定義了運動站台分潤系統的技術設計，包含 Cassandra 資料表（營收報表、會員分潤報表、提領紀錄）及 11 個 REST API 端點。業務上每月 1 號透過 xxl-job 計算上個月分潤，公式為 (當月總收入 - 總收入*0.05) * 0.55，並記錄會員解鎖次數與提領紀錄。對 AI 開發的幫助在於提供精確的 API 規格、計算規則與資料結構，可據此實作自動化分潤報表生成或跨服務資料同步。

---

## 關鍵業務規則

- - 當月總收入 = 當月交易成功總金額
- 當月份潤金額 = (當月總收入 - 當月總收入*0.05) * 0.55
- 每月 1 號計算上個月分潤
- totalunlock 計算公式：一般莊殺解鎖次數 * 1 + 超級莊殺解鎖次數 * 1.3
- 提領紀錄狀態 (status)：0=處理中，1=成功，2=失敗

---

## 關鍵設計決策

- - 選擇 Cassandra 作為資料庫，滿足分潤資料的高可用與分散式存取需求
- 使用 xxl-job 實現每月定時分潤計算
- 分潤計算扣除 5% 平台費用後再依比例 0.55 分配
- 將營收報表與會員分潤分離存放，透過 API 提供查詢與更新能力
- 提領紀錄結果可由外部系統透過 PUT 方式更新狀態與備註

---

## 注意事項

- ⚠️ - ⚠️ totalunlock 欄位在 DB 備註中有計算公式，但 API PUT 請求仍包含此欄位，可能需確認是否由客戶端計算還是服務端自動計算
- ⚠️ 文件未說明會員分潤中的不同球種（GameType）與聯盟（League）的業務分配規則，僅提供 API 規格，實際分配邏輯需人工確認
- ⚠️ 提領紀錄的 dateTime 為 clustering key 且型別為 text，查詢時需注意格式與排序
