## 摘要

文件定義了支付系統（PaymentService）的 REST API，涵蓋儲值、訂閱、購買文章、交易紀錄查詢及錢包餘額查詢等功能，部分端點由會員服務（memberservice）提供。內容包含各 API 的 HTTP 方法、路徑、參數與回應格式，並列出儲值紀錄狀態碼、方案類型等關鍵細節，對實作支付與會員錢包功能有直接參考價值。

---

## 關鍵業務規則

- - 查詢會員錢包餘額時若無訂閱紀錄，EndTime 欄位應回傳 0。
- 儲值紀錄的狀態碼意義：1 成功、0 失敗、2 審核中。
- 付費方案與付費方式的 Enabled 欄位 1 代表啟用、0 代表停用。
- 付費方案類型 Type 為 'subscribe' 時，Value 代表訂閱天數（例：60、90）；Type 為 'point' 時，Value 代表增加的點數額度。
