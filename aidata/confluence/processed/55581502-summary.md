## 摘要

本文件描述為球王站台新增 NBA 主推闖關活動的 API 與資料表設計。定義了 activities_record 表格結構，以及透過 xxl-job 定時產生活動紀錄與主推連勝排行榜的流程。規則包括：僅在當天所有比賽結束且有結果時才記錄、只記錄有輸贏的注單（平手與取消不計）、中斷連勝即移除紀錄。共提供 5 個 API，其中 GET/DELETE 操作直接存取活動紀錄，POST 用於生成記錄與排行榜。

---

## 關鍵業務規則

- - 會員若中斷連勝或退出活動，其紀錄會從 activities_record 表中移除（不再保留於活動中）。
- 當天所有活動比賽都結束，且會員的預測注單都已產生結果後，才會開始記錄會員當天活動狀況。
- 只記錄有輸贏（Win/Loss）的紀錄，平手（Push）和取消的注單不列入活動紀錄。
- 活動紀錄與排行榜透過 xxl-job 定時排程呼叫對應 API 產生，非即時計算。

---

## 關鍵設計決策

- - 採用單一資料表 activities_record，以 (site, eventname, account) 作為複合分割與分群鍵，欄位包含 winbets 儲存注單串列，可支援快速查詢會員當前連勝紀錄。
- API #2 (排行榜) 不經過 gateway，直接由 backend 服務提供，推測為內部使用或避開路由層以降低延遲。
- API #3 為已有舊 API 的邏輯變更，表示排行榜功能可能在其他系統已有基礎，本次僅調整行為。
- 休息天數 (restday) 記錄在活動紀錄中，可能用於計算會員休息後重新參與的連勝中斷規則（具體未說明）。
