## 摘要

文件定義 PriceCenterService 取得賠率資料的 8 個 API 端點，支援根據比賽 GID、日期、聯盟 LID、站點 site 等條件查詢一般賠率 (odd) 和滾球賠率 (rbodd)，並可選回傳 other 賠率。對 AI 開發而言，這些 API 是價格中心服務的核心資料查詢接口，提供不同維度的賠率資訊。

---

## 關鍵業務規則

- - GetOddsByGID：根據 gametype 和 gid 取得所有 site 的 odd，可選參數 site（逗號分隔，預設全部站點）和 isGetOthers（是否包含 other odd，預設 false）。
- GetOddsByGDate：根據 gametype 和 gdate 取得該日期所有 site 的 odd。
- GetOddsBySiteGid：根據 gametype, site, sitelid, sitegid 取得指定 site 的指定 game odd，可選 isGetOthers（預設 false）。
- GetOddsByLID：根據 gametype 和 LID 取得該聯盟下所有 site 的 odd，可選 site（預設全部）、isGetOthers（預設 false）、gDate（預設為美東今天）。
- GetRBOddByGID：根據 gametype 和 gid 取得所有 site 的滾球 odd（rbodd），可選 site（預設全部）和 isGetOthers（預設 false）。
- GetRBOddsNow：根據 gametype 取得當前所有 site 的滾球 odd。
- GetOddsBySiteGid（滾球版）：根據 gametype, site, sitelid, sitegid 取得指定 site 的滾球 odd，可選 isGetOthers（預設 false）。⚠️ 注意：此 API 名稱與第 3 條相同，功能不同，可能為筆誤，需人工確認實際端點。
- GetRBOddsByLID：根據 gametype 和 LID 取得該聯盟下所有 site 的滾球 odd，可選 site（預設全部）和 isGetOthers（預設 false）。
