## 摘要

定義了從 bwin 和 ku 數據源將 PlayByPlay 事件名稱與時間值轉換為 bet365 統一名稱的映射規則。包含 BK（籃球）和 SC（足球）兩種運動的 Event 與 Time 欄位轉換邏輯，並明確列出未轉換的例外項目。對 AI 開發者而言，可用於理解數據標準化流程、建構測試案例或輔助數據解析模組的實作。

---

## 關鍵業務規則

- - bwin 籃球（BK）Event '1-pointer scored' 或 '1 pt scored' -> 轉換為 'Free Throw'
- bwin 籃球（BK）Event 'Possession' -> 轉換為 'In Possession'
- bwin 籃球（BK）Event 'Timeout ended' -> 轉換為 'In Possession'
- bwin 籃球（BK）Event '2 pt missed' 或 '3 pt missed' -> 轉換為 'Shot Missed'
- bwin 足球（SC）Event '1st Half 00:00' -> 轉換為 'Kick Off'
- ku 籃球（BK）Time 值 'Quarter x' (x=1~4) -> 轉換為對應的 'Q1'~'Q4'
- ku 籃球（BK）Time 值 '1H' -> 轉換為 'Q1'；'2H' -> 轉換為 'Q2'（1H、2H 分別爲上半場第 1、2 節）
- ku 足球（SC）Time 值 '1H, 11'' 或 '1H, 10+' -> 去掉單引號和加號後，轉為 '11:00' 或 '10:00'（1H 為上半場，數字即為分鐘）
- ku 足球（SC）Time 值 '2H, 10+' 或 '2H, 11'' -> 去掉符號後，分鐘數加上 45，轉為 '55:00' 或 '56:00'（2H 為下半場）
- ku 籃球及足球（BK, SC）Time 值如 '1H, 10+'、'2H, 10+' 等，若聯賽名稱類似電競且時間 Value 不為 'Full Time' 或 'Half Time'，則全部轉為 'LIVE'
- bwin 籃球 Event 'Turnover'、'Steal' 維持原值不轉換
- bwin 足球 SC Event 'Halftime 45:00'、'2nd Half 45:00'、'5th Substitution Club Guarani (94:16)'、'2nd Half added time - 3 minutes (90:14)' 等維持原值不轉換
- ku 籃球與足球（BK, SC）Time 值為 'LIVE' 時維持原值不轉換
