## 摘要

文件說明 PriceCenterSite 新增網球、電競預測及會員推薦分潤機制。提供兩個支付相關 API：取得運動使用者分潤報表明細（新增 recommendShareReportDetails 欄位），以及查詢推薦會員交易紀錄。定義資料庫表格 reports_sport_recommend、sharereports_sport_recommend 等，描述會員分潤與推薦數據儲存結構。對 AI 開發可掌握支付報表與推薦分潤的資料來源、API 規格，利於整合 Payment 與 Member 相關功能。

## 關鍵設計決策

- - 在現有分潤報表 API 回傳中新增 recommendShareReportDetails 屬性，維持向後相容，避免變更既有介面。
- 採用 Cassandra 分區鍵（partition_key）與聚簇鍵（clustering）設計表格，如 authkey 作為分區鍵，year、month、recommendaccount 作為聚簇鍵，支援高效查詢。
- transactiondetails 使用 text 型別，彈性存放交易明細（可能為 JSON 格式），便於未來擴充。
- 推薦會員交易紀錄 API 使用 yearMonth 路徑參數（格式 2024-06），精確過濾月度資料。
