## 摘要

本文件說明如何在 Vue 前端專案中實作 Google 第三方登入按鈕，包含建立 Google API 專案、取得 OAuth 用戶端 ID，以及使用 vue-google-signin-button 與 jsonwebtoken 套件完成登入流程與 ID token 解碼。內容聚焦於UI元件綁定與前端取得使用者資訊的方法，對 AI 開發的幫助在於理解 Google 登入的前端實作細節，但未涉及後端驗證、會員綁定或業務規則。

## 關鍵設計決策

- - 採用 vue-google-signin-button-directive (第一種) 或 vue-google-signin-button (第二種) 套件快速產生 Google 登入按鈕，減少手動自訂 UI 的成本。
- 使用 jsonwebtoken 套件在前端解碼 Google 回傳的 ID token，僅讀取其 payload 中的使用者資訊，未進行完整性驗證（驗證應於後端進行）。
