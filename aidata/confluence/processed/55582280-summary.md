## 關鍵業務規則

- - Story 點數為 13 時，必須召開 Design Review（需求分析階段）。
- 新增 Service 或 API 接口時，需檢查 Gateway 是否配置。
- 新增 Service 或 API 接口時，需修改對應的 swagger.json（參考頁面 ID 5341691）。

- Sprint 結束後需回報 PRD 監控結果。
- 線上問題若需長期關注，應在 JIRA 上開立 Task 持續監督。
