## 摘要

本文件定義 au8 爬蟲如何透過 FU API 抓取 30 天內賽事資料：在 API 的 _ 參數帶入三十天後的時間戳。同時記錄兩項實作調整：4/12 後賽事需將 league_id 改為原網站提供的數字以統一各語系，以及新增 lang 欄位根據 namemap 判斷語系。對於開發或維護爬蟲服務，提供了關鍵的 API 端點格式與多天資料處理邏輯。

## 關鍵設計決策

- - 使用 FU API 並以三十天後的 Unix 時間戳作為查詢參數，以取得 30 天內所有賽事資料（因 API 本身支援時間範圍查詢）。
- 因應 4/12 起的變更，賽事資料中的 league_id 不再沿用原有對照，而是直接使用原網站回傳的數字，以確保跨語系時 league_id 一致。
- 新增 lang 欄位，透過解析 namemap 中的語系資訊來決定該筆資料的語系屬性，以利後續處理或顯示。
