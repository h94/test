文件記錄了從 stats.nba.com 爬取球隊進階統計數據的技術規格，包含 API 端點 leaguedashteamstats、參數格式（日期區間、賽季）、請求範例與回傳 JSON 的欄位對照。另外詳細解釋了每個統計欄位（如 OFFRTG、NETRTG、PACE 等）的定義與計算方式，有助於理解爬取數據的意義並正確解析回應。

## 關鍵設計決策

- - 採用 NBA 官方 stats API 的 leaguedashteamstats 端點，透過 MeasureType=Advanced 取得進階球隊統計數據
- 使用 DateFrom/DateTo 參數指定時間區間，格式為 MM/DD/YYYY 並以 URL 編碼處理
- Season 參數格式為 YYYY-YY，如 2022-23
- 當不指定 DateFrom/DateTo 時可取得整季資料
- 回應 JSON 結構以隊名為 key，內含 season 和 last15 兩個部分
