## 摘要

本文件描述一個賠率分析折線圖服務的技術設計，適用於 NBA 與 MLB 球種。主要流程為：呼叫內部 API 取得當天賽事與各 site 的賠率及比分資料，整理為 DataFrame 後繪製雙軸線圖（含讓分盤 HA 與大小分 OU 兩種圖表，以及對應的滾球版本 RBHA/RBOU），最後以浮水印處理並輸出 PNG 到指定掛載目錄。對 AI 開發的幫助在於：明確資料來源 API、HA/OU 賠率的雙軸繪製邏輯、棒球（BS）讓分盤的賠率轉換公式，以及圖檔輸出目錄結構規則。

## 關鍵設計決策

- - 球種範圍以 NBA 與 MLB 為主，site 以 bet365、KU、TWSL 為主
- 取得當天所有賽事後，再逐一取得單場賽事的 site game 資訊與賠率
- DataFrame 整理時，HA 與 OU 需對齊時間序，長度不同時以最長者為準，並以前一筆資料（ffill method）填補缺失值
- BS（棒球）讓分盤 Y 軸需特殊處理：顯示值為 1+60, 1-40，實際繪圖值為 (1x200 - 60 = 140, 1x200 - (-40) = 240)，因棒球讓分基準為 1（非 0），需人工確認
- 最終比分以平行 X 軸的線呈現於圖上
- HA 與 OU 分開為兩張獨立圖表，RBHA 與 RBOU 也各為獨立圖表
- 輸出目錄結構：依球種建立 folder → 依日期建立 folder → 未加浮水印圖存在 Image folder
- 圖檔 mount 到 SRV63 的 /usr/local/openresty/nginx/html/downloads，供外部存取
- 部署到 PRD 正式環境
