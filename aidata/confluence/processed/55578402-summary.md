## 摘要

本文件定義了版主預測專用 API，包含新增、查詢及更新預測注單說明。預測說明以 Args 欄位傳遞，長度限制為 2 至 200 字元。查詢 API 僅回傳三天內的預測賽事。另包含 Signal 觸發前端重整。對於 AI 開發，可用於理解版主預測模組的接口設計與參數規範。

---

## 關鍵業務規則

- - 版主推薦預測必須包含預測說明 (走地玩法除外)，並透過 Args.predictdescription 欄位傳遞。
- 預測說明最少 2 字元、最多 200 字元。
- 查詢版主預測賽事 API 僅回傳三天內的賽事資料。

---

## 關鍵設計決策

- - 將版主預測 API 與一般預測 API 分離，以避免相互干擾，並支援預測說明的特殊需求。
- 採用 Args 動態欄位儲存預測說明，而非擴充固定結構，保持未來擴展彈性。
- 增加社群版主預測重整 Signal，確保版主更新預測後前端能即時重整。

---

## 注意事項

- ⚠️ - ⚠️ Request 參數使用 'predictdescription' (全小寫)，但 Response 中回傳 'predictDescription' (駝峰式)，需注意命名不一致。
- ⚠️ 文件屬於舊 Sprint (TCZB Sprint 159)，需人工確認規格是否仍為最新。
- ⚠️ 更新預測說明 API 使用 PUT method，需確認是否有權限控管。
