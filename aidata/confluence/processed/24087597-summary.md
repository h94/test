## 摘要

本文說明為監控加密貨幣相關機器狀態而建立的 Dashboard，新增兩組 Heartbeat API：一組讓個別機器依機器名稱與程式回報狀態，另一組供 crawlerservice 整併上報內部 IP 等資訊。儀表板視覺設計參考既有的賽事賠率 Dashboard，並沿用舊有的 machine mapping 配置。對於 AI 開發，此文件提供 crawlerservice 機器心跳的 API 規格與監控架構，方便日後自動化健康檢查或異常告警的實作。
