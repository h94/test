## 摘要

這份文件整理了 bet365、pinnacle、ku888、沙巴、betfair 等 14 個博彩網站的爬蟲技術分析，記錄各站的渲染方式（AJAX/WebSocket）、API 端點、是否需要 VPN、開發進度與已知問題，並針對 SBOBet 和 1xbet 提出由中心節點抓取聯盟清單後分派給多爬蟲的架構設計，是開發與維護爬蟲服務的重要技術參考。

## 關鍵設計決策

- - SBOBet 採用「一隻爬蟲抓取各球種 country list 丟給 Pricecenter，再由 Pricecenter 分配給其他爬蟲針對個別國家抓取」的分散式架構
- 1xbet 先用一隻爬蟲抓取所有聯盟，由 Pricecenter 分派後各 crawler 針對分配到的 league 找 game，每個 game 獨立開 thread，且只抓今明兩天的賽事（含 InPlay）
- 部分網站（如 KU/JZ）因畫面用 WebSocket 或 AJAX 更新，採用 Python + Selenium 模擬瀏覽器抓取
- 能直接呼叫 API 的網站（如 bwin、1xbet）優先使用 API 取得資料，以降低資源消耗
- 沙巴（nova88）的籃球比賽進行時間不可信，畫面會亂跳，可能是網站本身問題
