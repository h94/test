## 摘要

本文件定义了一个针对 TG 网站的爬虫代理方案，采用 Selenium 实现自动登录、图形验证码识别（调用外部 API，准确率约 80%）以及赛事 correct score 数据爬取。流程为：VPN 环境下访问目标网站，输入账号密码并解析验证码，获取比赛 ID 列表后逐个爬取详情页，通过 XPath 解析出 correct score 数据并以统一 match 格式发送至内部 API。对 AI 开发的参考价值在于明确了该 Provider 的登录、反爬绕过和数据提取的具体实现方式，以及验证码解析服务的接口约定。

---

## 關鍵業務規則

- - 必须通过 VPN 才能访问目标网站（注：实际测试时 VPN 无法成功登录，该前置条件未验证）。
- 登录过程需调用外部验证码解析 API，该 API 准确率约 80%，不能保证每次成功。
- 爬取流程需先获取所有比赛 ID 列表，再逐一爬取各比赛详情，不可批量查询。
- 数据解析采用 XPath 方式，提取后以 odd-correct score 为主体的 match 格式发送至 API。

---

## 關鍵設計決策

- - 选择 Selenium 而非直接 HTTP 请求，原因：需要模拟真实浏览器行为以绕过反爬机制，同时处理 JavaScript 渲染的登录表单。
- 验证码识别采用外部 API，而非自研模型，优先考虑快速集成，接受约 80% 的准确率。
- 采用先获取比赛 ID 列表再逐场爬取的串行方案，简化异常处理，避免并发可能引发的风控。
- 数据输出格式统一为 match 格式，与下游预测或价格服务约定一致。
