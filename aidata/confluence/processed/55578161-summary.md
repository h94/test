## 摘要

本文件記錄了從 ESPN 的 FastcastService API 獲取 MLB 棒球走地詳情的方法，重點在於取得每次投球的球速（pitchVelocity）與球種（text）。API 端點為 https://fcast.espncdn.com/.../gp-baseball-mlb-{gameid}/message/{num}/checkpoint，其中 num 參數的規律為每次投球 +6，但起始數字及如何取得尚待確認。這對於開發 ESPN 棒球爬蟲的資料擷取邏輯具有直接參考價值。

- - 採用 ESPN 的 FastcastService API 作為資料來源，直接從 message/{num}/checkpoint 獲取投球資訊。
