## 摘要

本文件定義 GameSetting 前端站台的 Log 查詢工具，包含三種查詢：登入記錄（單獨頁面，僅查自己帳號）、設定值變更記錄（從設定頁面進入，可查所有 log）、站台停啟用記錄。明確提供對應的 GET API、路由參數模型與回應欄位。對開發而言，釐清了後端需實作的 Log 端點、過濾條件與資料結構，有助於前後端對接。

---

## 關鍵業務規則

- - 登入 log 查詢頁面僅能查詢當前登入帳號自己的登入記錄，搜尋條件日期為選填
- 設定值 log 必須由設定值查詢頁面進入，進入後可查詢該設定值的所有 log，搜尋條件帳號、日期均為選填
- 站台停啟用 log 列表可依帳號、日期篩選（選填）

---

## 關鍵設計決策

- - API 路由將 company 和 gameType 作為路徑參數，以區分不同租戶及遊戲類型；過濾條件以 query string 傳遞，保留擴充彈性
