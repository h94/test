## 摘要

這份文件定義了一個中國A股爬蟲（AStockParser）的資料擷取策略。爬蟲主要目標是從 Investing.com 取得當日A股的收盤價、最高價、最低價、開盤價及漲跌幅等資訊。實作流程為先透過 Stock Screener API 取得所有A股的基本列表，再依據列表中的股票名稱拼音逐一爬取個股價格頁面。

---

## 關鍵業務規則

- - 需爬取的個股欄位包含：當日最高價、當日最低價、昨收盤價、開盤價、漲跌幅、漲跌。
- 爬蟲流程：先取得A股所有股票基本資訊列表（透過 stock-screener API，country[] 參數中國代碼為 37，Content-Type 為 multipart/form-data）→ 從列表中取得個股名稱拼音 → 逐一爬取個股價格資訊（網址格式：https://cn.investing.com/equities/{股票名稱拼音}）。

---

## 關鍵設計決策

- - 資料來源選擇 Investing.com 作為中國A股資訊的爬取目標。
- 採用兩階段爬取策略：先取得股票清單，再批次爬取個股明細，而非嘗試即時搜尋或單一入口。
- 使用 Stock Screener Service API 的 country 參數過濾市場，而非爬取網頁結構，以結構化方式獲取股票清單。
