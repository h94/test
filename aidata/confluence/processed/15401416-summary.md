## 摘要

本文件為 PriceCenterManage 服務新增 KU provider 的 Page API 設計，定義了三個端點：GET ku/getpage/{provider} 取得網頁與帳號資訊，POST ku/workfor/{pageNames}/{account}/{provider} 進行心跳偵測，POST ku/sendstop/{pageName}/{account}/{provider} 刪除 handler。同時，它也確認了 Bet365、Pinnacle、Bwin、Betfair 的既有 Page API 功能拆分是否為最新版本。這份設計文件可作為 AI 開發時串接 KU 相關功能的 API 規格參考。
