## 摘要

本文件記錄 Daum Finance 韓國股市的兩個外部 API 端點規格：1) 取得全部股票清單，支援 KOSPI/KOSDAQ 市場分類；2) 取得單一股票的歷史交易資料，支援分頁。文件載明了請求的 Method、Route、必要 Header（referer、user-agent）以及 Response 結構。對 AI 開發而言，這是一份外部資料源的對接規格書，開發串接韓股資料爬取或資料更新模組時可直接引用這些端點與參數定義。

## 關鍵設計決策

- - 使用 `market` 參數區分 KOSPI 與 KOSDAQ 市場，而非使用不同端點。
- 取得單股票歷史時，使用 `pagination=true` 配合 `page` 和 `perPage` 參數（預設每頁 50 筆）進行分頁，而非一次回傳全部歷史資料。
- 兩個 API 請求均需設定特定的 `referer` 與 `user-agent` Header，模擬瀏覽器正常訪問行為。

- ⚠️ - ⚠️ 文件最後更新於 2022-12-28，API 可能已變更或失效，使用前需重新驗證端點可用性。
