## 摘要

本文檔定義了 PriceBackendService 後台管理用的 RESTful API，涵蓋運動交易訂單新增、運動文章管理、App 版本控制、會員分潤與日報查詢、球種玩法開關、會員列表與身份管理、賽事結果更新等 14 個端點。每個 API 皆提供 method、route、請求參數範例與回應結構，對 AI 開發而言可直接作為實作後台功能的規格參考，並支援生成客戶端呼叫或測試腳本。

---

## 關鍵業務規則

- - 新增運動站台文章時，請求中的 id 欄位需為空值，由系統自動生成唯一識別碼。
- 更新賽事結束資訊（PUT /pricebackendservice/api/pricecenter/games/{...}/resultinfo）僅能新增或修改 resultInfo 內的欄位，傳入空物件 {} 不會刪除已存在的屬性（例如已設定 'fintype':'early'，傳 {} 後 fintype 仍存在）。
- 更新會員身份時，Memberships 陣列可填入的字串值及對應角色為：admin（管理者）、vlsport（緯來專家）、moderator（版主會員）。
- 取得 App 系統版本列表回傳的 device 欄位值為 'Android' 或 'IOS'，並包含版本號 version 與更新說明 description。
- 取得時間範圍內會員與預測報表時，參數 sdate 與 edate 格式為 yyyy-MM-dd；回應中 registers 為註冊成功人數，actives 為活動人數，chats 為會員社群訊息數（不含小編），trades 為成功交易金額，editorchats 為小編社群訊息數；gameType 為 'All' 時代表所有球種的總和。
- 取得年月會員賽事分潤明細 API (/api/payment/sport/reportlist/{year}/{month}) 回傳的資料按帳號彙總，含各聯盟解鎖次數與分潤金額。
